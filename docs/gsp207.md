# GSP207 - Dataflow: Qwik Start - Python

Runbook untuk [`gsp207.sh`](../gsp207.sh). Status: terverifikasi 100/100 (2026-08-21, asia-southeast1).

## Sebelum jalan

1. Start lab, login pakai kredensial student, buka Cloud Shell.
2. Cek region di teks lab. Default script `asia-southeast1`.
3. Nama bucket `<PROJECT_ID>-bucket`, sesuai saran lab. Bisa ditimpa dengan `BUCKET_NAME=`.
4. Sediakan waktu. Ini lab paling lambat di kelompok Qwik Start: 10-15 menit.

## Tiga hal yang membedakan dari teks lab

- **Diamnya lama itu normal.** Perintah pipeline menunggu sampai job Dataflow
  selesai, bukan hang. Sekitar 8 menit tanpa output baru.
- **Docker dilewat kalau tidak perlu.** Lab menyuruh masuk container `python:3.12`
  karena apache-beam belum tentu mendukung Python versi terbaru. Script mengecek
  versi Python Cloud Shell dulu: 3.9-3.12 dijalankan di venv (lebih cepat, tidak
  perlu menarik image), di luar itu baru jatuh ke container seperti lab.
- **Restart API tetap dikerjakan.** Terlihat mubazir, tapi instruksi lab memang
  memintanya: project lab kadang punya Dataflow API yang terdaftar aktif padahal
  penyediaannya belum selesai, dan job pertama gagal start karenanya.

Script mengulang perintah pipeline sampai tiga kali dengan jeda 45 detik, sesuai
saran lab ("Re-run the command until the job starts").

## Klik manual

Dua checkpoint. Sebelum mengklik yang kedua, pastikan kolom `state` di tabel job
yang dicetak script sudah `SUCCEEDED` — bukan `RUNNING`.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| Job gagal start tiga kali | Dataflow API belum siap. Tunggu 2 menit, jalankan ulang script — bucket yang sudah ada akan dilewati. |
| `Workers have started successfully` lalu diam lama | Normal. Job sedang berjalan; tunggu sampai perintah kembali ke prompt. |
| `pip install` gagal soal versi Python | Versi Python Cloud Shell keluar dari rentang yang didukung dan deteksi otomatisnya meleset. Jalankan manual dengan `docker run -it python:3.12 /bin/bash` seperti teks lab. |
| `results/` kosong | Job belum selesai atau gagal. Cek `gcloud dataflow jobs list --region=<region>`. |
