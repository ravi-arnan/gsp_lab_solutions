# GSP069 - App Engine: Qwik Start - PHP

Runbook untuk [`gsp069.sh`](../gsp069.sh).

Lab ini mendemonstrasikan proses deployment aplikasi sederhana berbasis PHP (runtime `php83`) ke Google App Engine Standard Environment menggunakan `gcloud CLI`, pengujian akses web, pembaruan kode (`hello world!` ke `goodbye world!`), dan redeployment.

## Alur Kerja

1. **Task 1: Enable Google App Engine Admin API**
   - Mengaktifkan API `appengine.googleapis.com`.
   - Menginisialisasi App Engine application pada region yang sesuai (`europe-west` untuk `europe-west1`, `us-central` untuk `us-central1`).

2. **Task 2: Download the Hello World app**
   - Menyiapkan berkas konfigurasi `app.yaml` dengan konfigurasi runtime modern `php83`.
   - Membuat berkas entrypoint `index.php` yang menampilkan pesan `hello world!`.

3. **Task 3 & 4: Deploy your app**
   - Men-deploy aplikasi ke App Engine (`gcloud app deploy app.yaml -q`).
   - Melakukan uji respon HTTP ke domain App Engine (`https://<PROJECT_ID>.appspot.com`).
   - Penilaian: *Deploy your app* (Task 4).

4. **Task 5: Make a change**
   - Memperbarui `index.php` untuk menampilkan `goodbye world!`.
   - Menjalankan deployment ulang (`gcloud app deploy app.yaml -q`) dan memverifikasi perubahan teks.

## Cara Menjalankan

Jalankan langsung di terminal Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp069.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp069.sh
bash gsp069.sh
```

Region akan ditanyakan di awal (default `europe-west1`). Cukup tekan `Enter` jika panel lab Anda sesuai.

Setelah script menampilkan banner `SELESAI!`, klik tombol **Check my progress** di panel lab:
- *Deploy your app*
