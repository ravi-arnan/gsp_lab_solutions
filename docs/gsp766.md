# GSP766 - Managing a GKE Multi-tenant Cluster with Namespaces

Runbook untuk [`gsp766.sh`](../gsp766.sh). Status: **terverifikasi 100/100** (2026-11-10).

Lab untuk mempelajari konfigurasi cluster multi-tenant di Google Kubernetes Engine (GKE) menggunakan namespaces, RBAC, resource quotas, dan usage metering ke BigQuery.

## Alur Kerja

1. **Task 1: Download required files**
   - Mengunduh manifest YAML dan SQL query template dari `gs://spls/gsp766/gke-qwiklab`.
   - Menyiapkan direktori kerja `~/gke-qwiklab`.

2. **Task 2: View and create namespaces**
   - Mengonfigurasi kredensial GKE untuk cluster `multi-tenant-cluster`.
   - Membuat namespace `team-a` dan `team-b`.
   - Menjalankan pod `app-server` di kedua namespace.
   - Mengatur active namespace context ke `team-a`.
   - Penilaian: *Create namespaces* (10 pts).

3. **Task 3: Access Control in namespaces**
   - Menambahkan role IAM `roles/container.clusterViewer` ke service account `team-a-dev`.
   - Membuat role `pod-reader` dan role `developer` di namespace `team-a`.
   - Membuat rolebinding `team-a-developers` yang menghubungkan service account `team-a-dev` ke role `developer`.
   - Mengunduh service account key ke `/tmp/key.json`.
   - Penilaian: *Access Control in namespaces* (25 pts).

4. **Task 4: Resource quotas**
   - Membuat resource quota `test-quota` (maksimal 2 pods dan 1 load balancer) di namespace `team-a`.
   - Menjalankan pod kedua `app-server-2`.
   - Melakukan patching pada `test-quota` untuk menaikkan batas pods menjadi 6.
   - Menerapkan quota komputasi `cpu-mem-quota` (CPU dan Memory requests/limits).
   - Menjalankan pod uji `cpu-mem-demo` dengan konfigurasi request dan limit yang sesuai.
   - Penilaian: *Resource quotas* (25 pts).

5. **Task 5: Monitoring GKE and GKE usage metering**
   - Mengaktifkan GKE resource usage metering pada cluster dengan tujuan BigQuery dataset `cluster_dataset`.
   - Mengenerate kueri SQL cost breakdown dari template `usage_metering_query_template.sql`.
   - Membuat tabel `usage_metering_cost_breakdown` di dataset `cluster_dataset`.
   - Mendaftarkan scheduled query transfer config via BigQuery Data Transfer REST API (menghindari error OAuth OOB lama).
   - Menjalankan custom query verifikasi `SELECT * FROM ...cluster_dataset.usage_metering_cost_breakdown` via `bq query`.
   - Penilaian: *Monitoring GKE and GKE usage metering* (40 pts).
   - Seluruh task otomatis penuh dari terminal, tidak perlu membuka Looker Studio di browser.
