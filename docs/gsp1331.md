# GSP1331 - Request Temporary Elevated Access with Privileged Access Manager

Runbook untuk [`gsp1331.sh`](../gsp1331.sh). Status: **siap uji**.

Lab tentang pengelolaan hak akses sementara (just-in-time) menggunakan Privileged Access Manager (PAM). Menggunakan dua akun user: **Primary User** (requester) dan **Secondary User** (approver).

## Alur Kerja

1. **Tahap Setup (Cloud Shell Username 1):**
   - Mengaktifkan API `privilegedaccessmanager.googleapis.com`.
   - Mengikat role `roles/privilegedaccessmanager.serviceAgent` ke PAM service agent di level project.
   - Membuat entitlement `pam-entitlement` dengan role `roles/resourcemanager.projectIamAdmin` (durasi 1 Day / 86400s).
   - Memperbarui entitlement dengan durasi maksimal 10 jam (`36000s`).
   - Mengajukan permohonan grant durasi 10 jam dengan justifikasi `pam-test`.

2. **Tahap Approval (Username 2):**
   - PAM menerapkan kontrol persetujuan: approver tidak bisa digantikan oleh siapapun di luar daftar approver.
   - Cara termudah: Buka tab incognito browser, login sebagai Secondary User, navigasi ke **IAM & Admin > PAM > APPROVE GRANTS**, lalu klik **Approve/Deny > Approve**.
   - Opsi CLI: Buka Cloud Shell di sesi Secondary User, lalu jalankan `bash gsp1331.sh approve`.

## Cara Menjalankan

### Langkah 1: Jalankan di Cloud Shell (sebagai Primary User)

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1331.sh
bash gsp1331.sh
```

Email Secondary User akan dideteksi secara otomatis dari IAM policy project. Cukup tekan `Enter` saat konfirmasi prompt.

Setelah selesai, klik **Check my progress** untuk:
- Task 1: Enable Privileged Access Manager.
- Task 2: Create the entitlement.
- Task 3: Update the entitlement

### Langkah 2: Setujui Grant sebagai Secondary User

Buka jendela browser incognito baru, login menggunakan kredensial **Secondary User** yang ada di panel lab:
1. Buka menu **IAM & Admin > PAM > APPROVE GRANTS**.
2. Klik tombol **Approve/Deny** pada grant yang tertunda.
3. Klik **Approve**.

*(Atau via Cloud Shell sesi Secondary User: `bash gsp1331.sh approve`)*

Tunggu sekitar 30 detik agar log approval sinkron, lalu klik **Check my progress** untuk:
- Task 4: Request temporary elevated access.

## Detail yang Gampang Salah

- **PAM Service Agent tingkat organisasi:** PAM menggunakan service agent berbasis organisasi (`service-org-<ORG_NUM>@gcp-sa-pam...`), bukan project number. Script mengekstrak nomor organisasi melalui `gcloud projects get-ancestors`.
- **Etag saat update entitlement:** Endpoint `entitlements update` akan menolak request jika `etag` tidak disertakan atau kedaluwarsa. Script mengambil `etag` segar via `entitlements describe` sebelum melakukan update.
- **Approver wajib user terdaftar:** Approval harus dikirimkan oleh principal yang terdaftar pada approval workflow (`Secondary User`).
