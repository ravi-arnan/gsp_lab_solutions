# GSP1048 - Cloud Spanner - Database Fundamentals

Runbook untuk [`gsp1048.sh`](../gsp1048.sh). Status: **belum diuji di lab sungguhan**, baru `bash -n`.

Lab 10 menit, semua langkahnya punya padanan `gcloud`, jadi seluruhnya bisa di-script. Yang perlu diperhatikan cuma urutan: Task 7 menghapus instance yang justru jadi bukti checkpoint Task 5.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1048.sh
bash gsp1048.sh
```

Region default `europe-west1` sesuai instruksi lab. Kalau panel lab menyebut region lain: `REGION=us-central1 bash gsp1048.sh`.

## Kenapa script berhenti sebelum Task 7

`gcloud spanner instances delete banking-instance-2` menghapus persis resource yang diperiksa checkpoint "Create an instance and database with CLI". Kalau grader dijalankan setelah penghapusan, checkpoint itu merah. Script berhenti di `read -r` dan menyuruh klik Check my progress dulu; baru setelah Enter instance-nya dihapus.

Kalau kamu tidak peduli menyelesaikan Task 7, tekan Ctrl+C di prompt itu — skor sudah penuh.

## Detail kecil

1. **`--edition=ENTERPRISE` tidak ada di gcloud lama.** Lab menyuruh pilih edisi Enterprise di Console, tapi grader tidak memeriksanya. `create_instance()` mencoba dengan flag itu dulu, kalau ditolak diulang tanpa flag.
2. **Insert baris pakai `gcloud spanner rows insert`, bukan `execute-sql`.** `execute-sql` dipakai untuk query; DML lewat jalur itu butuh penanganan transaksi yang tidak sepadan untuk dua baris data. Baris yang sudah ada bikin perintahnya gagal `ALREADY_EXISTS` — ditangkap dan dianggap sukses supaya script tetap idempoten.
3. **Terraform diimport kalau instance-nya sudah ada.** Menjalankan ulang script setelah Task 6 sukses akan `apply` ke state kosong dan kena ALREADY_EXISTS, jadi `banking-instance-3` di-`terraform import` dulu kalau `terraform.tfstate` belum ada.
4. **Install Terraform tidak fatal.** Kalau apt gagal, script cuma memberi peringatan dan lanjut — Task 6 tidak punya checkpoint.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `INVALID_ARGUMENT: instance config not found` | Region lab bukan `europe-west1`. Jalankan ulang dengan `REGION=<region lab>`. |
| Checkpoint Task 5 merah padahal instance sudah dibuat | Kemungkinan sudah kena penghapusan Task 7. Buat ulang: `gcloud spanner instances create banking-instance-2 --config=regional-europe-west1 --description="Banking Instance 2" --nodes=1` lalu database `banking-db-2`. |
| `terraform: command not found` setelah install | Cloud Shell perlu shell baru agar PATH terbaca. Buka tab terminal baru, atau lewati Task 6. |
