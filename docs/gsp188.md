# GSP188 - App Dev: Deploying the Application into Kubernetes Engine - Python

Runbook untuk [`gsp188.sh`](../gsp188.sh). Status: siap dijalankan di live lab Cloud Shell Qwiklabs (belum diuji di lab sungguhan).

## Kenapa lab ini cocok di-script

Lab ini menggabungkan setup aplikasi Quiz (App Engine, Datastore, Pub/Sub, Cloud Spanner), pembuatan cluster GKE `quiz-cluster`, Artifact Registry, Cloud Build untuk dua image Docker (`quiz-frontend` dan `quiz-backend`), serta deployment manifest Kubernetes. Dengan script, seluruh proses berjalan otomatis tanpa harus mengedit `Dockerfile` dan file YAML secara manual.

## Sebelum jalan

1. Start lab di Google Cloud Skills Boost / Qwiklabs, login dengan kredensial student.
2. Buka Cloud Shell.
3. Cocokkan `ZONE` dan `REGION` dengan panel instruksi lab (default: `europe-west1-c` dan `europe-west1`).

## Jalankan

Di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp188.sh
bash gsp188.sh
```

Waktu estimasi: ~6-8 menit (terutama pembuatan GKE cluster dan build dua Docker image).

## Yang dikerjakan script

| Task | Aksi | Checkpoint |
|------|------|------------|
| 1 | Unduh starter code `kubernetesengine`, sesuaikan `prepare_environment.sh`, dan jalankan setup aplikasi Quiz | Configure the Quiz application |
| 2 | Buat cluster GKE `quiz-cluster` (3 node, full Cloud API scopes) dan ambil kredensial `kubectl` | Create Kubernetes engine cluster |
| 3 | Buat Docker repository `container-dev-repo` di Artifact Registry | Create a Docker Repository |
| 4 | Tulis `frontend/Dockerfile` dan `backend/Dockerfile`, lalu build image dengan Cloud Build | Build Docker Images using Cloud Build |
| 5 | Isi placeholder di `frontend-deployment.yaml` dan `backend-deployment.yaml`, lalu `kubectl apply` untuk deployment dan `frontend-service.yaml` | Create Kubernetes Deployment and service resources |

## Troubleshooting

| Gejala | Sebab dan Solusi |
|--------|------------------|
| `prepare_environment.sh` gagal di tengah | Jalankan ulang `bash gsp188.sh`; script sudah idempoten. |
| External IP LoadBalancer `<pending>` | Tunggu 1-2 menit lalu cek dengan `kubectl get services`. |
