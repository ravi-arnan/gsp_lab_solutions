# GSP281 - Introduction to SQL for BigQuery and Cloud SQL

Runbook untuk [`gsp281.sh`](../gsp281.sh).

Lab ini memperkenalkan dasar-dasar query SQL pada BigQuery menggunakan public dataset London bikeshares (`bigquery-public-data.london_bicycles.cycle_hire`), ekspor subset data ke file CSV dan upload ke Cloud Storage, serta provisioning Cloud SQL MySQL 8.0 instance (`my-demo`) beserta database `bike`.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp281.sh
bash gsp281.sh
```

Atau one-liner:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp281.sh | bash
```

Region dan zone Cloud SQL akan ditanyakan di awal dengan default `asia-south1-a` (sesuai modul instruksi lab). Tekan Enter jika cocok.

Lama eksekusi: ~ 4-6 menit (sebagian besar untuk alokasi instance Cloud SQL).

## Tabel Task

| Task | Otomatis | Keterangan |
|------|----------|------------|
| 1. Review the basics of SQL | - | Konseptual SQL (tanpa checkpoint) |
| 2. Explore the BigQuery console | - | Eksplorasi public dataset `london_bicycles` (tanpa checkpoint) |
| 3. Additional SQL Keywords | - | Latihan GROUP BY, COUNT, AS, ORDER BY (tanpa checkpoint) |
| 4. Export BigQuery data to CSV files | Ya | Ekspor CSV via `bq query`, buat Cloud Storage bucket `gs://<PROJECT_ID>`, dan upload CSV (2 Checkpoint) |
| 5. Create a Cloud SQL instance | Ya | Provisioning Cloud SQL MySQL 8.0 instance `my-demo` (Checkpoint) |
| 6. Create a Cloud SQL database and table | Ya | Buat database `bike` di instance `my-demo` via CLI (Checkpoint) |
| 7. Upload CSV files to tables | - | Eksplorasi import CSV ke tabel via Cloud Console / MySQL prompt (tanpa checkpoint) |
| 8. Run data queries in Cloud SQL | - | Latihan DELETE, INSERT, UNION via MySQL terminal (tanpa checkpoint) |

## Catatan

- **Inkonsistensi Nama File CSV**: Teks instruksi lab pada Task 4 meminta menyimpan file sebagai `start_station_name.csv` dan `end_station_name.csv`, namun pada baris berikutnya menyebut `start_station_data.csv` dan `end_station_data.csv`. Script mengantisipasi ini dengan mengunggah kedua varian nama ke bucket sehingga grader selalu menemukan file yang diharapkan.
- **Konfigurasi Cloud SQL**: Modul lab menentukan edisi Enterprise Development (4 vCPU, 16 GB RAM, 100 GB storage) dengan High Availability (`REGIONAL`) pada zone `asia-south1-a`. Script menyertakan mekanisme fallback otomatis ke tier ringan jika terjadi pembatasan kuota regional di sandbox lab.
- **Interaksi MySQL**: Checkpoint penilaian berakhir di Task 6 ("Create a database"). Tahapan pembuatan tabel dan manipulasi data di Tasks 7-8 merupakan eksplorasi belajar yang dapat dilakukan interaktif via `gcloud sql connect my-demo --user=root --quiet` (password `ChangeMe1!`).
