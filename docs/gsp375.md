# GSP375 - Share Data using Google Data Cloud: Challenge Lab

Challenge lab penutup jalur Data Sharing Partner. Dua project, dua fase, plus
satu checkpoint yang wajib dikerjakan di Looker Studio.

## Skor maksimum lewat script: 80/100

Checkpoint terakhir ("Connect BigQuery to Data Studio") menilai report Looker
Studio. Sama seperti [gsp1042](gsp1042.md), grader lab keluarga ini memang bisa
melihat report tersebut, jadi bagian itu tidak bisa dilewati.

## Jalankan

Nama view diacak per peserta (`authorized_view_XXXX`,
`customer_authorized_view_XXXX`) — salin dari teks Task 1 dan Task 3.

```bash
# 1. Cloud Shell Data Sharing Partner
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp375.sh
PARTNER_VIEW=authorized_view_XXXX \
CUSTOMER_USER=student-...@qwiklabs.net \
bash gsp375.sh partner

# 2. Cloud Shell Customer
PARTNER_PROJECT=qwiklabs-gcp-... \
PARTNER_VIEW=authorized_view_XXXX \
CUSTOMER_VIEW=customer_authorized_view_XXXX \
PARTNER_USER=student-...@qwiklabs.net \
bash gsp375.sh customer
```

## Task

| Task | Fase | Catatan |
|------|------|---------|
| 1. Partner authorized view + otorisasi + IAM | partner | dua checkpoint |
| 2. UPDATE county di `customer_info` | customer | tanpa checkpoint, tapi wajib — tanpa ini view customer kosong |
| 3. Customer authorized view + otorisasi + IAM | customer | dua checkpoint |
| 4. Visualisasi Looker Studio | manual | checkpoint terakhir |

## Bagian manual (Task 4)

Kerjakan **dengan akun partner**, tapi datanya dari project **customer** — itu
justru inti pertukaran dua arahnya.

1. Buka [lookerstudio.google.com](https://lookerstudio.google.com) dari jendela
   console partner → **Blank Report**
2. **BigQuery** → **Authorize** → **Allow**
3. Cari project **customer** (cek **MY PROJECTS** dan **SHARED PROJECTS**) →
   `customer_dataset` → `customer_authorized_view_XXXX` → **Add to report**
4. Judul report: **Data Sharing Partner Vizualization** (ejaan `Vizualization`
   memang begitu di instruksi lab)
5. **Insert → Column chart**
6. Dimension `county`, Breakdown dimension `Count`, Metric `Count`

**Jebakan yang kena saat diuji 2026-08-05:** yang ke-add malah
`authorized_view_pzlt`, yaitu view partner sendiri. Gampang dikenali dari
daftar fieldnya — kalau muncul `area_land_meters`, `city`, `state_code`, itu
skema `zip_codes` alias view partner. View customer yang benar hanya punya dua
kolom: `county` dan `Count`. Perbaikannya cukup **Add data** lagi lalu ganti
Data source pada chart-nya, tidak perlu bikin report baru.
