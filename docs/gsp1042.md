seperti [gsp1041](gsp1041.md). Bedanya lab ini menambahkan dashboard Looker
Studio, dan **dashboard itu ikut dinilai**.

## Jalankan

```bash
# 1. Cloud Shell Data Sharing Partner Project — Task 1, 2, 3
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1042.sh
CUSTOMER_A_USER=student-...@qwiklabs.net \
CUSTOMER_B_USER=student-...@qwiklabs.net \
bash gsp1042.sh partner

# 2. Cloud Shell Customer Project A
PARTNER_PROJECT=qwiklabs-gcp-... bash gsp1042.sh a

# 3. Cloud Shell Customer Project B
PARTNER_PROJECT=qwiklabs-gcp-... bash gsp1042.sh b
```

## Bagian manual (10 poin per customer)

Kerjakan **dengan akun customer yang bersangkutan**, bukan akun partner:

1. Buka [lookerstudio.google.com](https://lookerstudio.google.com) dari jendela
   console customer itu → **Blank Report**
2. Cari **BigQuery** → **Authorize** → **Allow**
3. Project customer → `customer_x_dataset` → `customer_x_table` → **Add** →
   **Add to report**
4. Ganti judul jadi `Customer A Visualization` / `Customer B Visualization`
5. **Insert → Pie chart**
6. Seret **city** dari Available Fields ke dimension, menggantikan `zip_code`

**Jebakan akun.** Kalau panel "MY PROJECTS" hanya menampilkan project partner
dengan `demo_dataset` berisi `authorized_view_a/b`, berarti Looker Studio masih
memakai sesi akun partner. Sign out, masuk sebagai customer yang benar, ulangi.

Bagian "Get report link lalu sign out dan cek dari akun lain" di instruksi lab
boleh dilewati — itu demonstrasi keamanan, tidak dinilai.
