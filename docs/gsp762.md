# GSP762 - Create PDFs with Go and Cloud Run

Runbook untuk [`gsp762.sh`](../gsp762.sh).

Lab ini mendemonstrasikan perancangan arsitektur pemrosesan dokumen berbasis event (event-driven architecture) menggunakan Cloud Run, Cloud Storage, dan Pub/Sub. Sebuah microservice Go mengonversi berkas dokumen (Word, Excel, gambar) menjadi format PDF menggunakan LibreOffice headless, dipicu secara otomatis setiap kali dokumen diunggah ke Cloud Storage bucket.

## Cara jalan

Jalankan perintah one-liner langsung di terminal Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp762.sh | bash
```

Atau tentukan region secara eksplisit jika panel lab meminta region khusus (`us-central1`):

```bash
REGION=us-central1 curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp762.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp762.sh
bash gsp762.sh
```

Durasi eksekusi: sekitar 4 sampai 6 menit.

## Yang Perlu Diperhatikan

1. **Alokasi Memori Cloud Run (2Gi):**
   LibreOffice headless memerlukan kapasitas memori yang cukup untuk memproses konversi dokumen Office dan grafis. Konfigurasi service Cloud Run wajib menyertakan flag `--memory=2Gi` agar tidak mengalami error Out of Memory (OOM).

2. **Kompilasi Binary Statis:**
   Binary Go dikompilasi di Cloud Shell menggunakan `CGO_ENABLED=0 GOOS=linux go build -o server` sebelum container image di-build dan di-submit ke Cloud Build. Hal ini memastikan binary yang disalin ke container debian dapat langsung dieksekusi secara mulus.

3. **Autentikasi Push Pub/Sub ke Private Cloud Run:**
   Service Cloud Run di-deploy dengan opsi `--no-allow-unauthenticated`. Notifikasi Pub/Sub mengantarkan pesan melalui push endpoint terproteksi dengan identitas Service Account `pubsub-cloud-run-invoker`. Hak penandatanganan token OIDC pada Pub/Sub Service Agent sudah disediakan otomatis oleh environment lab.

4. **Idempotensi Resource:**
   Script mengecek keberadaan repository Artifact Registry, service account, bucket notification, dan subscription sebelum melakukan pembuatan atau pembaruan konfigurasi, sehingga aman dijalankan berulang kali jika koneksi terputus.
