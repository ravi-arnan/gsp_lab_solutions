# GSP074 - Cloud Storage: Qwik Start - CLI/SDK

Runbook untuk [`gsp074.sh`](../gsp074.sh). Status: terverifikasi 100/100 sekali jalan (2026-08-21, us-east1).

## Sebelum jalan

1. Start lab, login pakai kredensial student.
2. Buka Cloud Shell.
3. Cek region di panel lab. Default script `us-east1`; hanya dipakai untuk
   `gcloud config set compute/region` (bucket sendiri dibuat dengan lokasi
   default US multi-region), jadi tidak fatal kalau beda.
4. Nama bucket diturunkan dari Project ID (`<PROJECT_ID>-bucket`), otomatis unik.
   Bisa ditimpa lewat `BUCKET=<nama> bash gsp074.sh`.

## Yang dikerjakan script

| Task | Perintah | Checkpoint |
|------|----------|------------|
| 1 | `gcloud storage buckets create` | ✅ Create a Cloud Storage bucket |
| 2 | unduh `ada.jpg` dari Wikimedia, `cp` ke bucket, hapus lokal | — |
| 3 | `cp -r gs://.../ada.jpg .` | — |
| 4 | `cp` ke `image-folder/` | ✅ Copy an object to a folder in the bucket |
| 5-6 | `ls` dan `ls -l` | — |
| 7 | `objects update --add-acl-grant=entity=allUsers,role=READER` | ✅ Make your object publicly accessible |
| 8 | cabut ACL + hapus `ada.jpg` — fase `cleanup` | tidak ada checkpoint |

Setelah Task 7 script mengecek sendiri akses publiknya dengan `curl` ke
`https://storage.googleapis.com/<bucket>/ada.jpg`. Harus **HTTP 200**. Kalau 403,
jangan klik checkpoint dulu.

Task 1 idempoten (`buckets describe` dulu sebelum create), jadi script aman diulang.

## Kenapa Task 8 dipisah

Task 8 mencabut akses publik lalu menghapus `ada.jpg` — persis yang dinilai
checkpoint 3. Tidak ada poin di situ. Setelah semua hijau, kalau tetap mau:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp074.sh
bash gsp074.sh cleanup
```

Harus di-download dulu, bukan `curl | bash -s cleanup`.

## Klik manual

Tiga checkpoint di atas. Pilihan ganda (tidak masuk skor):

- Default storage class ditentukan saat membuat bucket — **True**
- ACL menentukan siapa yang punya akses ke bucket dan object — **True**
- Cara berhenti berbagi object secara publik — **allUsers**

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `409 Bucket already exists` | Nama bucket dipakai orang lain. Jalankan ulang dengan `BUCKET=<nama-lain> bash gsp074.sh`. |
| Cek akses publik balas `HTTP 403` | Public access prevention aktif di bucket atau org policy. Checkpoint 3 tidak akan hijau; cek `gcloud storage buckets describe gs://$BUCKET`. |
| `--add-acl-grant` ditolak dengan pesan uniform bucket-level access | Bucket dibuat dengan UBLA aktif, ACL per-object mati. Hapus bucket lalu buat ulang tanpa `--uniform-bucket-level-access`. |
| `Project belum di-set` | `gcloud config set project <Project ID dari panel lab>`. |
