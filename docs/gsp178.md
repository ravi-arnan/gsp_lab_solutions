# GSP178 - Setting up a Private Kubernetes Cluster

Runbook untuk [`gsp178.sh`](../gsp178.sh). Status: siap dijalankan (estimasi 100/100, 7 checkpoint).

## Sebelum jalan

1. Start lab, login pakai kredensial student.
2. Buka Cloud Shell.
3. Cek Zone di panel lab (default: `us-west1-b`).

## Jalankan

### Opsi 1 (Disarankan, interaktif dengan jeda otomatis)

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp178.sh
bash gsp178.sh
```

Script akan menjalankan Part 1, lalu berhenti dan menunggu Anda menekan ENTER setelah mengklik 3 checkpoint awal. Setelah Anda menekan ENTER, script lanjut otomatis ke Part 2.

### Opsi 2 (Eksplisit per fase)

Jalankan Part 1:
```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp178.sh | bash -s part1
```

Klik Check my progress pada 3 checkpoint pertama. Setelah hijau, jalankan Part 2:
```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp178.sh | bash -s part2
```

## Kenapa lab ini dibagi 2 fase

Task 5 menghapus `private-cluster`. Jika `private-cluster` dihapus sebelum Anda mengklik Check my progress untuk Task 2 dan Task 4, validator Qwiklabs tidak akan menemukan cluster tersebut dan poin tidak akan diberikan.

## Checkpoint yang dinilai

| Fase | Task | Aksi | Checkpoint |
|------|------|------|------------|
| Part 1 | 2 | `clusters create private-cluster` (master CIDR 172.16.0.16/28) | Create a private cluster |
| Part 1 | 4 | `instances create source-instance` | Create a VM instance |
| Part 1 | 4 | `clusters update private-cluster` (authorized natIP/32) | Authorize your external address range |
| Part 2 | 5 | `clusters delete private-cluster` | Delete the Kubernetes cluster |
| Part 2 | 6 | `subnets create my-subnet` (10.0.4.0/22 + secondary pod/svc) | Create a subnetwork and secondary ranges in us-west1 region |
| Part 2 | 6 | `clusters create private-cluster2` (subnetwork my-subnet) | Create a private cluster that uses your subnetwork |
| Part 2 | 6 | `clusters update private-cluster2` (authorized natIP/32) | Authorize your external address range for private cluster in custom subnetwork |

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| Checkpoint Task 2 merah setelah Part 2 | Anda belum mengklik checkpoint Task 2 sebelum Task 5 dijalankan. Pastikan klik 3 checkpoint pertama sebelum lanjut ke Part 2. |
| Pembuatan cluster memakan waktu lama | Cluster GKE private membutuhkan alokasi VPC peering dan node pool (~3-4 menit). Tunggu hingga proses create selesai. |
| Kuota region habis | Lab default menyediakan kuota di `us-west1-b`. Jika zone diubah, sesuaikan dengan instruksi panel lab. |
