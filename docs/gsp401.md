# GSP401 - Cloud Scheduler: Qwik Start

Runbook untuk [`gsp401.sh`](../gsp401.sh).

Semua langkah otomatis via `gcloud` CLI. Checkpoint lab hanya ada di Task 2 (10 poin).

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp401.sh
bash gsp401.sh
```

Atau one-liner:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp401.sh | bash
```

Region default adalah `us-east4` (mengikuti instruksi lab). Jika lab menggunakan region berbeda, isi via env var `REGION=<region>`.

Lama eksekusi: < 1 menit.

## Tabel Task

| Task | Otomatis | Keterangan |
|------|----------|------------|
| 1. Enable Cloud Scheduler API | Ya | `cloudscheduler.googleapis.com` & `pubsub.googleapis.com` |
| 2. Set up Cloud Pub/Sub | Ya | Topic `cron-topic` dan subscription `cron-sub` (Checkpoint 10 pts) |
| 3. Create a job | Ya | Cloud Scheduler job `cron-job` dengan target Pub/Sub |
| 4. Verify results in Cloud Pub/Sub | Ya | Trigger job manual & pull message via `gcloud pubsub subscriptions pull` |
| 5. Test your knowledge | Manual | Kuis (jawaban tertera di bawah) |

## Jawaban Kuis Task 5
