## Dua jebakan di Task 2

Diuji 2026-08-04. Percobaan pertama Task 3 hijau tapi Task 2 nol
(`Please create and deploy the cloud run function 'gcfunction' as specified in
the lab configuration`), padahal function-nya jelas ada dan bisa dipanggil.

1. **`gcloud functions deploy --gen2` tidak diterima.** Grader mencari Cloud Run
   service hasil alur "Cloud Run > Write a function". Service yang dibuat Cloud
   Functions ber-label `goog-managed-by: cloudfunctions` dan bentuknya beda.
   Yang dipakai: `gcloud run deploy <nama> --source=... --function=helloHttp
   --base-image=nodejs22`.
2. **`--execution-environment=gen2` wajib.** Lab minta "Execution environment:
   Second generation". Itu setting sandbox Cloud Run yang default-nya gen1, dan
   beda dari "gen2" milik Cloud Functions. Tanpa flag ini Task 2 tetap nol
   walau sudah deploy lewat `gcloud run deploy`.

Menambahkannya belakangan juga bisa, tanpa deploy ulang:

```bash
gcloud run services update gcfunction --region=asia-east1 --execution-environment=gen2
```

IAM `allUsers`/`roles/run.invoker` (Allow public access) bukan penyebabnya —
`--allow-unauthenticated` sudah mengurusnya sejak percobaan pertama.

Menghapus function di tengah lab aman: checkpoint Task 3 yang sudah hijau tetap
tersimpan.
