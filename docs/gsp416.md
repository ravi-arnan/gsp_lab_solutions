## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `Project belum di-set` | Jalankan `gcloud config set project <Project ID dari panel lab>`. |
| `Access Denied` / `Permission denied` | Kemungkinan login pakai akun pribadi, bukan akun student lab. |
| `Not found: Dataset ... was not found in location US` | Dataset terlanjur dibuat di location lain. Hapus (`bq rm -r -f -d <dataset>`) lalu jalankan ulang. |
| Berhenti di tengah | `set -e` menghentikan di error pertama, jadi baris terakhir output adalah penyebabnya. Script idempoten, aman diulang dari awal. |

## Catatan

Dua query yang sengaja dibuat error di lab (`['raspberry', ..., 1234567]` dan `SELECT visitId, hits.page.pageTitle`) tidak dimasukkan ke script, karena `set -euo pipefail` akan menghentikan eksekusi. Jalankan manual di BigQuery console kalau ingin melihat pesan errornya, itu bagian dari materi.
