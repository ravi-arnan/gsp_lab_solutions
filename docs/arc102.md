Nama topic menggantikan `REPLACE_WITH_YOUR_TOPIC ID` di baris 15 `index.js`,
disulam lewat heredoc yang menginterpolasi `$TOPIC`.

Deploy memakai `--trigger-bucket`, runtime `nodejs22`, dan gen1. Flag
`--trigger-resource` bersama `--trigger-event=google.storage.object.finalize`
juga valid untuk gen1, tetapi jalur ini mengikuti solver terbaru dan tidak
bergantung pada bentuk argumen trigger yang berbeda.

## Kenapa gen1, padahal ARC100 gen2

`--no-gen2` di sini bukan gaya lama yang tertinggal, melainkan syarat:

1. **Tanda tangan fungsinya gaya lama.** `exports.thumbnail = (event, context)`
   adalah background function gen1. Gen2 memakai CloudEvent
   (`functions.cloudEvent('nama', cloudEvent => ...)` seperti di ARC100), jadi
   kode lab apa adanya tidak akan jalan kalau dipaksa gen2.
2. **Kode lab memakai signature background function.** Gen2 menggunakan
   CloudEvent dan framework berbeda. Tetap gunakan gen1 agar `exports.thumbnail`
   dari lab menerima event Storage dengan bentuk yang sama. Jangan memaksa
   source ini ke gen2 hanya karena fungsi tersebut sekarang bisa memakai
   Node.js 22.

Perhatikan juga gen1 tidak butuh kerumitan IAM Eventarc seperti ARC100: trigger
`google.storage.object.finalize` memakai notifikasi GCS internal, bukan Eventarc,
jadi keempat binding di runbook ARC100 tidak diperlukan di sini.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| Log berisi `convert: not found` | Runtime/build function tidak menyediakan ImageMagick. Pastikan deploy memakai `--no-gen2` dan runtime yang didukung, lalu deploy ulang. |
| Deploy gagal di percobaan pertama | Cloud Build atau Artifact Registry belum siap. Script mengulang sekali setelah 60 detik. |
| Thumbnail tidak muncul | `gcloud functions logs read wild-thumbnail-maker --region=<region> --limit=20`. |
| Publish ke Pub/Sub gagal | Nama topic di `index.js` tidak cocok. Pastikan `TOPIC` persis seperti teks Task 2. |
