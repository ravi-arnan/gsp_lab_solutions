Runbook untuk [`arc100.sh`](../arc100.sh). Status: terverifikasi 100/100 (2026-08-21, us-east1).

## Sebelum jalan

1. Start lab, login pakai kredensial student, buka Cloud Shell.
2. Baca **Task 2**: nama topic berakhiran angka acak per instance
   (`memories-topic-251`, `memories-topic-618`, ...). Wajib diisi.
3. Nama bucket mengikuti pola `memories-bucket-<PROJECT_ID>`, jadi default script
   sudah benar. Cocokkan sekilas dengan teks Task 1.

## Jalankan

Butuh parameter, jadi download dulu.

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc100.sh
TOPIC=memories-topic-<NNN> bash arc100.sh
```

5-8 menit, hampir semuanya di deploy function karena `sharp` dikompilasi.

## Jebakan utama: service agent yang belum ada

Jalan perdana script ini gagal di sini:

```
ERROR: (gcloud.projects.add-iam-policy-binding) INVALID_ARGUMENT:
Service account service-<PN>@gcp-sa-pubsub.iam.gserviceaccount.com does not exist.
```

Google membuat service agent secara **malas** — akunnya belum ada sampai
layanannya benar-benar dipakai, dan mengaktifkan API saja tidak cukup. Jadi
`add-iam-policy-binding` menolak. Perbaikannya, sebelum grant:

```bash
gcloud beta services identity create --service=pubsub.googleapis.com
gcloud beta services identity create --service=eventarc.googleapis.com
```

Empat binding yang harus ada sebelum trigger Cloud Storage bisa dibuat:

| Service account | Role | Untuk apa |
|---|---|---|
| `service-<PN>@gs-project-accounts` | `roles/pubsub.publisher` | GCS boleh publish notifikasi object |
| `service-<PN>@gcp-sa-pubsub` | `roles/iam.serviceAccountTokenCreator` | Pub/Sub membuat token OIDC ke Cloud Run |
| `<PN>-compute@developer` | `roles/eventarc.eventReceiver` | function boleh menerima event |
| `<PN>-compute@developer` | `roles/run.invoker` | function boleh dipanggil |

Setelah grant, script menunggu 60 detik. Kalau deploy tetap gagal, ia menunggu
90 detik lagi dan mencoba sekali lagi — propagasi IAM ke Eventarc memang lambat.

trigger ketahuan di tempat.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `Service account ... does not exist` | Service agent belum dibuat. Sudah ditangani script; kalau muncul untuk agent lain, `gcloud beta services identity create --service=<api>`. |
| Deploy gagal `Permission denied while using Eventarc` | Binding IAM belum menyebar. Script mengulang sekali; kalau masih gagal, tunggu 2 menit lalu jalankan ulang script. |
| Thumbnail tidak muncul | Cek `gcloud functions logs read memories-thumbnail-maker --region=us-east1 --limit=20`. Log kosong berarti trigger Eventarc tidak terbentuk: `gcloud eventarc triggers list --location=us-east1`. |
| Function jalan tapi publish gagal | Nama topic di `index.js` tidak cocok. Pastikan `TOPIC` diisi persis seperti teks Task 2. |
