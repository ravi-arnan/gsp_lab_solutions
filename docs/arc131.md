# ARC131 - Using the Google Cloud Speech API: Challenge Lab

Runbook untuk [`arc131.sh`](../arc131.sh). Status: 100/100 tercapai 2026-08-21 (us-east4),
tapi checkpoint Task 1 butuh satu langkah tambahan — baca bagian terakhir.

## Sebelum jalan

Start lab, login student, buka Cloud Shell. Tidak ada parameter: zone `lab-vm`
dicari sendiri oleh script.

## Jalankan

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc131.sh | bash
```

1-2 menit. SSH pertama ke `lab-vm` akan membuat keypair dulu, itu normal.

## Temuan 1: `question_en.wav` itu stereo

Request Inggris tanpa `audioChannelCount` ditolak:

```
"Must use single channel (mono) audio, but WAV header indicates 2 channels."
```

Nilainya jadi 10/30 — file request-nya dihitung ada, transcript-nya tidak.
Perbaikannya satu field:

```json
{
  "config": {
    "languageCode": "en-US",
    "audioChannelCount": 2
  },
  "audio": { "uri": "gs://spls/arc131/question_en.wav" }
}
```

File Spanyolnya (`multi_es.flac`) mono, jadi tidak butuh field itu. `encoding`
dan `sampleRateHertz` tetap tidak diisi untuk keduanya: Speech API membaca header
WAV/FLAC di Cloud Storage sendiri, dan menebak angka yang salah malah menolak
request.

## Temuan 2: checkpoint API key tidak hijau dari key gcloud polos

Urutan yang benar-benar terjadi pada 2026-08-21:

1. Key dibuat `gcloud services api-keys create --display-name=arc131-key`.
   Key sah — Task 2 dan 3 memakainya dan dapat nilai penuh. Checkpoint 1: **0/30**.
2. Dibuat key kedua bernama `API key 1` (menyamai nama default console),
   masih lewat gcloud, tanpa restriction. Checkpoint 1: **tetap 0/30**.
   Jadi bukan soal display name.
3. Dibuat key lewat console lalu **Restrict key → Cloud Speech-to-Text API**.
   Checkpoint 1: **30/30**, total 100/100.

**Terjawab pada hari yang sama lewat [ARC114](arc114.md):** key `gcloud` yang
dibatasi dengan `--api-target` ke API labnya **tetap merah**, sedangkan key
console hijau. Jadi pemicunya adalah **pembuatan lewat console**, bukan
restriction-nya. Script tetap memasang `--api-target` (tidak merugikan), tapi
untuk checkpoint ini tempuh langsung jalur console:

**APIs & Services → Credentials → + Create credentials → API key → Restrict key
→ Cloud Speech-to-Text API → Save**, lalu klik Check my progress lagi.

Perlu satu kali jalan lagi di lab sungguhan untuk memastikan versi CLI-nya cukup.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `get-key-string ... 404` | `api-keys create` mengembalikan objek operation, bukan key. Script mengambil nama key lewat `api-keys list`; jangan pakai `--format=value(name)` pada create. |
| `response.json` berisi `INVALID_ARGUMENT` soal channel | Audio stereo, tambahkan `audioChannelCount`. |
| `VM lab-vm tidak ditemukan` | Nama VM beda di instance-mu. Jalankan `VM=<nama> bash arc131.sh`. |
| Checkpoint 1 merah padahal Task 2-3 hijau | Bukan key-nya yang salah. Ikuti jalur console di atas. |
