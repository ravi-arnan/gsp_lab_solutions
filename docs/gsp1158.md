# GSP1158 — Assessing Data Quality with Knowledge Catalog

Lab terakhir yang kurang untuk badge **681 Build a Data Mesh with Dataplex**.

**Skor maksimal yang bisa dicapai script ini: 60 dari 100.** Sisanya wajib manual,
dan itu batas arsitektural, bukan kekurangan script. Baca bagian di bawah sebelum jalan.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1158.sh
bash gsp1158.sh
```

Script berhenti empat kali menunggu ENTER. Jangan di-pipe ke `bash` — stdin-nya
dipakai untuk jeda itu.

Region dibaca dari metadata project. Override kalau tidak cocok:

```bash
REGION=europe-west1 bash gsp1158.sh
```

## Task

| Task | Isi | Poin | Otomatis |

| 1 | Create a lake, zone, and asset | 20 | ya |

## Kenapa Task 2 dan 5 tidak bisa diotomasi

Checkpoint keduanya memeriksa **job history BigQuery**, bukan perubahan state resource.
Job yang dijalankan dari Console ber-ID `bquxjob_...`; job dari `bq query` di Cloud Shell
ber-ID `bqjob_...`. Query yang isinya identik dan berhasil tetap dinilai 0 kalau
dijalankan dari shell.

Ini pola yang sama dengan [GSP1154](../README.md#lab-yang-tidak-cocok-diotomasi) di repo
ini: API call sukses, tapi artefak yang dicari checkpoint tidak pernah terbentuk.

Script tetap menjalankan kedua query lewat `bq` supaya kamu bisa melihat datanya, tapi
outputnya diberi label jelas bahwa itu **tidak** menghijaukan checkpoint.

Yang harus kamu kerjakan di Console:

- **Task 2** — BigQuery > SQL Editor:
  `SELECT * FROM \`PROJECT.customers.contact_info\` ORDER BY id LIMIT 50`
- **Task 5** — Preview tabel `customers_dq_dataset.dq_results`, salin isi kolom
  `rule_failed_records_query` (dua baris: email dan id), jalankan keduanya di SQL Editor.

Ini penyebab hampir semua script komunitas gagal.

## Satu rule memang harus GAGAL

Hasil yang benar adalah **1 dimension, 1 rule failed**:

- rule `id` → **gagal**, kolomnya 10% null lawan threshold 1.0
- rule `email` → lulus, ~10.5% invalid lawan threshold .85

Jangan perlakukan kegagalan itu sebagai error script.

## Detail kecil yang menggigit

**Jangan kirim `--discovery-enabled` saat membuat asset.** Teks lab menyetel Discovery
ke "Inherit". Beberapa script komunitas menambahkannya.

**Heredoc YAML harus di-quote** (`<<'EOF'`). Regex-nya mengandung `$` di ujung pola dan
`{1}` di tengah. Project ID disisipkan lewat `sed` setelahnya, bukan lewat expansion.

**Bucket `PROJECT-bucket` di-provision lab**, bukan dibuat script. Kalau belum ada,
script berhenti dengan pesan jelas — membuatnya sendiri berisiko salah region.
