# GSP976 - Optimizing Applications Using Cloud Profiler

Runbook untuk [`gsp976.sh`](../gsp976.sh).

Lab ini mempelajari teknik analisis bottleneck performa dan pengoptimalan aplikasi Go (`shakesapp`) menggunakan Cloud Profiler melalui visualisasi Flame Graph, optimalisasi siklus CPU (mengganti kompilasi `regexp.MatchString` berulang dengan `strings.Contains`), serta pengurangan alokasi heap berlebih (menerapkan in-memory caching pada operasi pembacaan file Storage).

## Alur Kerja

1. **Task 1: Enable the Cloud Profiler API**
   - Mengaktifkan layanan `cloudprofiler.googleapis.com` di Google Cloud project.
   - Penilaian: *Enable the Cloud Profiler API* (100 pts).

2. **Task 1b: Unduh dan Jalankan Sample Application**
   - Meng-clone repositori `GoogleCloudPlatform/golang-samples.git`.
   - Mengirim profil inisialisasi awal ke layanan Cloud Profiler.

3. **Task 3: Optimasi CPU Time**
   - Mengganti pemanggilan ekspresi reguler `regexp.MatchString(query, line)` dengan `strings.Contains(line, query)`.
   - Menghapus dependensi paket `regexp` untuk memangkas overhead siklus CPU.

4. **Task 6: Optimasi Allocated Heap**
   - Mendefinisikan slice global `var files []string` sebagai cache memori.
   - Mengubah fungsi `readFiles(...)` agar memeriksa status cache sebelum membaca ulang file teks dari Cloud Storage bucket.

5. **Task 7: Evaluasi dan Verifikasi Hasil**
   - Menjalankan versi teroptimasi (versi 4) dengan opsi heap profiling aktif (`-heap -heap_alloc`).
   - Throughput query melonjak dari <1 req/detik menjadi >15 req/detik.
