# GSP192 - Dataflow: Qwik Start - Templates

Runbook untuk [`gsp192.sh`](../gsp192.sh).

Semua checkpoint otomatis via `gcloud` dan `bq` CLI.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp192.sh
bash gsp192.sh
```

Atau one-liner:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp192.sh | bash
```

Region Dataflow default adalah `europe-west1` (mengikuti teks Task 4 di lab). Jika panel lab atau teks task menyebut region lain, sesuaikan saat prompt muncul atau isi via `REGION=<region>`.

Lama eksekusi: < 1 menit.

## Tabel Task

| Task | Otomatis | Keterangan |
|------|----------|------------|
| 1. Re-enable Dataflow API | Ya | `gcloud services disable ... --force` lalu `enable` (Checkpoint) |
| 2a. BigQuery dataset | Ya | `bq mk taxirides` (Checkpoint) |
| 2b. BigQuery table | Ya | `bq mk` table partitioned `realtime` dengan skema (Checkpoint) |
| 2c. Cloud Storage bucket | Ya | `gcloud storage buckets create gs://<PROJECT_ID>/` (Checkpoint) |
| 3. Console alternative | - | Dilewati (sudah selesai di Task 2) |
| 4. Run the pipeline | Ya | `gcloud dataflow jobs run iotflow` template PubSub_to_BigQuery (Checkpoint) |
| 5. Submit a query | Manual | Query BQ opsional / verifikasi data masuk |
| 6. Test your understanding | Manual | Kuis (jawaban tertera di bawah) |
