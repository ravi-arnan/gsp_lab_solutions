# GSP095 - Pub/Sub: Qwik Start - Command Line

Runbook untuk [`gsp095.sh`](../gsp095.sh). Dua checkpoint menilai pembuatan
`myTopic` dan `mySubscription`. Task publish dan pull dikerjakan untuk materi
pembelajaran, tetapi tidak menambah skor.

## Sebelum jalan

1. Start lab dan login memakai kredensial student dari panel lab.
2. Buka Cloud Shell. Pastikan project lab sudah aktif.
3. Publisher dan makanan default-nya `Ravi` dan `sate`. Saat `bash gsp095.sh`
   dijalankan dari terminal, script menanyakan keduanya. Kalau dijalankan lewat
   pipe atau `nohup`, script memakai default. Nilai juga bisa diset sebagai env
   var sebelum menjalankan script.

## Jalankan

Dari file yang sudah ada di Cloud Shell:

```bash
bash gsp095.sh
```

Dengan nilai publisher dan makanan sendiri:

```bash
PUBLISHER_NAME="Nama Kamu" FOOD="Makanan favorit" bash gsp095.sh
```

Kalau script diunduh dari repo:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp095.sh
bash gsp095.sh
```

## Yang dikerjakan script

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Pub/Sub topics | Ya | Membuat `myTopic`, `Test1`, `Test2`, lalu menghapus `Test1` dan `Test2` |
| 2. Pub/Sub subscriptions | Ya | Membuat `mySubscription`, `Test1`, `Test2`, lalu menghapus dua subscription sementara |
| 3. Publishing dan pull satu pesan | Ya | Publish 4 pesan, lalu pull dengan `--auto-ack`; pull kelima biasanya `Listed 0 items.` |
| 4. Pull semua pesan | Ya | Publish 3 pesan, lalu pull dengan `--limit=3`; hasil bisa perlu diulang setelah beberapa detik |
| Kuis | Manual | Jawaban: `True` |

## Checkpoint

Setelah script selesai, klik **Check my progress** untuk:

1. **Create a Pub/Sub topic**, nama resource harus `myTopic`.
2. **Create Pub/Sub Subscription**, nama resource harus `mySubscription`.

Task 3 dan Task 4 tidak memiliki checkpoint. Pesan yang sudah di-ack tidak
muncul lagi, dan pesan baru dapat membutuhkan beberapa detik untuk tersedia.
Kalau pull Task 4 masih kosong, ulangi manual memakai project yang sama:

```bash
PROJECT_ID="$(gcloud config get-value project)"
gcloud --project="$PROJECT_ID" pubsub subscriptions pull mySubscription --limit=3
```

## Idempotensi

Script mengecek topic dan subscription sebelum membuat, serta mengecek resource
sementara sebelum menghapus. Jadi Aman diulang jika gagal di tengah. Script
juga selalu meneruskan project ID ke perintah `gcloud`, sehingga tetap memakai
project lab yang benar.
