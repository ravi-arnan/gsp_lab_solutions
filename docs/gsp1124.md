# GSP1124 - Get Started with Security Command Center

Runbook untuk [`gsp1124.sh`](../gsp1124.sh). Status: **terverifikasi 100/100** (2026-11-10).

Lab pengenalan Security Command Center (SCC) untuk memantau kerentanan dan ancaman di Google Cloud.

## Analisis Checkpoint

Meskipun instruksi lab terdiri dari 3 task, **penilaian skor (100/100) seluruhnya berada pada Task 3**:
- Task 1: Eksplorasi antarmuka SCC dan trigger refresh metadata VPC (tanpa tombol Check my progress).
- Task 2: Konfigurasi modul SHA `VPC_FLOW_LOGS_SETTINGS_NOT_RECOMMENDED` di Console (tanpa tombol Check my progress).
- Task 3: Tiga checkpoint evaluasi:
  1. *Create a mute rule* (`mute-flowlogs-findings`)
  2. *Create a network* (`scc-lab-net`)
  3. *Update the firewall rules* (batasi SSH & RDP ke range IAP `35.235.240.0/20`)

Seluruh langkah yang dinilai dapat diselesaikan secara otomatis sekali jalan via Cloud Shell.

## Cara Menjalankan

Jalankan di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1124.sh
bash gsp1124.sh
```

Setelah script selesai, klik tombol **Check my progress** untuk:
1. Create a mute rule
2. Create a network
3. Update the firewall rules

Skor akan langsung penuh 100/100.

## Checkpoint

| Poin | Checkpoint | Status |
|-----:|-----------|--------|
| 30 | Create a mute rule | Otomatis via `gcloud scc muteconfigs` |
| 30 | Create a network | Otomatis via `gcloud compute networks create` |
| 40 | Update the firewall rules | Otomatis via `gcloud compute firewall-rules update` |

## Yang Dikonfigurasi

| Komponen | Nama | Nilai / Konfigurasi |
|----------|------|---------------------|
| Mute Config | `mute-flowlogs-findings` | Global, dynamic, filter `category="FLOW_LOGS_DISABLED"` |
| VPC Network | `scc-lab-net` | Auto-mode subnet |
| Firewall RDP | `default-allow-rdp` | Source range dibatasi ke `35.235.240.0/20` (Google IAP) |
| Firewall SSH | `default-allow-ssh` | Source range dibatasi ke `35.235.240.0/20` (Google IAP) |
