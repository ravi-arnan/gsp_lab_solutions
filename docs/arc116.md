## Checkpoint

- Task 1: `gs://<PROJECT>-redact/redact-response.txt` berisi hasil `content:deidentify` (bukan file kosong, harus mengandung `EMAIL_ADDRESS`/`US_HEALTHCARE_NPI` yang ter-redact).
- Task 2: dua `deidentifyTemplates` dengan `displayName` persis `structured_data_template` dan `unstructured_data_template`.
- Task 3: satu `jobTrigger` dengan `triggerId`/`displayName` `dlp_job`, `status HEALTHY`, `recurrencePeriodDuration 604800s`, `cloudStorageOutput gs://<PROJECT>-output`, dan `transformationConfig` menunjuk kedua template di atas.

## API yang dipakai

Semua `dlp.googleapis.com/v2`:

| Endpoint | Method | Untuk |
|----------|--------|-------|
| `projects/{p}/content:deidentify` | POST | Task 1 redact |
| `projects/{p}/locations/us/deidentifyTemplates` | POST | Task 2 (structured + unstructured) |
| `projects/{p}/locations/us/deidentifyTemplates/{id}` | DELETE | Idempoten |
| `projects/{p}/locations/us/jobTriggers` | POST | Task 3 |
| `projects/{p}/locations/us/jobTriggers/dlp_job:activate` | POST | Memicu run pertama |

## Catatan implementasi

1. **Bucket discovery.** Lab menulis `qwiklabs-gcp-04-xxxxx-redact/input/output` tapi instance nyata memakai `<PROJECT_ID>-redact`. Script mencari kedua pola lewat `gcloud storage buckets list` lalu fallback ke `<PROJECT_ID>-suffix`.
2. **Header `x-goog-user-project`.** DLP menolak ADC tanpa quota project. Script mengirim `x-goog-user-project: $PROJECT_ID` di semua call. Task 1 juga retry tanpa header kalau response kosong (beberapa proyek lab tidak butuh).
3. **Template idempoten.** `POST` akan 409 kalau `templateId` sudah ada. Script `DELETE` dulu keduanya, lalu `POST` ulang. Tidak memakai `PATCH` karena grader memeriksa `displayName` dan `deidentifyConfig` utuh.
4. **Mask all characters.** Cukup `characterMaskConfig: {maskingCharacter: "#"}`. `charactersToIgnore` tidak diisi (default = tidak ada yang diabaikan) sudah memenuhi "Enable mask all characters".
5. **Unstructured template.** Hanya `infoTypeTransformations` dengan `replaceConfig.newValue.stringValue: "[redacted]"`. Tidak perlu `recordTransformations` atau `inspectConfig`.
6. **Job trigger schedule.** `recurrencePeriodDuration: "604800s"` = 7 hari = Weekly. `filesLimitPercent: 100` = 100% objek, `fileSet.regexFileSet.bucketName` tanpa `gs://`.
7. **De-identify copy.** `transformationConfig.deidentifyTemplate` = unstructured, `structuredDeidentifyTemplate` = structured. Keduanya wajib, kalau tertukar grader Task 3 merah.
8. **Activate.** `jobTriggers:activate` membuat job run pertama tanpa menunggu jadwal mingguan. `hybridInspect` dicoba juga tapi diabaikan kalau error.
9. **Race IAM service agent.** Di `qwiklabs-gcp-04-422f95d2b1a4` (2026-09-03) `POST /jobTriggers` sukses `HEALTHY` tapi `errors[0]` = `PERMISSION_DENIED dlp.jobs.create` untuk `service-...@dlp-api.iam.gserviceaccount.com`, jadi `activate` pertama `403`. Grader baca `errors` juga, jadi Task 3 `0/40` walau trigger kelihatan `HEALTHY`. Student tidak bisa `setIamPolicy` (`Policy update access denied`). Fix: script sekarang auto-detect `403` di response `activate`, lalu `DELETE` + recreate trigger dan retry `activate` (tanpa `setIamPolicy`). Run kedua langsung `PENDING` (`dlpJobs/i-5483578807029352635`) dan 100/100.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `redact-response.txt` berisi `error` | DLP API belum aktif. `gcloud services enable dlp.googleapis.com`, tunggu 30 detik, jalankan ulang. |
| `PermissionDenied` / `x-goog-user-project` | Token belum punya quota project. Script sudah kirim header; kalau masih, `gcloud auth print-access-token` lalu cek `gcloud config get-value project`. |
| Template 409 Already Exists | Script seharusnya sudah DELETE dulu. Kalau masih, `curl -X DELETE .../deidentifyTemplates/<id>` manual lalu ulang. |
| Job trigger 409 | Sama, DELETE dulu. |
| Bucket not found saat upload | Lab belum selesai provisioning. `gcloud storage ls` untuk lihat nama aktual, lalu `gsutil cp redact-response.txt gs://<nama-yang-ada>/`. |
| Output bucket masih kosong | Job trigger weekly belum jalan. `activate` sudah dipanggil script; tunggu 1-2 menit lalu `gcloud storage ls gs://<PROJECT>-output/`. |
| `activate` 403 `dlp.jobs.create denied` / Task 3 `0/40` walau `HEALTHY` | Race grant service agent lab. `curl .../jobTriggers/dlp_job \| jq .errors`. Script terbaru auto-retry recreate; kalau masih, jalankan `bash arc116.sh` sekali lagi (recreate membersihkan `errors`). Jangan `gcloud projects add-iam-policy-binding` — student tidak punya `setIamPolicy`. |
