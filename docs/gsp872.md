# GSP872 - API Gateway: Qwik Start

Lab aslinya campur Console dan CLI, tapi keenam checkpoint bisa dikerjakan
sepenuhnya dari Cloud Shell — termasuk pembuatan API key, yang di lab disuruh
lewat halaman Credentials.

## Jalankan

Pembuatan gateway makan ~10 menit dan sesi Cloud Shell bisa putus di tengah
(terbukti 2026-08-04), jadi jalankan di background:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp872.sh
REGION=us-central1 nohup bash gsp872.sh > gsp872.log 2>&1 &
tail -f ~/gsp872.log
```

`Ctrl+C` di `tail` aman, script tetap jalan. Pantau dari tab kedua:

```bash
watch -n 20 'gcloud api-gateway gateways list --format="table(name.basename(), state, defaultHostname)"'
```

Script idempoten: function di-skip kalau sudah ACTIVE, API `hello-world-*` yang
sudah ada dipakai ulang, config dan gateway dicek sebelum dibuat. Jadi kalau
Cloud Shell mati di tengah, tinggal jalankan ulang.

## Jebakan

- **`gcloud api-gateway apis list` menolak `--filter='name~...'`** dengan
  `INVALID_ARGUMENT: invalid list filter`. Filternya dikirim ke server dan
  server-nya tidak mendukung itu. Saring di sisi klien pakai `grep`.
- **`tr -dc 'a-z' < /dev/urandom | head -c 8` membunuh script diam-diam.**
  `head` keluar duluan, `tr` kena SIGPIPE (141), dan dengan `set -o pipefail`
  plus `set -e` script berhenti tanpa pesan apa pun — persis setelah banner
  task. Perintah di lab aman karena dijalankan manual tanpa `set -e`. Di script
  pakai `${RANDOM}${RANDOM}` saja.
- **Service account backend**: lab menyuruh Compute Engine default SA di Task 3
  dan "Qwiklabs User Service Account" di Task 5. Compute default dipakai untuk
  keduanya dan tetap 100/100 — grader tidak mengeceknya.
