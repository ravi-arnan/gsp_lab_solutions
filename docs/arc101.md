## Catatan Arsitektur & Penjelasan Teknis

1. **Cloud Run Function Gen 2 & Eventarc Trigger**:
   - Lab meminta fungsi generasi kedua (`--gen2`) dengan runtime Node.js 22.
   - Pemicu Cloud Storage pada Cloud Functions Gen 2 berjalan di atas Eventarc. Script memastikan service agent GCS (`service-<PN>@gs-project-accounts...`) dan Pub/Sub memiliki izin yang memadai untuk memublikasikan event ke Eventarc dan menginvokasi Cloud Run.
   - Kode `index.js` mendukung penanganan CloudEvent dari Eventarc (`event.data`) maupun payload langsung tanpa modifikasi logic utama lab.
2. **Alerting Policy Metrik Serverless**:
   - Filter kondisi menggunakan `resource.type = "cloud_function" AND metric.type = "cloudfunctions.googleapis.com/function/active_instances"`.
   - Threshold ditetapkan `COMPARISON_GT` dengan nilai `0` sesuai instruksi "greater than zero (0)".
   - Script mendukung pembuatan kebijakan melalui `gcloud alpha monitoring`, `gcloud monitoring`, dan fallback REST API v3 secara otomatis.

## Troubleshooting

| Gejala | Sebab dan Solusi |
|--------|------------------|
| Task 1 belum centang | Pastikan `USER2` diisi persis dengan **Username 2** di panel kredensial lab, bukan Username 1. |
| Task 2 belum centang | Pastikan nama topic sesuai dengan angka acak di deskripsi Task 2 pada sesi lab Anda. |
| Deploy Task 3 gagal di awal | Propagasi IAM Eventarc membutuhkan waktu. Script sudah otomatis menunggu 60 detik dan mencoba ulang deploy. |
| Task 4 gagal | Pastikan nama policy adalah `Active Cloud Run Function Instances`. Jika dihapus manual, jalankan ulang script. |
