# ARC134 - Configure Service Accounts and IAM Roles for Google Cloud: Challenge Lab

Runbook untuk [`arc134.sh`](../arc134.sh). Status: skor 100/100 terverifikasi.

## Kenapa lab ini cocok di-script

Semua task berbasis `gcloud` CLI (service accounts, IAM bindings, compute instances, custom roles). Task 6 pakai Python BigQuery query yang dijalankan via SSH ke VM. Tidak ada UI-only checkpoint.

## Jalankan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc134.sh
bash arc134.sh
```

Satu fase, idempoten. Aman diulang kalau gagal di tengah (cek dulu sebelum create).

## Detail task

### Task 1: Service account 'devops'

```bash
gcloud iam service-accounts create devops --display-name=devops
```

### Task 2: IAM roles untuk 'devops'

```bash
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:devops@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/iam.serviceAccountUser"

gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:devops@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/compute.instanceAdmin"
```

### Task 3: VM 'vm-2'

```bash
gcloud compute instances create vm-2 \
  --machine-type=e2-micro \
  --service-account=devops@$PROJECT_ID.iam.gserviceaccount.com \
  --scopes=https://www.googleapis.com/auth/compute \
  --zone=$ZONE
```

### Task 4: Custom role

```yaml
# role-definition.yaml
title: Custom Role
description: Custom role with cloudsql permissions
includedPermissions:
- cloudsql.instances.connect
- cloudsql.instances.get
```

```bash
gcloud iam roles create customRole --project=$PROJECT_ID --file=role-definition.yaml
```

### Task 5: Service account 'bigquery-qwiklab' + VM

```bash
gcloud iam service-accounts create bigquery-qwiklab --display-name=bigquery-qwiklab

gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:bigquery-qwiklab@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/bigquery.dataViewer"

gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:bigquery-qwiklab@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/bigquery.user"

gcloud compute instances create bigquery-instance \
  --machine-type=e2-micro \
  --service-account=bigquery-qwiklab@$PROJECT_ID.iam.gserviceaccount.com \
  --scopes=https://www.googleapis.com/auth/cloud-platform \
  --zone=$ZONE
```

### Task 6: BigQuery Python query

Script dijalankan via SSH ke `bigquery-instance`. Pakai `google.auth.compute_engine.Credentials` untuk autentikasi menggunakan service account yang terpasang di VM. Query ke `bigquery-public-data.usa_names.usa_1910_2013` (state = TX, top 20).

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `service account already exists` | Idempoten, skip otomatis. |
| `instance already exists` | Idempoten, skip otomatis. |
| `role already exists` | Script update role yang sudah ada. |
| `PermissionDenied` di VM | IAM roles belum propagate. Tunggu 10-20 detik lalu jalankan ulang. |
| `bigquery-instance` belum siap | VM baru butuh ~30 detik untuk expose metadata. Script sudah pakai sleep 20. |
| SCP gagal ke `lab-vm` | `lab-vm` mungkin belum ada atau name berbeda. Non-fatal, task 4 tetap jalan via `gcloud iam roles`. |
