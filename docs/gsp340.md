# GSP340 - Build a Data Warehouse with BigQuery: Challenge Lab

Runbook untuk [`gsp340.sh`](../gsp340.sh). Status: terverifikasi 40/40, **satu varian task** (2026-07-16).

## Peringatan utama

Ini challenge lab. Tasknya **diacak per instance**, ditandai teks `Dynamically selected task will show up here...` di halaman lab. Nama dataset, tabel, dan kolom bisa berbeda dari yang kamu dapat.

**Cocokkan blok parameter di awal `gsp340.sh` dengan teks task di lab-mu sebelum jalan.** Kalau beda, ubah variabelnya, jangan query di bawahnya.

Varian yang sudah terverifikasi:

| Variabel | Nilai | Dari task |
|----------|-------|-----------|
| `DS_PARTITIONED` | `covid` | Task 1 |
| `DS_MAIN` | `covid_data` | Task 2, 3, 4 |
| `TBL_TRACKER` | `oxford_policy_tracker` | Task 1 |
| `TBL_AREA` | `country_area_data` | Task 2 |
| `TBL_MOBILITY` | `mobility_data` | Task 3 |
| `TBL_BY_COUNTRIES` | `oxford_policy_tracker_by_countries` | Task 4 |
| `EXPIRY_DAYS` | `2175` | Task 1 |

## Dua jebakan yang bikin orang tersesat

1. **Ada dua dataset berbeda, bukan satu.** Task 1 minta dataset `covid`, tapi Task 2, 3, dan 4 pakai `covid_data`. Namanya mirip, gampang terlewat.
2. **Task 4 menunjuk tabel yang tidak pernah kamu buat.** `oxford_policy_tracker_by_countries` tidak dihasilkan Task 1 sampai 3. Tabel itu **disiapkan lab**, makanya ada catatan "pre-created resources" di halaman task.

## Sebelum jalan

1. Start lab, login akun student, buka Cloud Shell.
2. Baca teks Task 1 sampai 4 di halaman lab, bandingkan dengan tabel parameter di atas.
3. Kalau ada yang beda, download dulu lalu edit, jangan langsung pipe ke bash.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `tabel covid_data.oxford_policy_tracker_by_countries belum ada` | Provisioning lab belum selesai. Tunggu sebentar, refresh halaman lab, jalankan ulang script. Bukan bug script. |
| `Not found: Dataset ... in location US` | Dataset `covid_data` dibuat lab di location lain. Cek dengan `bq show --format=prettyjson covid_data \| grep location`, lalu sesuaikan `LOCATION` di script. |
| Checkpoint task 1 merah padahal tabel ada | Cek partisi dan expiry-nya, bukan cuma isinya. Lihat tabel "Yang harus muncul" di atas. |
| Checkpoint merah dan nama tabelmu beda | Kamu kebagian varian task lain. Sesuaikan blok parameter. |

## Kalau kebagian varian lain

Varian GSP340 yang lain biasanya minta hal berikut, dan script ini **tidak** mengcovernya:

- `ALTER TABLE ... ADD COLUMN population, country_area` lalu populate dari `covid19_ecdc` dan `country_names_area` (join lewat kolom `country_name`, karena `country_names_area` tidak punya kode 3 huruf).
- Menambah kolom `mobility` bertipe RECORD, diisi rata-rata per kombinasi country dan date.
- Query gabungan pakai `UNION ALL`.

Tips 3 sampai 6 di halaman lab mengarah ke varian-varian itu.
