# GSP070 - App Engine: Qwik Start - Go

Runbook untuk [`gsp070.sh`](../gsp070.sh).

Lab ini mendemonstrasikan proses deployment aplikasi sederhana berbasis Go (runtime `go125`) ke Google App Engine Standard Environment menggunakan `gcloud CLI`, pengujian akses web, dan verifikasi ketersediaan layanan.

## Alur Kerja

1. **Task 1: Enable Google App Engine Admin API**
   - Mengaktifkan API `appengine.googleapis.com`.
   - Menginisialisasi App Engine application pada region yang sesuai (`us-west1` atau lainnya).

2. **Task 2: Download the Hello World app**
   - Menyiapkan berkas konfigurasi `app.yaml` dengan konfigurasi runtime modern `go125`.
   - Menyiapkan modul Go `go.mod` dan kode sumber `helloworld.go` yang menampilkan pesan `Hello, World!`.

3. **Task 3 & 4: Deploy your app**
   - Men-deploy aplikasi ke App Engine (`gcloud app deploy app.yaml -q`).
   - Melakukan uji respon HTTP ke domain App Engine (`https://<PROJECT_ID>.appspot.com`).
   - Penilaian: *Deploy your app* (Task 4).

## Cara Menjalankan

Jalankan langsung di terminal Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp070.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp070.sh
bash gsp070.sh
```

Region akan ditanyakan di awal (default `us-west1`). Cukup tekan `Enter` jika panel lab Anda sesuai.

Setelah script menampilkan banner `SELESAI!`, klik tombol **Check my progress** di panel lab:
- *Deploy your app*
