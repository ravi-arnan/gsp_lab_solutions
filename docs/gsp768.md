# GSP768 - Understanding and Combining GKE Autoscaling Strategies

Runbook untuk [`gsp768.sh`](../gsp768.sh). Status: **siap uji**.

Lab untuk mempelajari kombinasi strategi autoscaling pada Google Kubernetes Engine (GKE): Horizontal Pod Autoscaling (HPA), Vertical Pod Autoscaling (VPA), Cluster Autoscaler, Node Auto Provisioning (NAP), dan overprovisioning dengan Pause Pods.

## Alur Kerja

1. **Setup: Provision testing environment**
   - Menetapkan zone komputasi (default `us-east1-c`).
   - Membuat cluster `scaling-demo` (3 node, `--enable-vertical-pod-autoscaling`).
   - Menerapkan Deployment dan Service `php-apache`.
   - Penilaian: *Provision testing environment*.

2. **Task 1: Scale pods with Horizontal Pod Autoscaling**
   - Mengonfigurasi HPA pada deployment `php-apache` (target CPU 50%, min 1, max 10 replicas).
   - Penilaian: *Scale pods with Horizontal Pod Autoscaling*.

3. **Task 2: Scale size of pods with Vertical Pod Autoscaling**
   - Membuat deployment `hello-server` dengan request awal CPU 450m.
   - Menerapkan resource `VerticalPodAutoscaler` bernama `hello-server-vpa` dengan `updateMode: "Auto"`.
   - Melakukan scale deployment ke 2 replika dan menetapkan request target 25m sesuai rekomendasi lab.
   - Penilaian: *Scale size of pods with Vertical Pod Autoscaling*.

4. **Task 5: Cluster autoscaler**
   - Mengaktifkan cluster autoscaler pada `scaling-demo` (min 1, max 5 node).
   - Mengubah profil autoscaling menjadi `optimize-utilization`.
   - Menerapkan 10 Pod Disruption Budgets (PDB) pada pods `kube-system` agar autoscaler dapat melakukan reschedule dan men-scale down node.
   - Penilaian: *Cluster autoscaler*.

5. **Task 6: Node Auto Provisioning**
   - Mengaktifkan Node Auto Provisioning (NAP) dengan batas CPU (1-45) dan Memory (2-160 GB).
   - Penilaian: *Node Auto Provisioning*.

6. **Task 8: Optimize larger loads**
   - Menerapkan PriorityClass `overprovisioning` (prioritas -1).
   - Menerapkan Deployment `overprovisioning` (Pause Pods) di namespace `kube-system` dengan reservasi 1 CPU dan 4Gi Memory.
   - Penilaian: *Optimize larger loads*.


2. *Scale pods with Horizontal Pod Autoscaling*

4. *Cluster autoscaler*

6. *Optimize larger loads*
