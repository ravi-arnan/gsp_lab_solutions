# GSP1108 - Monitor an Apache Web Server using Ops Agent

Empat checkpoint, semuanya otomatis. Task 4 dan 6 (lihat dashboard, uji alert)
tanpa checkpoint.

## Jalankan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1108.sh
ZONE=us-east1-c bash gsp1108.sh
```

## Task

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Create a VM instance | Ya | `quickstart-vm`, e2-small, Debian 12, tag http-server + https-server |
| 2. Install an Apache Web Server | Ya | lewat SSH |
| 3. Install the Ops Agent | Ya | plus `config.yaml` receiver apache/apache_access/apache_error |
| 5. Create an alerting policy | Ya | REST `alertPolicies`, rate 1 menit, above 4000, autoclose 30 menit |
| 4, 6. Dashboard & uji alert | Manual | tanpa checkpoint |

## Catatan

- **Notification channel email** dibuat otomatis menggunakan akun aktif Cloud Shell dan di-link ke Alert Policy.
- **`php7.0` tidak ada di Debian 12**, pakai paket `php`. Instruksi lab sudah
  menyediakan jalan keluarnya.
- Metrics scope tidak perlu disiapkan manual di lab ini; pembuatan alerting
  policy lewat REST langsung diterima.
- Trafik 120 detik ikut digenerate supaya dashboard Apache Overview terisi dan
  metrik `workload.googleapis.com/apache.traffic` punya data.
