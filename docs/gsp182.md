# GSP182 - Distributed Load Testing Using Kubernetes

Runbook untuk [`gsp182.sh`](../gsp182.sh). Status: terverifikasi 100/100 (2026-11-16, us-east1/us-east1-c).

## Ringkasan Lab

Lab ini mengimplementasikan pengujian beban terdistribusi (Distributed Load Testing) menggunakan framework **Locust** yang dijalankan di atas **Google Kubernetes Engine (GKE)** untuk menguji performa backend web REST API sederhana di **Google App Engine**.

Arsitektur terdiri dari:
1. **Target Web App**: Aplikasi backend Python yang di-deploy ke App Engine (`sample-webapp/app.yaml`).
2. **Locust Master Pod & Service**: Pod tunggal sebagai koordinator dan web interface (port 8089) yang diekspos melalui LoadBalancer Service.
3. **Locust Worker Pods**: Deployment worker yang di-scale hingga 20 replika untuk menghasilkan traffic HTTP POST secara konkuren.

## Detail Teknis & Penanganan Kendala

- **Runtime Python App Engine Terbaru**: Mengubah runtime `python37` ke `python312` pada `app.yaml` sesuai update instruksi lab terbaru untuk menghindari error deployment App Engine legacy.
- **Nol Interaksi & Non-Blocking**: Otomasi pembuatan App Engine application menggunakan opsi non-interaktif `-q`, serta penanganan penamaan region App Engine (`us-central1` ke `us-central`, dll).
- **Idempoten**: Pemeriksaan ketersediaan GKE cluster sebelum pembuatan. Jika cluster sudah ada, script langsung mengambil kredensial `kubectl` tanpa mengulang pembuatan.
- **LoadBalancer IP Retrieval**: Loop penantian otomatis hingga external IP service Locust Master dialokasikan oleh GKE, sehingga siap diakses lewat browser.
