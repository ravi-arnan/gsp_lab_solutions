# GSP345 — Build Infrastructure with Terraform on Google Cloud: Challenge Lab

Challenge lab penutup untuk topik Terraform di Google Cloud. Mencakup import existing instance, konfigurasi custom module, remote backend di GCS, update/destroy resource, Terraform Registry VPC module (v10.0.0), dan firewall rule.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp345.sh
bash gsp345.sh
```

Atau one-liner langsung dengan suffix yang sesuai dengan teks tugas di panel lab Anda:

```bash
BUCKET_SUFFIX=852606 VPC_SUFFIX=821633 INSTANCE3_SUFFIX=298349 curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp345.sh | bash
```

Script otomatis mendeteksi zone dari `tf-instance-1` yang sudah ada di GCP atau metadata project. Jika dijalankan secara interaktif, script akan menanyakan suffix dan zone dengan nilai default yang siap pakai.

## Task

| Task | Isi | Checkpoint | Otomatis |
|------|-----|-----------|----------|
| 1 | Create the configuration files | Checkpoint | ya (struktur modules/instances dan modules/storage) |
| 2 | Import infrastructure | Checkpoint | ya (import tf-instance-1 dan tf-instance-2) |
| 3 | Configure a remote backend | Checkpoint | ya (GCS bucket tf-bucket-<suffix>, migrate state) |
| 4 | Modify and update infrastructure | Checkpoint | ya (update e2-standard-2, buat tf-instance-<suffix>) |
| 5 | Destroy resources | Checkpoint | ya (destroy tf-instance-<suffix>) |
| 6 | Use a module from the Registry | Checkpoint | ya (VPC module v10.0.0, tf-vpc-<suffix>, 2 subnets) |
| 7 | Configure a firewall | Checkpoint | ya (tf-firewall port 80 allow) |

Total: **100/100 poin** otomatis.

## Yang perlu diperhatikan

**Provider Google dan Versi Module VPC:**
Materi lab terbaru mensyaratkan Google Provider `~> 6.0` dan Network Module `10.0.0`. Keduanya saling kompatibel dan telah diselaraskan di seluruh blok HCL.

**Auto-detect Zone & Region:**
Zone otomatis diambil dari `tf-instance-1` yang sudah disiapkan oleh Qwiklabs sejak awal lab. Subnet VPC dan firewall rule otomatis menggunakan region yang sesuai dengan zone tersebut.

**Suffix Dinamis:**
Lab ini mengacak suffix untuk nama bucket, VPC, dan instance ke-3. Script menyediakan nilai default terbaru (`852606`, `821633`, `298349`) yang dapat di-override lewat env var atau prompt interaktif.
