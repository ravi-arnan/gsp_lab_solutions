# GSP156 — Terraform Fundamentals

Lab introductory untuk pengenalan Terraform di Google Cloud. Satu checkpoint, satu VM.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp156.sh
bash gsp156.sh
```

Atau one-liner langsung dengan zone spesifik (misalnya `us-east1-c`):

```bash
ZONE=us-east1-c curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp156.sh | bash
```

Script otomatis membaca zone dari metadata project (`google-compute-default-zone`) atau `gcloud config`. Jika tidak terdeteksi, prompt interaktif `ask` akan menanyakan zone dengan default `us-east1-c`.

## Yang perlu diperhatikan

**Cloud Shell placeholder wrapper:** Di Google Cloud Shell, command `terraform` secara bawaan adalah dummy wrapper script yang selalu keluar dengan exit code 0 dan hanya mencetak instruksi instalasi. Oleh karena itu, pengecekan instalasi wajib memvalidasi output `terraform --version | grep 'Terraform v'`, bukan sekadar `command -v terraform`.

**Jangan pin versi provider.** Lab sengaja tidak memakai blok `provider` maupun `required_providers`. `terraform init` akan mengunduh provider Google versi terbaru secara otomatis.

**`machine_type` = `e2-medium`.**

**Image `debian-12`.** Materi lab terbaru telah diperbarui ke Debian 12.

**Resource name Terraform:** Blok resource memakai `resource "google_compute_instance" "default"` dengan atribut `name = "terraform"`.

**Idempotensi:** Jika VM `terraform` sudah terlanjur dibuat di GCP namun state lokal belum mencatatnya, script otomatis melakukan `terraform import` sebelum apply.

**Script pakai direktori `~/gsp156`**, bukan home langsung, agar terisolasi dari file `.tf` lab lain.
