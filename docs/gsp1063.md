# GSP1063 - Finding Data in Google Sheets

Runbook manual. **Tidak ada script** — lab ini seluruhnya di Google Sheets, tidak menyentuh Google Cloud sama sekali. Status: belum diuji.

## Kenapa tidak bisa di-script, dan kenapa Gemini tidak menolong

Tidak ada `gcloud`, tidak ada Cloud Shell. Checkpoint membaca isi spreadsheet di Drive akun student.

Gemini di Sheets **tidak bisa menulis ke sel tertentu**. Side panel-nya membuat tabel/template dan membantu menyusun rumus, tapi tidak mengeksekusi "isi K3 dengan rumus ini". Seluruh pekerjaan lab ini cuma 9 sel — tempel manual selesai dalam 3 menit, memandu Gemini justru lebih lama.

## Semua yang perlu diketik

Buka **On the Rise Bakery Bulk Orders** dari Drive. Urutannya wajib: Task 2 memakai kolom hasil Task 1.

### Task 1 — SPLIT dan TRANSPOSE

| Sheet | Sel | Isi |
|-------|-----|-----|
| Bulk Orders | `B1` | `=SPLIT(A1, ",")` |
| New Order | `A8` | `=TRANSPOSE(A1:A7)` |

1. Setelah `B1`, isi ke bawah: klik `B1`, **klik dua kali** kotak biru kecil di pojok kanan bawah sel. (Atau blok `B1:B100` lalu **Ctrl+D**.)
2. Klik kanan label kolom **A** → **Hide column**.
3. Ke sheet **New Order**, isi `A8`, lalu **salin `A8:G8`**.
4. Balik ke **Bulk Orders**, klik `B101`, tempel dengan **Ctrl+Shift+V** (Paste values only). Kalau memakai Ctrl+V biasa, klik ikon clipboard yang muncul → **Paste values only**.

Paste values only itu wajib — kalau rumusnya ikut tertempel, referensinya pindah dan nilainya kacau.

### Task 2 — find/replace dan SUBSTITUTE

1. **Ctrl+F** → **More options**
   - Find: `Muffin`
   - Replace with: `Blueberry Muffin`
   - Search: **This sheet**
   - **Replace all** → **Done**

| Sel | Isi |
|-----|-----|
| `I1` | `Adjusted Delivery Date` |
| `I2` | `=SUBSTITUTE(F2,"Nov-6","Nov-7")` |

Isi `I2` ke bawah sampai `I101`.

### Task 3 — VLOOKUP dan QUERY

| Sheet | Sel | Isi |
|-------|-----|-----|
| Bulk Orders | `J2` | `Georgia Nkosi` |
| Bulk Orders | `K2` | `=VLOOKUP(J2, G2:I100, 3, False)` |
| Discount | `A1` | `=QUERY('Bulk Orders'!$B$2:$I$100, "select H where E > 500")` |

Sheet **Discount** dibuat sendiri: **+** di kiri bawah → klik kanan namanya → **Rename** → `Discount`.

Bagian opsional (ubah `500` jadi `750`) **kerjakan setelah checkpoint Task 3 hijau**. Instruksi labnya menyebut "at least $500", jadi biarkan 500 dulu saat diperiksa.

### Task 4 — IFERROR dan ISERROR

Ketik berurutan, jangan dilompati — labnya sengaja menyuruh melihat dua pesan error yang berbeda.

| Sel | Isi | Hasil |
|-----|-----|-------|
| `J3` | `Alexander Jorgenson` | |
| `K3` | `=VLOOKUP(J3, B2:I100)` | `#N/A`, error "Wrong number of arguments" |
| `K3` | `=VLOOKUP(J3, B2:I100, 8)` | `#N/A`, error baru |
| `K4` | `=ISERROR(K3)` | `TRUE` |
| `K3` | `=IFERROR(VLOOKUP(J3, B3:I100, 8), "Record not found")` | `Record not found`, dan `K4` jadi `FALSE` |

**Jawaban kuis** ("Which of the following is the new error message?"):
> Did not find value 'Alexander Jorgenson' in VLOOKUP evaluation.

Pesan `Wrong number of arguments to VLOOKUP...` itu pesan **pertama**, sebelum argumen `8` ditambahkan — jebakan pilihan gandanya di situ.
