# ARC117 - Organize and Govern Data with Knowledge Catalog: Challenge Lab

Runbook untuk [`arc117.sh`](../arc117.sh). Status: belum diuji di lab sungguhan.

## Peringatan utama

**Task 3 kemungkinan besar butuh UI.** Aspect harus ditempel ke **zone**, bukan tabel BigQuery. Di [GSP514](gsp514.md) hal yang sama gagal karena zone Dataplex tidak muncul sebagai entry di entry group `@dataplex`, dan menunggu tidak menolong. Script tetap mencoba (murah, non-fatal), lalu mencetak langkah UI-nya kalau gagal. Aspect type sendiri tetap dibuat otomatis.

**Region `europe-west1`** sesuai instruksi lab, dan **bucket harus bernama sama dengan Project ID**. Keduanya default script.

## Sebelum jalan

1. Start lab, login akun student, buka Cloud Shell.
2. Cek kalimat "Create all resources in the ... region" — kalau bukan `europe-west1`, override.
3. Cek nama bucket yang diminta di Task 2; biasanya persis Project ID.

## Jalankan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc117.sh
bash arc117.sh
```

Satu fase, tidak ada delete. Lake ~3 menit, zone dan asset masing-masing ~2 menit.

## Yang dibuat

| Task | Resource | ID | Display name | Catatan |
|------|----------|-----|--------------|---------|
| 1 | Lake | `customer-engagements` | Customer Engagements | |
| 1 | Zone | `raw-event-data` | Raw Event Data | RAW, SINGLE_REGION |
| 2 | Bucket | `<Project ID>` | - | uniform bucket-level access |
| 2 | Asset | `raw-event-files` | Raw Event Files | STORAGE_BUCKET, discovery inherit |
| 3 | Aspect type | `protected-raw-data-aspect` | Protected Raw Data Aspect | field enum `protected-raw-data-flag` (Protected Raw Data Flag), nilai `Y` dan `N` |

Field enum-nya sengaja **tanpa** `constraints.required` — lab tidak memintanya (beda dengan GSP1145 yang eksplisit "Is Required").

## Sisa Task 3 lewat UI

Kalau output terakhir bilang aspect belum menempel:

1. Knowledge Catalog > **Discover > Search**.
2. Cari `Raw Event Data` (atau **Filters > Systems** > Dataplex).
3. Klik entry zone **Raw Event Data**.
4. Scroll ke **Aspects**, di sebelah **Optional aspects** klik **Add**.
5. Ketik `protected raw data`, pilih **Protected Raw Data Aspect**.
6. **Protected Raw Data Flag** pilih **Y**, klik **Save**.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `403 dataplex.lakes.create denied` | Propagasi permission setelah API di-enable. Tunggu 1-2 menit, jalankan ulang (idempoten). |
| Bucket `409 already exists` (dimiliki orang lain) | Nama bucket global. Pastikan nama = Project ID persis seperti yang diminta lab. |
| Checkpoint Task 2 merah padahal asset ada | Bucket dibuat di region lain. Bucket dan zone harus se-region. |
| Entry zone tidak ketemu di `@dataplex` | Diharapkan. Kerjakan sisa Task 3 lewat UI di atas. |
| Checkpoint Task 3 merah setelah UI | Butuh beberapa menit sebelum terdeteksi. Tunggu, klik lagi. |
