# GSP1043 - Consuming Customer Specific Datasets from Data Sharing Partners using BigQuery

Tiga project dengan kredensial berbeda, ditambah satu langkah verifikasi di
akhir — total empat fase. Ketiga checkpoint otomatis penuh.

## Jalankan

Urutannya mengikat: publisher butuh tabel dari partner, customer butuh view
dari publisher.

```bash
# 1. Cloud Shell Data Sharing Partner — Task 1
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1043.sh
PUBLISHER_USER=student-...@qwiklabs.net \
CUSTOMER_USER=student-...@qwiklabs.net \
bash gsp1043.sh partner

# 2. Cloud Shell Data Publisher — Task 2
PARTNER_PROJECT=qwiklabs-gcp-... \
CUSTOMER_USER=student-...@qwiklabs.net \
bash gsp1043.sh publisher

# 3. Cloud Shell Customer (Data Twin) — Task 3
PUBLISHER_PROJECT=qwiklabs-gcp-... bash gsp1043.sh customer

# 4. Kembali ke Cloud Shell Partner — Task 4, tanpa checkpoint
bash gsp1043.sh insert
```

Isi lewat env var, jangan menjawab prompt satu per satu — lebih kecil peluang
salah ketik project ID.

## Task

| Task | Fase | Catatan |
|------|------|---------|
| 1. Created an Authorized Table | partner | `bq query --destination_table`, authorize dataset, dataViewer untuk dua user |
| 2. Authorized view di Data Publishing project | publisher | view filter `state_code="NY"`, authorize view, dataViewer untuk customer |
| 3. Access the authorized view as a Data Twin | customer | join dengan `customer_info`, simpan jadi `customer_table` |
| 4. Confirm functionality | insert | INSERT satu baris di partner; tanpa checkpoint |

## Catatan

- **Dua bentuk otorisasi yang berbeda** dipakai di lab ini, keduanya lewat
  `bq show --format=prettyjson` → tambah entry `access[]` → `bq update --source`:
  - Task 1 "Authorize datasets": entry `{"dataset": {"dataset": {...},
    "targetTypes": ["VIEWS"]}}`
  - Task 2 "Authorize views": entry `{"view": {projectId, datasetId, tableId}}`

  Helper `authorize_entry()` di script menerima keduanya dan idempoten.
- **Task 4 tidak dinilai**, tapi tetap disediakan sebagai fase `insert` karena
  itu inti demonstrasi Data Twin: baris baru di project partner langsung
  terlihat dari project customer tanpa menyalin data.
- Berbeda dari [gsp1042](gsp1042.md), lab ini tidak menyentuh Looker Studio,
  jadi 100/100 bisa dicapai sepenuhnya lewat script.
