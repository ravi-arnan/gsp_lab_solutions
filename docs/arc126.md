# ARC126 - Develop with Apps Script and AppSheet: Challenge Lab

Runbook manual. **Tidak ada script** — semuanya UI (AppSheet, Apps Script, Cloud Console, Google Chat). Tidak ada satu pun task yang bisa dikerjakan dari Cloud Shell: konfigurasi Chat API tidak punya API publik, dan checkpoint membaca artefak UI. Status: **belum diuji di lab sungguhan**.

Empat checkpoint:

| Checkpoint | Task |
|------------|------|
| Create and customize an AppSheet app | 1 |
| Add an automation to an AppSheet app | 2 |
| Create an Apps Script chat bot | 3 |
| Configure the OAuth consent screen | 3 |

Task 1 dan 2 adalah versi ringkas [GSP1146](gsp1146.md) — kalau sudah pernah mengerjakan lab itu, jalurnya sama. **Tapi teks first message-nya berbeda satu kata**, lihat di bawah.

## Aturan dasar

- **Incognito, akun student lab saja.** AppSheet, Apps Script, Cloud Console, dan Google Chat harus satu akun yang sama.
- Ganti setiap `student-XX-xxxx@qwiklabs.net` di bawah dengan **User Email dari panel lab**.
- Challenge lab tidak menyebut langkah "buat space di Google Chat", padahal Task 2 membutuhkannya (automation harus punya Space ID tujuan). Kerjakan Task 2a di bawah lebih dulu.

## Task 1 — AppSheet app

1. Buka **ATM Maintenance app** lewat tautan di halaman lab → menu kiri **Copy app**.
2. App name: `ATM Maintenance Tracker`, sisanya default → **Copy app**.
3. Menu kiri → **Chat apps** → **Create** → kartu **Enable** → **Next**.
   **Jangan reload halaman** selama konfigurasi otomatis berjalan (beberapa menit). Reload di tengah proses merusak project Chat yang dibuat otomatis dan mode konfigurasinya tidak bisa diganti.
4. Kartu **Customize** → **First message** → ganti teks jadi persis:

   ```
   Welcome to the ATM Maintenance Tracker app. What would you like to do today?
   ```

   **Perhatikan: `What would you like to do today?`** — GSP1146 memakai `What do you want to do today?`. Kalau kamu menyalin dari runbook lab sebelumnya, checkpoint bisa gagal.
5. Masih di Customize → **Actions** → **+ New action** → **Slash command: Open app view**:

   | Field | Isi |
   |-------|-----|
   | App View | `Issues Reported By Me` |
   | Name | `/myissues` |
   | Description | `Lists tickets that include your email address` |

   → **Next** → **Save**.
6. **Deploy** (lab menyuruh eksplisit: *"Be sure to deploy your app"*). Menu kiri → **Manage** → **Run deployment check**. Kalau App description WARNING: **Settings → Information → App Properties** → Function `Maintenance`, Industry `Financial Services` → **Save** → jalankan ulang deployment check → **Move app to deployed state**.

**Check my progress** — *Create and customize an AppSheet app*.

Tanpa deploy, app tidak muncul di Google Chat dan Task 2 mentok.

## Task 3 — Apps Script chat bot

Urutannya penting: enable API → link project → deploy → baru konfigurasi Chat API.

### 3a. Enable Google Chat API

Cloud Console (project lab) → **APIs & Services** → aktifkan **Google Chat API**.

### 3b. OAuth consent screen

**APIs & Services → OAuth consent screen** (di UI baru: **Google Auth Platform → Branding**) → **Get Started**:

| Field | Isi |
|-------|-----|
| App name | `Helper Bot` |
| User support email | `student-XX-xxxx@qwiklabs.net` |
| Audience | **Internal** |
| Contact information | `student-XX-xxxx@qwiklabs.net` |

Centang persetujuan kebijakan → **Create**.

Ini checkpoint tersendiri (*Configure the OAuth consent screen*), jadi boleh diverifikasi sekarang.

### 3c. Project Apps Script

1. Buka [script.google.com](https://script.google.com) → **New project** dari template **Chat app**. Kalau template tidak muncul, buat project kosong dan tempel kode di bawah ke `Code.gs`.
2. Rename project jadi `Helper Bot` (klik judul "Untitled project" kiri atas).
3. Kodenya (template biasanya sudah berisi ini):

   ```javascript
   function onMessage(event) {
     var name = "";

     if (event.space.type == "DM") {
       name = "You";
     } else {
       name = event.user.displayName;
     }

     var message = name + ' said "' + event.message.text + '"';

     return { "text": message };
   }

   function onAddToSpace(event) {
     var message = "";

     if (event.space.singleUserBotDm) {
       message = "Thank you for adding me to a DM, " + event.user.displayName + "!";
     } else {
       message = "Thank you for adding me to " +
           (event.space.displayName ? event.space.displayName : "this chat");
     }

     if (event.message) {
       message = message + ' and you said: "' + event.message.text + '"';
     }

     return { "text": message };
   }

   function onRemoveFromSpace(event) {
     console.info("Bot removed from ",
         (event.space.name ? event.space.name : "this chat"));
   }
   ```

4. **Project Settings** (ikon gerigi) → **Google Cloud Platform (GCP) Project** → **Change project** → tempel **project number** lab (Cloud Console → Home, bukan project ID) → **Set project**.

   **Ini jebakan utama Task 3.** Project Apps Script default memakai project Cloud tersembunyi milik Apps Script. Kalau tidak dipindahkan ke project lab, Deployment ID-nya tidak dikenali oleh Chat API di project lab dan bot tidak akan pernah membalas.

5. **Deploy → Test deployments** → salin **Head Deployment ID** → **Done**.
   Bukan *New deployment*. Yang diminta lab adalah Head Deployment ID dari test deployment.

### 3d. Konfigurasi Chat API

Cloud Console → **APIs & Services → Google Chat API → Configuration**:

| Field | Isi |
|-------|-----|
| App name | `Helper Bot` |
| Avatar URL | `https://goo.gl/kv2ENA` |
| Description | `Helper chat bot` |
| Functionality | centang **Join spaces and group conversations** |
| Connection settings | **Apps Script** + tempel Head Deployment ID |
| Visibility | specific people/groups → `student-XX-xxxx@qwiklabs.net` |
| App Status | **LIVE – available to users** |

**Save.**

### 3e. Uji

Google Chat → **New chat** → cari **Helper Bot** → kirim pesan apa saja. Bot harus membalas dengan mengulang pesanmu.

**Check my progress** — *Create an Apps Script chat bot*.

## Kalau checkpoint macet

| Gejala | Kemungkinan |
|--------|-------------|
| Task 1 tidak hijau | Teks first message tidak persis (`would you like`, bukan `do you want`), atau app belum di-deploy. |
| Task 2 tidak hijau | Automation belum di-Save saat tiket Freeda dibuat, atau Space ID belum diisi. Buat tiket baru setelah Save. |
| Helper Bot tidak muncul di pencarian Chat | App Status belum LIVE, atau Visibility belum berisi email student. |
| Helper Bot muncul tapi diam | Project Apps Script belum dipindah ke project Cloud lab (langkah 3c.4), atau Deployment ID yang ditempel bukan Head Deployment ID. |
| Bot balas error izin | Google Chat API belum di-enable di project lab. |
