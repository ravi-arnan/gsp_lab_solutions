# GSP382 - Mitigate Threats and Vulnerabilities with Security Command Center: Challenge Lab

Runbook untuk [`gsp382.sh`](../gsp382.sh). Status: **siap uji**.

Challenge lab untuk menguji kecakapan implementasi mitigasi ancaman dan kerentanan menggunakan Security Command Center (SCC), Web Security Scanner (WSS), dan Cloud Storage.

## Alur Kerja

1. **Task 1: Configure the environment**
   - Eksplorasi antarmuka SCC Findings dengan filter Last 180 days (tidak ada penilaian skor).

2. **Task 2: Create static mute rules for Cymbal Bank**
   - Membuat tiga mute rules:
     - `muting-flow-log-findings` (kategori `FLOW_LOGS_DISABLED`)
     - `muting-audit-logging-findings` (kategori `AUDIT_LOGGING_DISABLED`)
     - `muting-admin-sa-findings` (kategori `ADMIN_SERVICE_ACCOUNT`)
   - Menerapkan mute pada temuan yang cocok.
   - Penilaian: *Create static mute rules for Cymbal Bank* (25 pts).

3. **Task 3: Fix Cymbal Bank's high vulnerability findings**
   - Memperbarui firewall rules SSH (port 22) dan RDP (port 3389) yang terbuka ke internet (`0.0.0.0/0`) agar dibatasi ke range Google IAP `35.235.240.0/20`.
   - Penilaian: *Fix Cymbal Bank's high vulnerability findings* (25 pts).

4. **Task 4: Run a Web Security Scan**
   - Mendeteksi instance `cls-vm` dan external IP-nya.
   - Mempromosikan external IP menjadi static IP dengan nama `static-ip`.
   - Membuat scan config pada Web Security Scanner yang menargetkan `http://<IP>:8080` dan memulai scan run.
   - Penilaian: *Run a Web Security Scan* (25 pts).

5. **Task 5: Export Cymbal Bank Findings to Google Cloud Storage**
   - Membuat Cloud Storage bucket regional `scc-export-bucket-$PROJECT` di lokasi `us-central1`.
   - Mengambil seluruh temuan SCC dan mengunggahnya sebagai `findings.jsonl` (format JSONL).
   - Penilaian: *Export Cymbal Bank Findings to Google Cloud Storage* (25 pts).

## Detail Teknis

- **Pencadangan Mute Rule STATIC/DYNAMIC:** Script mencoba pembuatan mute config dengan `--type=STATIC`. Jika ditolak oleh API versi tertentu, otomatis dialihkan ke `--type=DYNAMIC`.
- **Ekspor JSONL:** Pengolahan file `findings.jsonl` menggunakan parser Python standar untuk memastikan format JSON Lines valid satu baris per rekaman finding.
