## Jalankan manual (100/100 terverifikasi)

Semua command dijalankan **di dalam `lab-vm` via SSH**, bukan Cloud Shell.

### Task 1: Create an API key

Bikin di Console: APIs & Services -> Credentials -> + Create credentials ->
API key. Application restrictions: None. **API restrictions: pilih Cloud
Natural Language API DAN Cloud Speech-to-Text API** (kalau lupa Speech, Task 3
dapat `API_KEY_SERVICE_BLOCKED`).

### Task 2: Entity analysis

```bash
nano nl_request.json
```

```json
{
  "document":{
    "type":"PLAIN_TEXT",
    "content":"With approximately 8.2 million people residing in Boston, the capital city of Massachusetts is one of the largest in the United States."
  },
  "encodingType":"UTF8"
}
```

```bash
curl -s -X POST -H "Content-Type: application/json" \
  --data-binary @nl_request.json \
  "https://language.googleapis.com/v1/documents:analyzeEntities?key=API_KEY" \
  -o nl_response.json
```

Catatan: `--data-binary @nama_file` (dengan `@` di depan nama file) menandai
file lokal. `curl nl_request.json` tanpa `@` dan tanpa `-d` membuat curl
mengira itu URL dan gagal resolve host.

### Task 3: Speech analysis

```bash
nano speech_request.json
```

```json
{
  "config": {
      "encoding":"FLAC",
      "languageCode": "en-US"
  },
  "audio": {
      "uri":"gs://cloud-samples-tests/speech/brooklyn.flac"
  }
}
```

Kesalahan umum: isi `uri` sempat diisi teks placeholder "Pass the API the uri
of the audio file..." yang bikin JSON jadi salah field dan error `400 Cannot
find field`. Ganti dengan URI Cloud Storage yang bener.

```bash
curl -s -X POST -H "Content-Type: application/json" \
  --data-binary @speech_request.json \
  "https://speech.googleapis.com/v1/speech:recognize?key=API_KEY" \
  -o speech_response.json
```

### Task 4: Sentiment analysis

Unduh sample review:

```bash
gsutil cp gs://cloud-samples-tests/natural-language/sentiment-samples.tgz .
gunzip -f sentiment-samples.tgz
tar -xf sentiment-samples.tar
ls reviews/
```

`sentiment_analysis.py` sudah ada di home tapi fungsi `analyze()` **masih kosong**
(cuma docstring). Lengkapi:

```bash
python3 - <<'EOF'
import re
src = open("sentiment_analysis.py").read()

body = '''def analyze(movie_review_filename):
    """Run a sentiment analysis request on text within a passed filename."""
    client = language_v1.LanguageServiceClient()

    with open(movie_review_filename, "r") as review_file:
        content = review_file.read()

    document = language_v1.Document(content=content, type_=language_v1.Document.Type.PLAIN_TEXT)
    annotations = client.analyze_sentiment(request={"document": document})

    print_result(annotations)
'''

m = re.search(r"^def analyze\(movie_review_filename\):.*?(?=^\S|\Z)", src, re.S | re.M)
open("sentiment_analysis.py", "w").write(src[:m.start()] + body + "\n" + src[m.end():])
print("analyze() selesai diisi.")
EOF
```

Jalankan (venv `env` lab sudah berisi `google-cloud-language`):

```bash
source env/bin/activate
python3 sentiment_analysis.py reviews/bladerunner-pos.txt
```

Output berhasil: `Overall Sentiment: score of 0.2 with magnitude of 4.6`.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| Task 1 merah | Key buatan gcloud tidak menghijaukan checkpoint. Bikin lewat console. |
| `curl: (6) Could not resolve host: nl_request.json` | `curl nama_file` tanpa `@` dan tanpa `-d`; curl anggap itu URL. Pakai `--data-binary @file`. |
| `400 Cannot find field ... at 'audio'` | Isi `uri` masih teks placeholder. Ganti jadi `"gs://cloud-samples-tests/speech/brooklyn.flac"`. |
| `403 API_KEY_SERVICE_BLOCKED` | API key di-restrict tapi Speech API tidak dicentang. Tambahkan Cloud Speech-to-Text API di API restrictions. |
| `ModuleNotFoundError: No module named 'google'` | `google-cloud-language` belum terpasang. `source env/bin/activate` lalu `pip install google-cloud-language`. |
| SSH gagal | VM baru butuh ~30 detik untuk expose SSH. Script retry 5x. |
| `reviews/` kosong | Tgz gagal unduh. Cek koneksi atau unduh manual: `gsutil cp gs://cloud-samples-tests/natural-language/sentiment-samples.tgz .` |
