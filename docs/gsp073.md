# GSP073 - Cloud Storage: Qwik Start - Google Cloud Console

Runbook untuk [`gsp073.sh`](../gsp073.sh). Status: terverifikasi 100/100 sekali jalan (2026-08-21, europe-west1).

Versi console dari [GSP074](gsp074.md). Lab-nya beda cara, tapi yang dinilai sama-sama
hasil akhirnya di Cloud Storage — bukan apakah kamu mengkliknya di UI.

## Sebelum jalan

1. Start lab, login pakai kredensial student.
2. Buka Cloud Shell.
3. Cek Location di teks Task 1. Default script `europe-west1`.
4. Nama bucket memakai Project ID, sesuai saran lab. Bisa ditimpa dengan `BUCKET=<nama>`.

## Jalankan

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp073.sh | bash
```

## Yang dikerjakan script

| Task | Aksi | Checkpoint |
|------|------|------------|
| 1 | `buckets create` — Region, `STANDARD`, uniform access, public access prevention off | ✅ Create a bucket |
| 2 | upload `kitten.png` | ✅ Upload an object into the bucket |
| 3 | IAM bucket `allUsers` → `roles/storage.objectViewer` | ✅ Share a kitten.png object publicly |
| 4 | `folder1/folder2/kitten.png` | tidak ada checkpoint |
| 5 | hapus bucket — fase `cleanup` | tidak ada checkpoint |

## Dua detail yang menentukan checkpoint 3

- **Bucket dibuat `--uniform-bucket-level-access`**, sesuai teks lab. Karena uniform,
  ACL per-object tidak berlaku lagi — share-nya wajib lewat IAM di level bucket
  (`buckets add-iam-policy-binding`). Ini kebalikan GSP074 yang memakai
  `objects update --add-acl-grant` pada bucket fine-grained.
- **`--no-public-access-prevention` dipasang sejak create.** Lab menyuruh mencentang-
  mati "Enforce public access prevention". Tanpa itu grant `allUsers` ditolak dan
  checkpoint 3 tidak akan pernah hijau.

Script mencetak hasil `curl` ke URL publik object. Harus **HTTP 200** sebelum
checkpoint diklik.

## Task 4 dan 5

Task 4 tidak dinilai tapi murah, jadi tetap dijalankan: di Cloud Storage "folder"
hanyalah prefix nama object, sehingga satu `cp` ke `folder1/folder2/` membuat
keduanya muncul di console.

Task 5 menghapus seluruh bucket — persis yang dinilai ketiga checkpoint. Dipisah:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp073.sh
bash gsp073.sh cleanup
```

## Klik manual

Tiga checkpoint di atas. Pilihan ganda (tidak masuk skor): nama bucket unik
se-namespace — **True**; nama object unik hanya di dalam bucket — **True**.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| Grant `allUsers` ditolak `... public access prevention` | Bucket dibuat tanpa `--no-public-access-prevention`, atau org policy memaksanya. Jalankan ulang script; Task 1 akan meng-update bucket yang sudah ada. |
| Cek akses publik balas `HTTP 403` | IAM binding belum menyebar. Tunggu belasan detik lalu ulangi `curl`-nya. |
| `409 already exists` | Nama bucket (= Project ID) dipakai orang lain. `BUCKET=<nama-lain> bash gsp073.sh`. |
