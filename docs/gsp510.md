# GSP510 - Manage Kubernetes in Google Cloud: Challenge Lab

Enam checkpoint, semuanya otomatis. Lab penutup badge 783.

## Jalankan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp510.sh
bash gsp510.sh
```

Script menanyakan nilai yang diacak per peserta — salin dari blok "Set up
environment variables" di halaman lab: `CLUSTER_NAME`, `ZONE`,
`NAMESPACE_NAME`, `SERVICE_NAME`.

## Jeda yang disengaja

Script berhenti dua kali dan menunggu Enter:

1. **Setelah Task 4.** Task 5 memperbaiki deployment yang rusak, jadi
   checkpoint Task 3 harus diklik selagi state-nya masih `InvalidImageName`.
2. **Setelah Task 5**, sebelum build Docker.

## Task

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Create a GKE cluster | Ya | release channel regular, 3 node, autoscaling 2-6 |
| 2. Enable Managed Prometheus | Ya | + namespace, prometheus-app, pod-monitoring |
| 3. Deploy an application | Ya | sengaja masih pakai image `<todo>` yang error |
| 4. Logs-based metric + alerting policy | Ya | `pod-image-errors`, `Pod Error Alert` |
| 5. Update and re-deploy | Ya | ganti image, delete, apply ulang |
| 6. Containerize + deploy | Ya | main.go v2.0.0, docker push v2, expose LoadBalancer |

## Dua jebakan (diuji 2026-08-05, awalnya 75/100)

### Managed Prometheus: jangan dilewati walau sudah `True`

Cluster yang baru dibuat melaporkan
`monitoringConfig.managedPrometheusConfig.enabled = True` sejak awal, jadi
versi pertama script melewati langkah `update`. Grader tetap menolak:
**15/20, "Please enable Managed Prometheus on the cluster"**. Setelah

```bash
gcloud container clusters update $CLUSTER_NAME --zone $ZONE --enable-managed-prometheus
```

dijalankan, checkpoint langsung penuh. Jadi perintahnya sekarang dijalankan
tanpa syarat — idempoten, ~1 menit.

### Nama container adalah `hello-app`, bukan `helloweb`

`kubectl set image deployment/helloweb helloweb=$IMAGE` gagal dengan
`error: unable to find container named "helloweb"`. Karena `set -e`, script
berhenti **diam-diam tepat setelah `docker push`** — Task 6 nol tanpa pesan
error yang jelas di akhir output. Sekarang dipakai wildcard:

```bash
kubectl set image deployment/helloweb -n $NS "*=$IMAGE"
```
