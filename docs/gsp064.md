# GSP064 - Manage Access Control with IAM

Runbook untuk [`gsp064.sh`](../gsp064.sh).

Semua checkpoint dieksekusi secara otomatis dari terminal Cloud Shell milik **Username 1** (Project Owner), tanpa harus login ke browser tab kedua atau melakukan klik manual di Google Cloud Console.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp064.sh
bash gsp064.sh
```

Atau one-liner:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp064.sh | bash
```

Script akan otomatis mendeteksi email **Username 2** dari IAM policy project. Tekan Enter saat prompt konfirmasi muncul.

Lama eksekusi: < 15 detik.

## Tabel Task

| Task | Otomatis | Keterangan |
|------|----------|------------|
| 1. Explore IAM console | - | Eksplorasi role primitif (tanpa checkpoint) |
| 2. Prepare Cloud Storage bucket | Ya | Buat bucket `gs://<PROJECT_ID>-bucket` & upload `sample.txt` (Checkpoint) |
| 3. Remove project access | Ya | Cabut `roles/viewer` dari Username 2 via CLI (Checkpoint) |
| 4. Add Cloud Storage permissions | Ya | Berikan `roles/storage.objectViewer` ke Username 2 via CLI (Checkpoint) |

## Catatan

- Semua operasi IAM dijalankan oleh Username 1 yang memiliki wewenang `roles/owner` (`resourcemanager.projects.setIamPolicy`).
- **`--condition=None` pada Mutasi IAM**: Policy IAM project lab ini memiliki *condition* (pembatasan kurikulum). Karena itu, perintah `add-iam-policy-binding` dan `remove-iam-policy-binding` secara non-interaktif wajib menyertakan flag `--condition=None` agar tidak ditolak gcloud.
- Checkpoint Task 2, Task 3, dan Task 4 dapat langsung diklik sekaligus di halaman lab setelah script selesai berjalan.
