# GSP038 - Entity and Sentiment Analysis with the Natural Language API

Tiga checkpoint: API key, `request.json`, `result.json`. Dua yang terakhir
dinilai dari file **di dalam VM `linux-instance`**, bukan di Cloud Shell.

## Jalankan

Bikin API key lewat console dulu (APIs & Services → Credentials → Create
credentials → API key, restriction: Cloud Natural Language API), lalu:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp038.sh
API_KEY=<key-dari-console> bash gsp038.sh
```

Script mengirim satu script remote lewat `gcloud compute scp` dan
menjalankannya via SSH — pola yang sama dengan [arc132](../arc132.sh).

## Task

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Create an API Key | Manual | lewat console; key buatan gcloud tidak diandalkan (lihat catatan arc132) |
| 2. Make an Entity Analysis Request | Ya | `request.json` di home VM |
| 3. Check the Entity Analysis response | Ya | `result.json`, divalidasi harus memuat entity `Joanne Rowling` |
| 4-7. Sentiment, entity sentiment, syntax, multibahasa | Ya | tanpa checkpoint, dijalankan sebagai bukti |

## Catatan

- **`request.json` sengaja tidak ditimpa oleh Task 4-7.** Instruksi lab
  menyuruh mengedit ulang file yang sama, tapi kalau checkpoint Task 2 diklik
  belakangan, isinya sudah bukan permintaan entity analysis lagi. Script pakai
  `request-extra.json` untuk Task 4-7 sehingga urutan klik tidak berpengaruh.
- Fallback pembuatan key lewat `gcloud` tetap disediakan supaya script bisa
  jalan tanpa argumen, tapi hanya untuk memanggil API.
