# GSP694 - gcloud for Network Configuration

Runbook untuk [`gsp694.sh`](../gsp694.sh).

Lab ini berfokus pada manajemen konfigurasi jaringan VPC di Google Cloud menggunakan `gcloud CLI`, mencakup inspeksi jaringan dan subnetwork kustom (`labnet` dan `privatenet`), pembuatan aturan firewall ALLOW (`labnet-allow-internal`) dan DENY (`privatenet-deny`), serta pengujian konektivitas traffic ICMP/SSH ke instance VM.

## Alur Kerja

1. **Task 1-3: Inspeksi VPC Networks & Subnets**
   - Melihat daftar jaringan VPC (`gcloud compute networks list`).
   - Memeriksa deskripsi jaringan `labnet` dan `privatenet`.
   - Menampilkan daftar dan detail subnetwork (`labnet-sub` dan `private-sub`).

2. **Task 4-5: Buat Firewall Rule labnet-allow-internal**
   - Membuat firewall rule `labnet-allow-internal` pada network `labnet`.
   - Mengizinkan protokol ICMP dan TCP port 22 dari source range `0.0.0.0/0`.
   - Penilaian: *Add firewall rules to allow tcp:22 and ICMP* (Checkpoint 1).

3. **Task 6: Buat Firewall Rule privatenet-deny**
   - Membuat firewall rule `privatenet-deny` pada network `privatenet`.
   - Menolak (DENY) traffic ICMP dan TCP port 22 dari source range `0.0.0.0/0`.
   - Penilaian: *Create deny firewall rules* (Checkpoint 2).

4. **Task 7-8: Eksplorasi Konektivitas VM**
   - Mendata instance VM `lnet-vm` dan `pnet-vm`.
   - Menguji ping ke IP publik masing-masing VM untuk memvalidasi perbedaan perilaku rule ALLOW vs DENY.

## Cara Menjalankan

Jalankan langsung di terminal Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp694.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp694.sh
bash gsp694.sh
```

Script akan mendeteksi zona dari instance `lnet-vm`/`pnet-vm` yang sudah ada secara otomatis. Cukup tekan `Enter` jika zona yang terdeteksi cocok dengan panel lab Anda.

Setelah script menampilkan banner `SELESAI!`, klik kedua tombol **Check my progress** di panel lab:
1. *Add firewall rules to allow tcp:22 and ICMP*
2. *Create deny firewall rules*
