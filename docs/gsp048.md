# GSP048 - Transkripsi Speech-to-Text dengan Speech-to-Text API

Runbook untuk [`gsp048.sh`](../gsp048.sh). Status: belum diuji di lab sungguhan.

## Sebelum jalan

Start lab, login student, buka Cloud Shell. Task 1 (API key) **manual**:

1. Navigation menu > APIs & Services > Credentials
2. Create credentials > API key
3. Di bagian "APIs that can be accessed using this key", pilih restriction
   **Cloud Speech-to-Text API**, OK, Create
4. Salin kuncinya

## Jalankan

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp048.sh | bash
```

Kalau dijalankan via `curl | bash`, stdin bukan terminal sehingga prompt
API_KEY tidak bisa dibaca. Set dulu sebelum menjalankan:

```bash
export API_KEY="<kunci dari console>"
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp048.sh | bash
```

Alternatif: download dulu (`curl -sLO ...`), lalu `bash gsp048.sh` dan jawab
prompt-nya.

## Yang dikerjakan script

| Task | Aksi | Checkpoint |
|------|------|------------|
| 1 | Manual: API key dengan restriction Speech-to-Text | |
| 2 | `request.json` bahasa Inggris (`en-US`, brooklyn_bridge.flac) | |
| 3 | `curl` ke `speech:recognize`, hasil di `result.json`, transcript `how old is the Brooklyn Bridge` | |
| 4 | `request.json` diganti Prancis (`fr`, corbeau_renard.flac), curl lagi | |

Script mengecek `result.json` mengandung `"transcript"` setelah tiap pemanggilan,
jadi gagal grader kelihatan dari output.

## Troubleshooting

- `API key not valid` atau `REQUEST_DENIED`: pastikan key di-restrict ke
  Cloud Speech-to-Text API dan API-nya sudah enabled (script melakukan
  `gcloud services enable speech.googleapis.com` sendiri).
- `result.json` tidak ada `transcript`: lihat isinya, biasanya error dari API
  (key salah atau API belum enabled).
