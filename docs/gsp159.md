# GSP159 - Create a Custom Network and Apply Firewall Rules

Runbook untuk [`gsp159.sh`](../gsp159.sh). Status: siap dijalankan di live lab Cloud Shell Qwiklabs.

## Kenapa lab ini cocok di-script

Lab ini berfokus pada pembuatan arsitektur jaringan aman dengan VPC custom mode. Melalui konsol UI, pembuatan 1 custom VPC, 3 subnet di 3 region berbeda, dan 5 firewall rules memakan waktu dan rentan salah ketik pada parameter target-tags atau IP range. Script ini mengotomasi seluruh provisioning dalam waktu kurang dari 1 menit.

## Sebelum jalan

1. Start lab di Google Cloud Skills Boost / Qwiklabs, login dengan kredensial student.
2. Buka Cloud Shell.
3. Cocokkan region di Task 1 dengan default script:
   - Region 1: `us-east4`
   - Region 2: `europe-west4`
   - Region 3: `us-central1`

## Jalankan

Di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp159.sh
bash gsp159.sh
```

Waktu estimasi: ~30-60 detik.

## Troubleshooting

| Gejala | Sebab dan Solusi |
|--------|------------------|
| Checkpoint Task 1 belum hijau | Cek apakah region di sesi lab Anda berbeda dari default (`us-east4`, `europe-west4`, `us-central1`). Jika berbeda, jalankan dengan `REGION_1=... REGION_2=... REGION_3=... bash gsp159.sh`. |
| Firewall rule konflik atau sudah ada | Script dirancang idempoten; rule yang sudah ada akan dilewati. Jika ingin memperbarui, hapus rule spesifik lalu jalankan ulang script. |
