## Yang harus manual (Task 3)

Task 3 meminta kamu:
1. Buka Sensitive Data Protection > Discovery > Scan Configurations
2. Klik Looker untuk buka dashboard
3. Authorize akses ke BigQuery
4. Review summary dan asset details
5. Identifikasi infoType US_SOCIAL_SECURITY_NUMBER

Tidak ada checkpoint di-score untuk Task 3, jadi cukup buka halaman Looker lalu lanjut.

## Checkpoint

- Task 1: Create and schedule a scan configuration
- Task 2: Modify the existing inspection template and create a de-identify template
- Task 4: Create and run an inspection job
- Task 5: Create and run a de-identify job

## API yang dipakai

Semua menggunakan `dlp.googleapis.com/v2`:

| Endpoint | Method | Untuk |
|----------|--------|-------|
| `projects/{p}/locations/global/inspectTemplates` | POST | Buat template inspection |
| `projects/{p}/locations/global/inspectTemplates/{id}` | PATCH | Update template |
| `projects/{p}/locations/global/deidentifyTemplates` | POST | Buat template de-identify |
| `projects/{p}/locations/global/discoveryConfigs` | POST | Buat discovery scan |
| `projects/{p}/locations/global/dlpJobs` | POST | Jalankan inspection/de-identify job |
| `projects/{p}/locations/global/dlpJobs/{id}` | GET | Poll status job |

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| Discovery config gagal dibuat | API `dlp.googleapis.com` belum aktif. Tunggu ~1 menit lalu jalankan ulang. |
| Job inspection/de-identify FAILED | Cek `gcloud dlp jobs describe <job-name>` untuk detail error. |
| BigQuery table kosong | Job belum selesai atau tidak ada data yang cocok di bucket input. |
| Bucket input/output tidak ada | Lab belum selesai provisioning. Tunggu 1-2 menit lalu jalankan ulang. |
| `PermissionDenied` | Akun belum punya role DLP. Lab seharusnya sudah memberikan role otomatis. |
