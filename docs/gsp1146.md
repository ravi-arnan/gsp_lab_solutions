# GSP1146 - Develop No-Code Chat Apps with AppSheet

Runbook manual. **Tidak ada script** — seluruhnya di UI AppSheet dan Google Chat, tidak menyentuh Cloud Shell atau `gcloud`. Durasi lab 15 menit (timer biasanya 1 jam), 3 checkpoint. Status: **belum diuji langsung**, tapi seluruh alur AppSheet-nya (copy app, enable Chat, first message, slash command, deploy, space, automation) terverifikasi lewat [ARC126](arc126.md) pada 2026-08-08 — lab itu memakai langkah yang sama.

Sekeluarga dengan [GSP1154](gsp1154.md): checkpoint membaca artefak yang dibuat lewat UI produk (di sini: app AppSheet + baris spreadsheet di Drive akun student), jadi tidak ada jalur API yang menghasilkan poin. Klik manual, tidak lama.

## Aturan dasar

- **Wajib incognito.** Login AppSheet dan Google Chat harus pakai akun student lab (`student-...@qwiklabs.net`). Kalau akun pribadi ikut tercampur, app dibuat di Drive yang salah dan checkpoint tidak menemukan apa pun.
- **Jangan Delete App sebelum tiga checkpoint hijau.** Langkah terakhir lab menyuruh menghapus app; itu bagian dari cerita, bukan syarat nilai. Hapus setelah skor 100/100.
- Checkpoint: *Create the app* (Task 1), *Test the app* (Task 4), *Build an automation* (Task 5). Task 2 dan 3 tidak punya checkpoint sendiri tapi wajib dikerjakan — tanpa deploy (Task 3) app tidak muncul di Google Chat.

## Task 1 — Copy app dan enable Chat

1. Dari halaman lab, buka tautan **ATM Maintenance app** di tab baru (masih di sesi incognito yang sama).
2. Menu kiri → **Copy app**.
3. App name: `ATM Maintenance Tracker`. Sisanya default. → **Copy app**.
   Spreadsheet sumbernya ikut tersalin ke `My Drive/appsheet/data/ATMMaintenanceTracker-nnnnnnn`.
4. Menu kiri → **Chat apps** (ikon chat) → **Create**.
5. Di kartu **Enable**, klik **Next** (mode automatic configuration).
6. **Tunggu sampai selesai, jangan reload halaman.** Konfigurasi otomatis ini membuat project Chat API di belakang layar dan butuh beberapa menit. Reload di tengah proses adalah cara paling umum merusak Task 1 — mode konfigurasi tidak bisa diganti setelah terlanjur dibuat, harus hapus project atau kontak support.

**Check my progress** — *Create the app*. Kalau belum hijau, tunggu sebentar lagi; kartu Enable belum tentu benar-benar selesai walau UI sudah pindah.

## Task 2 — Customize

**First message:**

1. Kartu **Customize** → **First message**.
2. Ganti teks sapaan jadi:
   `Welcome to the ATM Maintenance Tracker app. What do you want to do today?`
3. Di daftar Chat card menu: klik **My Tickets** → ganti jadi **Issues Reported By Me**.
4. Hapus **Manage Techs** (ikon delete).
   Peringatan *Unsupported app view selected* itu normal — view yang tidak didukung tetap muncul di menu tapi membuka tab baru, bukan render di dalam Chat.
5. **Save** (kanan atas).

**Slash command:**

1. Bagian **Actions** → **+ New action** → **Slash command: Open app view**.
2. App View: **Issues Reported By Me**
3. Name: `/myissues`
4. Description: `Lists tickets that include your email address`
5. **Next**, lalu **Save**.

**Kuis lab:** *Which of the following is NOT an option in the Customize section?* → jawabannya **Search**. Bagian Customize hanya punya First message, Actions, dan Replies.

## Task 3 — Deployment check dan publish

Deployment check pasti memberi WARNING di App description. Urutannya:

1. Kartu **Test** → **Go to deployment settings** → **Run Deployment Check** kalau tidak jalan sendiri.
2. **App description** → **Continue editing**.
3. Menu kiri → **Settings** → tab **Information** → App Properties:
   - Function: **Maintenance**
   - Industry: **Financial Services**
4. **Save**.
5. Menu kiri → **Manage** → **Run deployment check** lagi → App Description berubah PASSED.
6. **Move app to deployed state**.

Tanpa langkah 6 app tidak akan muncul di daftar **View apps** Google Chat, dan Task 4 mentok.

## Task 4 — Uji di Google Chat

1. Tab incognito baru → [Google Chat](https://mail.google.com/chat), akun student yang sama.
2. Spaces → **Create or find a space** → **Create a space** → beri nama → **Create**.
3. **View apps** → pilih **ATM Maintenance Tracker** → **Add** → **Install app**.
4. Di kartu app: **Open in app** di sebelah **All Tickets** → **New Ticket**.
5. Isi form:

   | Field | Isi |
   |-------|-----|
   | First Name / Last Name | bebas |
   | ATM ID | `ABC123` |
   | Email | **email student lab** (yang dipakai login AppSheet) |
   | Symptom | `Card reader not working` |
   | Resolved | `N` |

   Email harus persis email lab. Kalau salah, tiket tidak masuk hitungan "issues reported by me" dan `/myissues` balik kosong.
6. **Save**.
7. Ketik `/myissues` di kolom balasan → Enter, pastikan tiketnya muncul.

**Check my progress** — *Test the app*.

## Task 5 — Automation

Kembali ke tab AppSheet → **Chat apps** → kartu **Customize** → **+ New action** → **Build my own...** (halaman Automation terbuka di tab yang sama).

**Event:**

1. **Configure event** → **Create a new event**
2. Event name: `New ticket`
3. Data change type: centang **Adds** saja (hilangkan Updates/Deletes — kalau ikut tercentang, edit tiket lama juga memicu pesan)
4. Table: **Tickets**

**Step:**

1. **+ Add a step** → **Create a new step** → klik **New step** untuk buka Settings
2. Pilih **Send a chat message**
3. Message Content: **Select chat spaces**
4. Space ID(s) → **Add** → pilih space yang dibuat di Task 4
5. Message Text: `You have created a new ticket.`
6. **Save** (kanan atas)

**Uji:** balik ke Google Chat, **New Ticket** lagi, First Name `Freeda`, ATM ID dan Symptom bebas → **Save**. Pesan konfirmasi harus muncul di space.

**Check my progress** — *Build an automation*.

## Penutup

Setelah 100/100: **Manage** → **Collaborate & Publish** → **Delete App**.

## Kalau checkpoint macet

| Gejala | Kemungkinan |
|--------|-------------|
| Task 1 tidak hijau | Kartu Enable belum benar-benar selesai, atau halaman sempat di-reload saat konfigurasi otomatis. Tunggu; kalau tetap gagal, app harus dibuat ulang. |
| App tidak ada di **View apps** | Belum **Move app to deployed state** (Task 3), atau Google Chat dibuka dengan akun berbeda. |
| `/myissues` kosong | Kolom Email di tiket bukan email student lab. |
| Task 5 tidak hijau | Automation belum di-**Save**, atau tiket `Freeda` dibuat sebelum automation disimpan. Buat satu tiket lagi setelah Save. |
