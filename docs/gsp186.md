# GSP186 - App Dev: Adding User Authentication to your Application - Python

Runbook untuk [`gsp186.sh`](../gsp186.sh). Status: siap dijalankan di live lab Cloud Shell Qwiklabs.

## Kenapa lab ini cocok di-script

Lab ini memadukan persiapan environment Python Quiz application (App Engine, Cloud Storage bucket, Datastore entities) dengan integrasi Google Cloud Identity Platform (Firebase Authentication). Mengonfigurasi Identity Platform lewat Google Cloud Console memerlukan banyak navigasi dan klik manual (menambah provider Email/Password, authorized domain, dan membuat user). Script ini mengotomasi provisioning via REST API `identitytoolkit.googleapis.com` dan mengeksekusi persiapan Datastore hanya dalam waktu ~1 menit.

## Sebelum jalan

1. Start lab di Google Cloud Skills Boost / Qwiklabs, login dengan kredensial student.
2. Buka Cloud Shell.
3. Region default terdeteksi otomatis dari zone sesi aktif (misal `us-east4`).

## Jalankan

Di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp186.sh
bash gsp186.sh
```

Waktu estimasi: ~1 menit.

## Yang dikerjakan script

| Task | Aksi | Checkpoint |
|------|------|------------|
| 1 | Inisialisasi database Datastore mode `(default)` dan App Engine | ✅ Configure the case study application |
| 1 | Buat bucket `gs://${PROJECT_ID}-media` | ✅ Configure the case study application |
| 1 | Unduh starter code ke `~/firebase/start`, buat virtualenv Python, dan jalankan `python add_entities.py` untuk mengisi entitas Datastore | ✅ Configure the case study application |
| 3 | Inisialisasi Identity Platform via REST API (`initializeAuth`) | ✅ Configure Identity Platform Authentication |
| 3 | Aktifkan provider Email / Password (`signIn.email`) | ✅ Configure Identity Platform Authentication |
| 3 | Tambahkan authorized domains (`localhost`, `cloudshell.dev`, `${PROJECT_ID}.firebaseapp.com`) | ✅ Configure Identity Platform Authentication |
| 3 | Buat user autentikasi `user1@example.com` (`abc123!`) dan `user2@example.com` (`abcd1234$`) | ✅ Configure Identity Platform Authentication |
| 4 | Ambil Browser API Key dan suntikkan markup konfigurasi Firebase ke `index.html` | — (Client integration) |

## Klik Manual

Setelah script selesai:
1. Klik **Check my progress** pada **Task 1** (Configure the case study application).
2. Klik **Check my progress** pada **Task 3** (Configure Identity Platform Authentication).

*(Opsional)* Jika ingin mencoba login langsung di browser web preview:
```bash
cd ~/firebase/start
source ~/venvs/developingapps/bin/activate
python run_server.py
```
Buka Web Preview di port `8080` dan masuk menggunakan akun `user1@example.com` dengan password `abc123!`.

## Troubleshooting

| Gejala | Sebab dan Solusi |
|--------|------------------|
| Checkpoint Task 1 belum hijau | Pastikan database Datastore mode sudah aktif dan `add_entities.py` berhasil dieksekusi tanpa error. Jalankan ulang script jika Datastore terlambat merespons. |
| Checkpoint Task 3 belum hijau | Pastikan service `identitytoolkit.googleapis.com` aktif dan user `user1@example.com` terdaftar. Script sudah mendaftarkan user secara langsung via REST API akun Identity Platform. |
