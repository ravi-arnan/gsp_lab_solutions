## Task 1 butuh dua langkah, dan graderrnya kebalikan GSP081

Diuji 2026-08-04. Deploy lewat `gcloud run deploy --function
--execution-environment=gen2` — resep yang lolos di [gsp081](gsp081.md) dan
[arc109](arc109.md) — di sini **ditolak**: `Please create a cloud function with
desired configurations`. Penyebabnya `gcloud functions list` kosong; grader
GSP092 memeriksa resource **Cloud Functions v2**, bukan Cloud Run service.

Jadi jangan menyamaratakan lab keluarga Cloud Run functions. Yang benar di sini:

```bash
gcloud functions deploy helloworld --gen2 --runtime=nodejs22 --region=us-east4 \
  --source=<dir> --entry-point=helloWorld --trigger-http \
  --allow-unauthenticated --max-instances=5
```

Itu saja masih belum cukup — `gcloud functions deploy` tidak menulis annotation
`run.googleapis.com/execution-environment: gen2`, padahal lab meminta
"Execution environment: second generation". Tambahkan lewat Cloud Run:

```bash
gcloud run services update helloworld --region=us-east4 \
  --execution-environment=gen2 --cpu=1 --memory=512Mi
```

`--cpu=1` wajib: gen2 menolak CPU < 1, sedangkan Cloud Functions memberi 0.1666
(`Total cpu < 1 is not supported with gen2 execution environment`). Memory
dinaikkan ke 512Mi mengikuti default console.
