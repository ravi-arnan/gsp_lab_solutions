# GSP219 - Network Tiers - Optimizing Network Spend

Runbook untuk [`gsp219.sh`](../gsp219.sh). Status: terverifikasi 100/100 sekali jalan (2026-11-14, us-east1-c).

## Sebelum jalan

1. Start lab, login pakai kredensial student.
2. Buka Cloud Shell.
3. Cek Zone di teks instruksi atau panel lab (default: `us-east1-c`).

## Jalankan

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp219.sh | bash
```

Atau jika ingin menentukan Zone secara eksplisit:

```bash
ZONE=us-east1-c bash <(curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp219.sh)
```

## Yang dikerjakan script

| Task | Aksi | Checkpoint |
|------|------|------------|
| 1 | Membuat VM `vm-premium` (`e2-medium`, `--network-tier=PREMIUM`) dan `vm-standard` (`e2-medium`, `--network-tier=STANDARD`) secara paralel di zone yang sama | Create the VM instances |
| 2 | Eksplorasi latency dan traceroute manual via web eksternal | (tidak dinilai) |

Script juga memeriksa dan membuat firewall rule ICMP jika belum tersedia agar pengujian ping dapat berjalan.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `ZONE_RESOURCE_POOL_EXHAUSTED` pada `e2-medium` | Kapasitas zone sedang penuh. Jalankan dengan zone lain di region yang sama, misalnya: `ZONE=us-east1-b bash gsp219.sh`. |
| Instance sudah ada | Script idempoten, create otomatis dilewati jika instance sudah eksis. |
