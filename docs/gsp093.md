# GSP093 - Compute Engine: Qwik Start - Windows

Runbook untuk [`gsp093.sh`](../gsp093.sh).

Lab ini mendemonstrasikan peluncuran VM Windows Server 2022 Datacenter di Compute Engine, pemantauan status startup sysprep melalui output serial port, serta pembuatan kredensial login RDP menggunakan `gcloud compute reset-windows-password`.

## Cara jalan

Jalankan perintah one-liner langsung di terminal Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp093.sh | bash
```

Atau tentukan zona secara eksplisit jika panel lab meminta zona khusus (`us-central1-f`):

```bash
ZONE=us-central1-f curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp093.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp093.sh
bash gsp093.sh
```

Durasi eksekusi: sekitar 3 sampai 4 menit (menunggu inisialisasi boot Windows sysprep selesai).

## Kuis Pilihan Ganda (Manual di Halaman Lab)

1. **Konfigurasi Windows Instance**
   - *Pertanyaan*: "We can create a Windows instance in Google Cloud by changing its ____ in the VM instance console."
   - *Jawaban*: **Boot disk to Windows image**

2. **Perintah Cek Kesiapan RDP**
   - *Pertanyaan*: "Which command is used to check whether the server is ready for an RDP connection?"
   - *Jawaban*: **gcloud compute instances get-serial-port-output**

## Yang Perlu Diperhatikan

1. **Inisialisasi Windows OS & Sysprep:**
   Setelah instance Compute Engine berstatus RUNNING, OS Windows Server memerlukan waktu 1 sampai 2 menit untuk menyelesaikan inisialisasi sysprep dan mengaktifkan Google Compute Engine Windows Agent. Script melakukan polling pada serial port hingga muncul pesan `Instance setup finished. instance is ready to use.` sebelum mengeksekusi reset password.

2. **Kredensial User `admin`:**
   Perintah `gcloud compute reset-windows-password` mengonfigurasi password acak yang aman untuk username `admin`. Setelah selesai dieksekusi, grader lab akan mencatat event tersebut sebagai penyelesaian task RDP login.
