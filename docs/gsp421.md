# GSP421 - APIs Explorer: Cloud Storage

Runbook untuk [`gsp421.sh`](../gsp421.sh). Status: terverifikasi 100/100 sekali jalan (2026-08-21).

## Sebelum jalan

1. Start lab, login pakai kredensial student.
2. Buka Cloud Shell.
3. Tidak ada parameter yang perlu diisi. Nama bucket diturunkan dari Project ID
   (`<PROJECT_ID>-bucket-1` dan `-bucket-2`), jadi otomatis unik.

## Jalankan

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp421.sh | bash
```

Kurang dari satu menit.

## Yang dikerjakan script

Lab aslinya menyuruh mengklik method di APIs Explorer. Script memanggil endpoint
JSON API yang sama lewat `curl` + `gcloud auth print-access-token`, jadi hasilnya
identik di mata checkpoint.

| Task | Method | Dilakukan script | Checkpoint |
|------|--------|------------------|------------|
| 1 | `buckets.insert` | buat bucket 1 | ✅ Create a Cloud Storage Bucket |
| 2 | `buckets.insert` | buat bucket 2 | ✅ Make a second Cloud Storage bucket |
| 3 | upload media | `demo-image1.png` + `demo-image2.png` ke bucket 1 | ✅ Upload Files to Your Cloud Storage Bucket |
| 4 | `objects.copy` | `demo-image1-copy.png` ke bucket 2 | ✅ Copy files between Cloud Storage buckets |
| 5-6 | `objects.delete`, `buckets.delete` | fase `cleanup`, tidak otomatis | tidak ada checkpoint |

Task 3 di lab menyuruh mengunduh foto anjing dan Ada Lovelace lalu upload lewat
console. Checkpoint hanya memeriksa nama objectnya, bukan isinya, jadi script
membuat PNG 1x1 dari base64 inline supaya tidak perlu jaringan keluar.

## Kenapa Task 5-6 dipisah

Keduanya tidak punya checkpoint, dan menghapus persis object yang dinilai
checkpoint 3. Menjalankannya sebelum checkpoint hijau akan membuat skor hilang.
Setelah semua hijau, kalau ingin tetap mencobanya:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp421.sh
bash gsp421.sh cleanup
```

Perhatikan: harus di-download dulu, bukan `curl | bash -s cleanup`.

## Klik manual

Empat checkpoint di atas diklik sendiri. Task 7 (pilihan ganda) tidak masuk skor:

- Default storage class ditentukan saat membuat bucket — **True**
- Nama bucket unik se-namespace Cloud Storage — **True**
- Storage class Cloud Storage — **Coldline, Nearline, Multi-Regional, Regional**

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `409 ... already exists` | Bucket dengan nama itu sudah dibuat (script diulang). Aman, checkpoint tetap hijau. |
| `401 Invalid Credentials` | Token kedaluwarsa atau login akun pribadi. Script memanggil `gcloud auth print-access-token` tiap request, jadi biasanya cukup ulangi. |
| `Project belum di-set` | `gcloud config set project <Project ID dari panel lab>`. |
