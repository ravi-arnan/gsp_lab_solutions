# GSP185 - App Dev: Storing Image and Video Files in Cloud Storage - Python

Runbook untuk [`gsp185.sh`](../gsp185.sh).

Lab ini mengonfigurasi aplikasi kuis berbasis Python/Flask untuk menggunakan Cloud Storage dalam menyimpan dan mengambil aset media (gambar logo `Google_Cloud_Storage_logo.png`) serta mengintegrasikan metadata URL publik gambar tersebut ke dalam entitas Cloud Datastore.

## Alur Kerja

1. **Task 1: Prepare the quiz application**
   - Mengunduh starter code aplikasi dari Cloud Storage bucket project (`gs://${PROJECT_ID}-assets/cloudstorage`).
   - Mengonfigurasi App Engine instance (wilayah `$REGION`) jika belum aktif.
   - Menyiapkan Python virtual environment (`~/venvs/developingapps`) dan menginstal dependensi pustaka (`Flask`, `google-cloud-datastore`, `google-cloud-storage`).
   - Menginisialisasi entitas awal kuis ke Cloud Datastore via `python add_entities.py`.

2. **Task 3: Create a Cloud Storage Bucket**
   - Membuat bucket Cloud Storage bernama `<PROJECT_ID>-media` dengan opsi lokasi `$REGION`.
   - Menyetel variabel lingkungan `GCLOUD_BUCKET` dan `GCLOUD_PROJECT`.
   - Penilaian: *Create a bucket* (Checkpoint 1).

3. **Task 4: Adding objects to Cloud Storage**
   - Mengimplementasikan client Cloud Storage di `quiz/gcp/storage.py` (`bucket.blob()`, `blob.upload_from_string()`, `blob.make_public()`, `blob.public_url`).
   - Memperbarui modul `quiz/webapp/questions.py` untuk mengunggah file gambar dan menyimpan properti `imageUrl` ke Datastore.
   - Mengunggah file `Google_Cloud_Storage_logo.png` ke bucket `gs://${PROJECT_ID}-media` dan menyetel izin akses publik (`allUsers:roles/storage.objectViewer`).
   - Menyimpan entitas pertanyaan kuis terkait Google Cloud Storage ke Cloud Datastore.
   - Menjalankan server kuis di latar belakang port 8080 dan memverifikasi endpoint `/api/quizzes/gcp`.
   - Penilaian: *Upload objects to your bucket* (Checkpoint 2).

## Cara Menjalankan

Jalankan perintah berikut di Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp185.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp185.sh
bash gsp185.sh
```

Zona akan ditanyakan di awal (default `us-west1-b`). Tekan `Enter` jika panel lab Anda sesuai, atau ketik zona yang tertera pada panel lab Anda.

Setelah script menampilkan banner `SELESAI!`, klik kedua tombol **Check my progress** di panel lab:
1. *Create a bucket*
2. *Upload objects to your bucket*

## Detail Teknis

- **Idempotensi Pembuatan App Engine:** Script memeriksa keberadaan App Engine terlebih dahulu sebelum menjalankan `gcloud app create` untuk mencegah error saat lab sudah mengalokasikan App Engine.
- **Fallback Starter Code:** Jika bucket aset project belum terpropagasi, script melakukan fallback mengunduh starter files langsung dari upstream Google Cloud Platform training repository.
- **Eksekusi Logika Aplikasi Tanpa UI:** Alih-alih mengisi formulir melalui antarmuka web secara manual, script langsung menginstansiasi objek `FileStorage` di Python dan memanggil `questions.save_question(data, file_storage)` sehingga validasi Cloud Storage dan Datastore selesai seketika.
