# GSP761 - Developing a REST API with Go and Cloud Run

Runbook untuk [`gsp761.sh`](../gsp761.sh).

Lab ini mendemonstrasikan pengembangan REST API backend menggunakan bahasa Go, deployment kontainer ke Cloud Run via Artifact Registry dan Cloud Build, penyediaan database NoSQL serverless Firestore (Native Mode), impor data pelanggan dari Cloud Storage, serta penyambungan REST API ke Firestore dengan handler Gorilla Mux dan CORS.

## Cara jalan

Jalankan perintah one-liner langsung di terminal Cloud Shell:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp761.sh | bash
```

Atau tentukan region secara eksplisit jika berbeda dengan panel lab (`europe-west4`):

```bash
REGION=europe-west4 curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp761.sh | bash
```

Atau unduh terlebih dahulu dan jalankan:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp761.sh
bash gsp761.sh
```

Durasi eksekusi: sekitar 4 sampai 6 menit.

## Yang Perlu Diperhatikan

1. **Static Binary Compilation:**
   Dockerfile menggunakan base image minimalis `gcr.io/distroless/base-debian12`. Binary Go dikompilasi dengan `CGO_ENABLED=0 GOOS=linux` agar bersifat statically-linked dan dapat berjalan tanpa dependensi library C eksternal.

2. **Idempotensi Database Firestore:**
   Jika database `(default)` sudah dibuat sebelumnya di project lab, script akan mendeteksinya dan melewati pembuatan ulang sehingga aman dijalankan kembali.

3. **Injeksi Project ID:**
   Pada revisi 0.2, inisialisasi Firestore client `firestore.NewClient(ctx, "$PROJECT_ID")` menggunakan Project ID aktual dari sesi aktif Cloud Shell.
