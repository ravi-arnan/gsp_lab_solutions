# GSP1041 - Data Publishing on BigQuery using Authorized Views for Data Sharing Partners

Lab ini memakai **tiga project dengan kredensial berbeda**, jadi tidak bisa
dijalankan sekali dari satu Cloud Shell. Script dipisah tiga fase.

## Jalankan

Kumpulkan dulu lima nilai dari halaman lab (semuanya diacak per peserta):

| Nilai | Di mana |
|-------|---------|
| Project ID partner | query Task 4, sebelum `.demo_dataset` |
| Email Customer A dan B | teks Task 3 |

Lalu, urut:

```bash
# 1. Cloud Shell Data Sharing Partner Project — Task 1, 2, 3
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1041.sh
CUSTOMER_A_USER=student-...@qwiklabs.net \
CUSTOMER_B_USER=student-...@qwiklabs.net \
bash gsp1041.sh partner

# 2. Cloud Shell Customer Project A
PARTNER_PROJECT=qwiklabs-gcp-... bash gsp1041.sh a

# 3. Cloud Shell Customer Project B
PARTNER_PROJECT=qwiklabs-gcp-... bash gsp1041.sh b
```

Mengisi lewat env var lebih aman daripada menjawab prompt satu per satu —
tidak ada yang perlu diketik ulang di Cloud Shell.

Checkpoint Task 4 baru bisa diklik setelah **kedua** fase customer selesai.

## Task

| Task | Fase | Catatan |
|------|------|---------|
| 1. Create Authorized Views | partner | `bq mk --view`, filter `state_code` TX dan CA |
| 2. Assign IAM permissions to both the views | partner | otorisasi view pada dataset |
| 3. Grant permissions to the users | partner | `bq add-iam-policy-binding`, roles/bigquery.dataViewer |
| 4. Verify shared authorized views | a + b | bikin `customer_a_table` / `customer_b_table` |

## Catatan

- **Otorisasi view (Task 2) tidak punya perintah `bq` khusus.** Caranya:
  `bq show --format=prettyjson demo_dataset` → tambahkan entry
  `access[].view` untuk tiap view → `bq update --source`. Idempoten, entry
  yang sudah ada tidak diduplikasi.
- **Teks lab memuat dua project ID partner yang berbeda.** Yang muncul di
  perintah untuk dijalankan sudah diganti Qwiklabs dengan nilai instance-mu;
  yang muncul di contoh pesan `Access Denied` adalah teks statis yang tidak
  ikut diganti. Pakai yang pertama.
- Fase customer juga menjalankan query ke view milik customer lain, yang
  memang harus ditolak `Access Denied` — itu bukti isolasinya bekerja, bukan
  kegagalan script.
