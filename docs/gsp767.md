# GSP767 - Exploring Cost-optimization for GKE Virtual Machines

Runbook untuk [`gsp767.sh`](../gsp767.sh). Status: **terverifikasi 100/100** (2026-11-10).

Lab untuk mempelajari teknik optimasi biaya infrastruktur VM pada Google Kubernetes Engine (GKE) melalui pemilihan machine type (binpacking), migrasi node pool, pembuatan regional cluster, observasi VPC flow logs, dan pencegahan traffic lintas-zona (pod anti-affinity vs affinity).

## Alur Kerja

1. **Task 1: Understanding Node machine types**
   - Eksplorasi machine type dan profil alokasi resource CPU/Memory (konseptual).

2. **Task 2: Choosing the right machine type for the Hello app**
   - Mengambil kredensial cluster `hello-demo-cluster` di zone yang ditentukan (misal `europe-west1-b`).
   - Melakukan scale up deployment `hello-server` menjadi 2 replika (Checkpoint: *Scale Up Hello App*, 25 pts).
   - Menyesuaikan ukuran node pool lama `my-node-pool` menjadi 4 node agar replika kedua dapat dijadwalkan.
   - Membuat node pool baru `larger-pool` dengan tipe mesin yang lebih optimal (`e2-standard-2`, 1 node) (Checkpoint: *Create node pool*, 25 pts).
   - Melakukan cordon dan drain terhadap node pool lama `my-node-pool`.
   - Menghapus node pool lama `my-node-pool`.

3. **Task 3: Managing a regional cluster**
   - Membuat regional cluster `regional-demo` di region yang sesuai (misal `europe-west1`).
   - Menerapkan manifest `pod-1` (multitool) dan `pod-2` (hello-app) dengan aturan `podAntiAffinity` agar berjalan di node/zona berbeda.
   - Mengaktifkan VPC Flow Logs pada subnet default regional.
   - Membuat Cloud Logging export sink `FlowLogsSample` yang mengekspor flow logs ke BigQuery dataset `us_flow_logs`.
   - Mengirimkan simulasi ping antar-zona dari `pod-1` ke `pod-2`.
   - Script memberikan jeda sejenak untuk memberi waktu memverifikasi Checkpoint: *Check Pod Creation* (25 pts).
   - Mengubah aturan pada `pod-2` dari `podAntiAffinity` menjadi `podAffinity`, lalu melakukan recreate `pod-2` agar terjadwal di node yang sama dengan `pod-1`.
   - Menguji latensi ping intra-node dan memeriksa rekaman log (Checkpoint: *Simulate Traffic*, 25 pts).

## Cara Menjalankan

Jalankan langsung di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp767.sh
bash gsp767.sh
```

Script akan secara otomatis mendeteksi zone dan region dari cluster yang sudah ada di project Anda (default `europe-west1-b` dan `europe-west1`).

Saat muncul jeda **BERHENTI SEBENTAR**, klik Check my progress untuk:
1. *Scale Up Hello App* (25 pts)
2. *Create node pool* (25 pts)
3. *Check Pod Creation* (25 pts)

Setelah ketiga checkpoint di atas hijau, tekan **ENTER** di Cloud Shell untuk melanjutkan migrasi `pod-2` ke node yang sama.

Setelah script menampilkan banner `SELESAI!`, klik:
4. *Simulate Traffic* (25 pts)
