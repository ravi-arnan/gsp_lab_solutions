# GSP089 - Cloud Monitoring: Qwik Start

Keempat checkpoint otomatis. Uptime check dan alerting policy dibuat lewat REST
API Monitoring, tidak perlu console.

## Jalankan

Buka Navigation menu → Monitoring sekali dulu supaya metrics scope project
terbentuk, lalu:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp089.sh
ZONE=europe-west3-a bash gsp089.sh
```

## Task

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Create a Compute Engine instance | Ya | `lamp-1-vm`, e2-medium, Debian 12, tag `http-server` |
| 2. Add Apache2 HTTP Server | Ya | lewat SSH; ops agent ikut dipasang |
| 3. Success response over External IP | Ya | curl dari Cloud Shell, retry sampai HTTP 200 |
| 4. Uptime check + alerting policy | Ya | REST `uptimeCheckConfigs` dan `alertPolicies` |
| 5-7. Dashboard, log, incident | Manual | tanpa checkpoint, opsional |

## Catatan

- **`php7.0` tidak ada di Debian 12.** Instruksi lab sudah memberi jalan keluar
  ("kalau tidak bisa php7.0, pakai php5"), tapi yang benar di bookworm adalah
  paket `php` (menarik 8.2). Grader hanya melihat Apache-nya.
- **Notification channel email tidak dibuat** dan checkpoint Task 4 tetap
  hijau. Lab menyuruh memasukkan email pribadi lalu menghapusnya lagi di akhir
  — dilewati saja.
- **Ops agent tetap dipasang** walau tidak dicek grader: metrik
  `agent.googleapis.com/interface/traffic` yang dipakai alerting policy berasal
  dari sana.
- Checkbox "Allow HTTP traffic" di console sama dengan tag `http-server` plus
  firewall rule `default-allow-http`; script membuat rule-nya kalau belum ada.
