# GSP1125 - Detect and Investigate Threats with Security Command Center

Runbook untuk [`gsp1125.sh`](../gsp1125.sh). Status: **terverifikasi 60/60** (2026-11-10).

Lab tentang penggunaan fitur Event Threat Detection (ETD) dan Security Health Analytics (SHA) pada Security Command Center untuk mendeteksi ancaman akun non-kompatibel, investigasi mandiri service account, dan koneksi ke domain malware via Cloud DNS query logs.

## Alur Kerja

1. **Task 1: Initiate and mitigate a threat with Event Threat Detection**
   - Menambahkan binding IAM `roles/bigquery.admin` ke akun demo luar `demouser1@gmail.com` untuk menyimulasikan pembentukan persistensi oleh penyerang.
   - Event ini memicu finding `Persistence: IAM anomalous grant` (ETD) dan `Non org IAM member` (SHA).
   - Mencabut kembali akses `demouser1@gmail.com` sebagai langkah mitigasi insiden.
   - Penilaian: *Initiate and mitigate a threat with Event Threat Detection* (20 pts).

2. **Task 2: Configure a cloud environment to detect threats**
   - Mengaktifkan audit logs `ADMIN_READ` untuk Cloud Resource Manager API pada IAM policy project.
   - Meluncurkan VM instance `instance-1` (zone `us-central1-f`) dengan akses default service account dan scope `cloud-platform`.
   - Menjalankan `gcloud projects get-iam-policy` dari dalam VM untuk menyimulasikan ancaman *Service Account Self-Investigation*.
   - Penilaian: *Configure a cloud environment to detect threats* (20 pts).

3. **Task 3: Manage SCC findings with Event Threat Detection**
   - Membuat Cloud DNS server policy `dns-test-policy` pada network `default` dengan logging aktif (`--enable-logging`).
   - Mengirim kueri DNS dari VM ke domain simulasi malware `etd-malware-trigger.goog` untuk memicu ancaman *Malware: Bad Domain*.
   - Menghapus VM `instance-1` sesuai instruksi penutup lab.
   - Penilaian: *Manage SCC findings with Event Threat Detection* (20 pts).

## Cara Menjalankan

Jalankan langsung di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp1125.sh
bash gsp1125.sh
```

Region dan Zone ditanyakan di awal (default `us-central1` dan `us-central1-f`). Cukup tekan `Enter` jika cocok dengan panel lab.

Setelah script menampilkan banner `SELESAI!`, klik ketiga tombol **Check my progress** di panel lab:
1. *Initiate and mitigate a threat with Event Threat Detection*
2. *Configure a cloud environment to detect threats*
3. *Manage SCC findings with Event Threat Detection*

## Detail Teknis

- **Startup Script + SSH Fallback:** Simulasi pemanggilan `get-iam-policy` dan kueri `etd-malware-trigger.goog` disematkan langsung pada startup script VM dan diverifikasi via SSH dengan isolasi stdin `< /dev/null`.
- **Manipulasi Audit Log Aman:** Penambahan `auditConfigs` dilakukan via skrip Python in-line terhadap dokumen JSON policy IAM untuk menjaga integritas konfigurasi yang sudah ada.
