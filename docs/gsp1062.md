## Jebakan urutan — Task 1 harus hijau penuh sebelum Task 3

Ini penyebab kegagalan berulang di lab ini, terbukti dua kali.

**Checkpoint "Sort data" bernilai 20 dan terbagi dua:** 10 untuk sheet hasil SORT, 10 untuk sheet **Items** yang tersortir. Bagian kedua diperiksa dengan **membaca kolom C secara harfiah**.

Task 3 menyuruh `Insert 1 column left` di sheet Items. Setelah itu "Number of Items" pindah dari C ke D, dan C berisi Unit Price — grader jadi membaca kolom yang salah, dan separuh nilai Task 1 hilang. Rumus SORT-nya juga rusak: range `Items!A1:C15` kini menunjuk nama, Formatted Name, dan Unit Price, sedangkan sort key `Items!B1:B15` menunjuk Formatted Name, jadi hasilnya tersortir alfabet menurun alih-alih harga.

**Karena itu: klik Check my progress sampai Task 1 = 20/20 SEBELUM menyentuh Task 3.** Nilai yang sudah hijau tidak dicabut lagi.

### Kalau terlanjur (Task 1 macet di 10/20)

Task 3 sudah terkunci 20/20, jadi layout Items boleh dikembalikan:

1. Sheet **Items** → klik kanan kolom **B** (Formatted Name) → **Delete column**
2. Klik kanan kolom **C** (Number of Items) → **Sort sheet A → Z**
3. Sheet **Items Sorted By Unit Price**, `A1` kembalikan ke rumus asli lab:
   `=SORT(Items!A1:Items!C15, Items!B1:Items!B15, FALSE)`

Sortir kolom D atau memperbaiki rumusnya saja **tidak cukup** — keduanya sudah dicoba dan tetap 10/20. Yang menyelesaikan adalah mengembalikan layout ke bentuk yang diasumsikan grader.

Rumus tambal berikut sempat dipakai dan menghasilkan tampilan yang benar (3 kolom, harga menurun) tapi **tetap tidak menambah nilai** — bukti bahwa yang diperiksa sheet Items, bukan sheet hasilnya:

```
=SORT({Items!A1:A15,Items!C1:C15,Items!D1:D15}, 2, FALSE)
```

## Task 4 — Validasi

Sheet **Customers**.

| Sel | Isi |
|-----|-----|
| `D2` | `=ISEMAIL(C2)` → isi ke bawah sampai `D100` |

Lalu pilih `D2:D100` → **Data > Data validation > + Add rule**:
- Cell range sudah terisi `Customers!D2:D100`
- Criteria: **Text contains**
- Nilai: `True`
- **Done**

### Menjawab kuis "Which cell is flagged?"

Jawabannya tergantung isi data, jadi jangan ditebak. Ketik ini di sel kosong mana saja (misal `J1`):

```
=FILTER("D"&ROW(D2:D100), D2:D100=FALSE)
```

Keluar daftar sel yang ISEMAIL-nya FALSE — itulah yang ditandai. Cocokkan dengan pilihan ganda (jawabannya dua), lalu **hapus rumusnya**.

Klik **Check my progress** — *Validate data using the function and correct rule*.

## Task 5 — Clean data

Masih di sheet **Customers**.

**Conditional formatting:**
1. **Format > Conditional formatting**
2. Apply to range: `C1:C100`
3. Format cells if: **Custom formula is**
4. Value or formula: `=COUNTIF(C:C,C1)>1`
5. Fill color: **merah** → **Done**

**Greeting:**

| Sel | Isi |
|-----|-----|
| `G1` | `Personalized Greeting` |
| `G2` | `=CONCATENATE("Hello ", TRIM(A2),",")` → isi ke bawah |

Lab menyuruh menulis versi tanpa `TRIM` dulu supaya kelihatan bedanya. Tidak perlu — langsung tulis versi ber-TRIM, yang dinilai keadaan akhirnya.

**Remove duplicates (paling akhir):**
1. Pilih kolom **C** → **Data > Data cleanup > Remove duplicates**
2. **Expand to A:D**
3. Centang **Data has header row**, Column to analyze: **Select all**
4. **Remove duplicates** → **OK**

Klik **Check my progress** — *Clean Data*.
