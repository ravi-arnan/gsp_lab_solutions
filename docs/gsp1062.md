# GSP1062 - Validate Data in Google Sheets

Runbook manual. **Tidak ada script** — seluruhnya di Google Sheets, tidak menyentuh Google Cloud. Status: belum diuji.

Sekeluarga dengan [GSP1063](gsp1063.md): checkpoint membaca isi spreadsheet di Drive akun student, dan Gemini di Sheets tidak bisa menulis ke sel tertentu. Tempel manual.

## Tiga urutan yang tidak boleh dibalik

Ini yang bikin lab ini lebih rawan daripada GSP1063.

1. **Task 2: klik checkpoint SEBELUM menghapus filter.** Lab menyuruh `Data > Remove filter` dan `Delete all views in tab` tepat setelah masing-masing checkpoint. Kalau dihapus dulu, tidak ada yang bisa diperiksa.
2. **Task 3: sisipkan kolom B PALING AKHIR.** Rumus TRUNC dan ROUND ditulis dulu di kolom E dan D, baru kolom baru disisipkan. Sheets menggeser referensinya otomatis, jadi hasil akhirnya benar — tapi kalau kolomnya disisipkan lebih dulu, semua alamat sel di instruksi lab meleset satu kolom.
3. **Task 5: Remove duplicates paling akhir.** Menghapus baris menggeser semua yang di bawahnya; conditional formatting dan kolom greeting harus sudah terpasang dulu.

## Task 1 — Sort

1. Unduh **On The Rise Bakery Customers and Items** dari panel lab.
2. Di Google Sheets: **Open file picker** → tab **Upload** → **Browse** → pilih file itu.
3. **File > Make a copy** → **Make a copy**. Salinan inilah yang dinilai.
4. Sheet **Items** → **View > Freeze > 1 row**.
5. Klik kanan label kolom **C** → **Sort sheet A to Z**.
6. **+** di kiri bawah → klik kanan → **Rename** → `Items Sorted By Unit Price`

| Sel | Isi |
|-----|-----|
| `A1` (sheet baru) | `=SORT(Items!A1:Items!C15, Items!B1:Items!B15, FALSE)` |

Klik **Check my progress** — *Sort data*.

## Task 2 — Filter dan filter view

Balik ke sheet **Items**.

**Filter:**
1. Pilih kolom **A** → **Data > Create a filter**
2. Klik ikon filter di `A1` → **Filter by values** → hapus centang **Cinnamon bun** → **OK**
3. **Check my progress** — *Create a filter*
4. Baru: **Data > Remove filter**

**Filter view:**
1. Klik sel `A1` dulu (wajib, kalau tidak range-nya salah)
2. **Data > + Create filter view**
3. Ikon filter di `A1` → hapus centang **Cinnamon bun** → **OK**
4. **Data > View options > Save view > Save**
5. **Check my progress** — *Create a filter view*
6. Baru: **Data > View options > Delete all views in tab**

## Task 3 — Format

Masih di sheet **Items**. Ikuti urutan ini persis.

| Urutan | Sel | Isi |
|--------|-----|-----|
| 1 | `E1` | `Truncated Unit Prices` |
| 2 | `E2` | `=TRUNC(B2, 4)` → isi ke bawah |
| 3 | `D2` | `=ROUND(B2*C2, 2)` → isi ke bawah |

4. Klik label kolom **D** → **Format > Number > Currency**
5. Klik kanan label kolom **B** → **Insert 1 column left**

| Urutan | Sel | Isi |
|--------|-----|-----|
| 6 | `B1` | `Formatted Name` |
| 7 | `B2` | `=PROPER(A2)` → isi ke bawah |

Setelah penyisipan, layout akhirnya: A = nama item, B = Formatted Name, C = Unit Price, D = Number of items, E = total (currency), F = Truncated Unit Prices. Rumus di E dan F ikut tergeser sendiri — itu benar, jangan diperbaiki.

Klik **Check my progress** — *Format numbers and text*.

## Task 4 — Validasi

Sheet **Customers**.

| Sel | Isi |
|-----|-----|
| `D2` | `=ISEMAIL(C2)` → isi ke bawah sampai `D100` |

Lalu pilih `D2:D100` → **Data > Data validation > + Add rule**:
- Cell range sudah terisi `Customers!D2:D100`
- Criteria: **Text contains**
- Nilai: `True`
- **Done**

### Menjawab kuis "Which cell is flagged?"

Jawabannya tergantung isi data, jadi jangan ditebak. Ketik ini di sel kosong mana saja (misal `J1`):

```
=FILTER("D"&ROW(D2:D100), D2:D100=FALSE)
```

Keluar daftar sel yang ISEMAIL-nya FALSE — itulah yang ditandai. Cocokkan dengan pilihan ganda (jawabannya dua), lalu **hapus rumusnya**.

Klik **Check my progress** — *Validate data using the function and correct rule*.

## Task 5 — Clean data

Masih di sheet **Customers**.

**Conditional formatting:**
1. **Format > Conditional formatting**
2. Apply to range: `C1:C100`
3. Format cells if: **Custom formula is**
4. Value or formula: `=COUNTIF(C:C,C1)>1`
5. Fill color: **merah** → **Done**

**Greeting:**

| Sel | Isi |
|-----|-----|
| `G1` | `Personalized Greeting` |
| `G2` | `=CONCATENATE("Hello ", TRIM(A2),",")` → isi ke bawah |

Lab menyuruh menulis versi tanpa `TRIM` dulu supaya kelihatan bedanya. Tidak perlu — langsung tulis versi ber-TRIM, yang dinilai keadaan akhirnya.

**Remove duplicates (paling akhir):**
1. Pilih kolom **C** → **Data > Data cleanup > Remove duplicates**
2. **Expand to A:D**
3. Centang **Data has header row**, Column to analyze: **Select all**
4. **Remove duplicates** → **OK**

Klik **Check my progress** — *Clean Data*.

## Kalau checkpoint merah

| Gejala | Sebab |
|--------|-------|
| Task 1 merah | Nama sheet bukan persis `Items Sorted By Unit Price`, atau kolom C belum di-sort A to Z. |
| Filter merah | Filter sudah terlanjur dihapus sebelum diklik. Buat lagi, klik dulu, baru hapus. |
| Filter view merah | `A1` tidak dipilih sebelum **Create filter view**, atau view belum di-**Save**. |
| Task 3 merah | Kolom B disisipkan sebelum rumus E dan D ditulis. Undo sampai bersih, ulangi dari urutan 1. |
| Task 4 merah | Criteria bukan **Text contains** dengan nilai `True`, atau range bukan `D2:D100`. |
| Task 5 merah | Remove duplicates tidak di-**Expand to A:D**, atau **Data has header row** tidak dicentang (baris judul ikut terhapus). |
