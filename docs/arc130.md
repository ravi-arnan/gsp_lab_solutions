# ARC130 - Analyze Sentiment with Natural Language API: Challenge Lab

Task 3 dan 4 dinilai dari file **di dalam VM `lab-vm`**. Task 1 dan 2 di luar
jangkauan CLI.

## Jalankan

Bikin API key lewat console dulu (APIs & Services → Credentials → Create
credentials → API key, restriction: Cloud Natural Language API), lalu:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc130.sh
API_KEY=<key-dari-console> bash arc130.sh
```

## Task

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Create an API key | Manual | lewat console, seperti [arc132](../arc132.sh) |
| 2. Google Docs + Apps Script | Manual | tidak ada jalur CLI; instruksi lengkap di penutup script |
| 3. Analyze syntax and parts of speech | Ya | `analyzeSyntax` → `analyze-response.txt` |
| 4. Multilingual NLP | Ya | `analyzeEntities` → `multi-response.txt` |
