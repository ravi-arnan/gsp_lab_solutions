# GSP096 - Pub/Sub: Qwik Start - Console

Runbook untuk [`gsp096.sh`](../gsp096.sh).

Semua checkpoint otomatis dieksekusi via `gcloud` CLI (tanpa harus klik manual di Cloud Console).

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp096.sh
bash gsp096.sh
```

Atau one-liner:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp096.sh | bash
```

Lama eksekusi: < 1 menit.

## Tabel Task

| Task | Otomatis | Keterangan |
|------|----------|------------|
| 1. Setting up Pub/Sub | Ya | Topic `MyTopic` dibuat via `gcloud pubsub topics create` |
| 2. Add a subscription | Ya | Subscription `MySub` (pull) dibuat via `gcloud pubsub subscriptions create` |
| 3. Test your understanding | Manual | Kuis (jawaban tertera di banner script) |
| 4. Publish a message | Ya | Publish pesan `Hello World` via CLI |
| 5. View the message | Ya | Pull pesan via `gcloud pubsub subscriptions pull --auto-ack` |

## Jawaban Kuis Task 3

1. *A publisher application creates and sends messages to a ____. Subscriber applications create a ____ to a topic to receive messages from it.*
   **Jawaban:** `topic, subscription`
2. *Cloud Pub/Sub is an asynchronous messaging service designed to be highly reliable and scalable.*
   **Jawaban:** `True`
