# GSP090 - Monitor Multiple Google Cloud Projects with Cloud Monitoring

Runbook untuk [`gsp090.sh`](../gsp090.sh). Status: terverifikasi 20/20 (2026-11-16, europe-west1/europe-west1-b).

## Ringkasan Lab

Lab ini mengonfigurasi **Cloud Monitoring Metrics Scope** untuk memantau performa dan ketersediaan resource VM instance lintas dua Google Cloud Project (`PROJECT_1` dan `PROJECT_2`) secara terpusat dari satu akun/workspace Cloud Monitoring.

Arsitektur terdiri dari:
1. **Multi-Project Environment**: `PROJECT_1` (monitored project dengan `instance1`) dan `PROJECT_2` (scoping project dengan `instance2`).
2. **Cloud Monitoring Metrics Scope**: `PROJECT_1` ditambahkan ke dalam metrics scope `PROJECT_2`.
3. **Cloud Monitoring Resource Group**: Group `DemoGroup` yang secara dinamis menyaring seluruh VM instance yang namanya mengandung kata `instance`.
4. **TCP Uptime Check**: Uptime check berkala setiap 60 detik pada port 22 (SSH) yang ditargetkan ke seluruh anggota `DemoGroup`.
5. **Alerting Policy**: Kebijakan peringatan otomatis (`Uptime Check Policy`) berdasarkan metric absence dari uptime check passed.

## Cara Menjalankan

## Detail Teknis & Penanganan Otomasi

- **Deteksi Otomatis Multi-Project**: Script memeriksa daftar project via `gcloud projects list` dan membedakan `PROJECT_1` (prefix `-01-`) dan `PROJECT_2` (prefix `-02-`) secara otomatis.
- **Metrics Scope API**: Menghubungkan metrics scope antar-project via endpoint REST `locations/global/metricsScopes/{PROJECT_2}/projects` tanpa perlu interaksi manual di UI Console.
- **REST API Monitoring Group & Uptime Check**: Pembuatan grup dan konfigurasi pengecekan uptime dilakukan secara programatik dengan OAuth2 Bearer token bawaan `gcloud auth print-access-token`.
