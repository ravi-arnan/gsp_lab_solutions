# GSP529 - Develop AI-Powered Prototypes in Google AI Studio: Challenge Lab

Runbook manual. **Tidak ada script** untuk lab ini — lihat alasannya di bawah. Isi dokumen ini adalah enam prompt siap tempel, satu per task. Status: **terverifikasi 100/100** (2026-08-02), semua prompt jadi sekali jalan.

## Kenapa lab ini tidak bisa di-script

Seluruh pekerjaan ada di [aistudio.google.com](https://aistudio.google.com) Build, bukan di Google Cloud:

- Tidak ada `gcloud` atau API publik untuk membuat/mengedit app di AI Studio Build. Cloud Shell tidak dipakai sama sekali di lab ini.
- Login memakai akun student di browser, semua aksi lewat UI (prompt → Code Assistant → Save → Download ZIP).
- Checkpoint membaca app yang tersimpan di Drive akun student, bukan resource project. Tidak ada permukaan yang bisa disentuh script.

Yang bisa dipangkas cuma waktu menyusun prompt. Itulah isi dokumen ini.

## Sebelum mulai

1. Buka AI Studio di jendela **Incognito**, login dengan Username/Password dari panel lab.
2. Masuk ke tab **Build** (bukan Chat/Stream).
3. Beri akses Drive lebih dulu: menu **Add files → Drive**, pilih akun student, setujui permission. Tanpa ini tombol Save tidak berfungsi dan semua checkpoint akan merah.

## Aturan yang bikin gagal kalau dilanggar

- **Save setelah tiap task.** Grader membaca app yang tersimpan, bukan yang ada di layar. Task selesai tapi belum di-save = checkpoint merah.
- **Task 2 sampai 5 pakai Code Assistant** (panel chat di samping kode), bukan bikin app baru dari nol. Lab menilai penambahan fitur secara bertahap di app yang sama.
- **Nama app harus persis `Fantasy Character Generator`** di Task 6.
- Hasil generatif berbeda-beda tiap run. Kalau tampilan tidak sama persis dengan screenshot lab, itu normal — yang dinilai keberadaan fiturnya.

## Prompt per task

### Task 1 — app inti

Prompt awal (kolom "What do you want to build?"):

```
Build a Fantasy Character Creator web app. It has a single button labeled
"Generate Character". When clicked, use the Gemini API to generate a random
fantasy character and display the character's Name and Class (for example
Mage, Rogue, Warrior, Paladin, Druid) on the screen. Each click should produce
a new, different character.
```

Setelah app jalan: **Save**.

### Task 2 — portrait

Ke Code Assistant:

```
Add character portraits. Below the character's name and class, add a
"Generate Portrait" button that uses the Gemini image generation model to
create a cartoon / video game style portrait of the character currently
displayed, using its name and class in the image prompt. Once a portrait
exists, show a "Regenerate Portrait" button that creates a new one for the
same character. Show a loading state while the image is being generated.
```

**Save**.

### Task 3 — tema UI

```
Restyle the entire app to look like an ancient alchemist's workbench. Use a
dark, textured background (aged parchment and dark wood tones with a subtle
texture, not a flat color), warm candle-lit accent colors, and render the
character's name in a stylized fantasy-style display font. Keep all existing
functionality intact.
```

**Save**.

### Task 4 — backstory

```
Add a "Generate Backstory" button. When clicked, use the Gemini API to write
a unique one-to-two-sentence origin story for the character currently on
screen, based on its name and class, and display it below the portrait. Show
a loading state while it generates.
```

**Save**.

### Task 5 — player card, stats, save to deck

Task terberat, tapi tetap satu prompt:

```
Reformat the whole UI into a bordered fantasy player card that contains the
portrait, the name, the class, the backstory, and a stats block. When a
character is generated, also randomly generate three stats and show them on
the card: Health, Mana, and Strength. Add a "Save to Deck" button on the card
that adds the current character (portrait, name, class, stats, backstory) to a
"My Deck" list displayed in the app, so the user can collect multiple
characters. Keep the alchemist's workbench theme.
```

Cek manual sebelum save: generate karakter → Health/Mana/Strength muncul dan berubah tiap generate → Save to Deck → karakter muncul di My Deck.

**Save**.

### Task 6 — simpan dan download

1. Rename app menjadi persis `Fantasy Character Generator`, lalu **Save**.
2. Menu app → **Download** → simpan ZIP source code-nya.
3. Check my progress terakhir.

## Kalau checkpoint merah

- Fitur ada di layar tapi checkpoint merah → hampir selalu belum di-save, atau akses Drive belum diberikan sejak awal (app tidak pernah benar-benar tersimpan).
- Code Assistant menghapus fitur task sebelumnya (sering terjadi di Task 5 saat merombak UI) → minta balik secara eksplisit: `Restore the Generate Backstory button, it disappeared in the last change.`
- App error setelah edit → tempel pesan errornya mentah-mentah ke Code Assistant. Itu jalur yang memang diharapkan lab ("reading and researching error messages to fix your own mistakes").

## Estimasi waktu

15–20 menit dari 35 menit yang tersedia, dengan asumsi tiap prompt jadi sekali jalan. Sisanya buffer untuk generate ulang.
