# ARC112 - Deploy and Manage Applications on Google App Engine: Challenge Lab

Runbook untuk [`arc112.sh`](../arc112.sh). Status: terverifikasi 100/100 (2026-08-21, us-east4).

## Sebelum jalan

Start lab, login student, buka Cloud Shell. Cek region di teks Task 2 (default
script `us-east4`). Zone VM `lab-setup` dicari sendiri oleh script.

## Jalankan

Dua fase, jadi download dulu.

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc112.sh
bash arc112.sh                 # Task 1-2, 4-6 menit
# klik Check my progress 1 dan 2 sampai hijau
bash arc112.sh update          # Task 3, 2 menit
```

## Yang dikerjakan script

| Fase | Task | Aksi | Checkpoint |
|------|------|------|------------|
| main | 1 | `git clone --depth 1 python-docs-samples` di `$HOME` VM | ✅ Download the Hello World app |
| main | 2 | `gcloud app create --region`, tambah `automatic_scaling: max_instances: 1`, `gcloud app deploy` | ✅ Deploy the application |
| update | 3 | `sed` pesan jadi `Welcome to this world!`, deploy ulang | ✅ Deploy updates to your application |

Semua perintah dijalankan **di dalam VM `lab-setup`** lewat `gcloud compute ssh`,
sesuai instruksi lab ("Run all subsequent commands in this lab inside the SSH
terminal connected to lab-setup").

## Tiga keputusan

- **Jalur Python, bukan PHP atau Go.** Lab memberi tiga pilihan bahasa. Python
  paling ringan: tidak perlu menambal versi runtime seperti jalur PHP, yang
  `app.yaml`-nya masih menyebut `php81` (sudah tidak aktif) sehingga harus
  di-`sed` ke `php83` sebelum deploy.
- **`git clone --depth 1`.** `python-docs-samples` besar; shallow clone memberi
  struktur direktori yang sama dengan yang dicari grader, jauh lebih cepat.
- **Dua fase.** Checkpoint 2 dinilai ketika aplikasi masih menyajikan pesan
  bawaan `Hello World!`. Kalau pesan langsung ditimpa di jalan yang sama,
  checkpoint itu berisiko tidak pernah terlihat dalam kondisi yang dinilai.
  Pemisahan ini murah — fase kedua hanya butuh 2 menit.

`automatic_scaling: max_instances: 1` bukan hiasan: catatan lab memintanya supaya
deployment berulang tidak menabrak kuota instance project.

## Klik manual

Tiga checkpoint, dua di antaranya sebelum menjalankan fase `update`.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `VM lab-setup tidak ditemukan` | Nama VM beda di instance-mu. `VM=<nama> bash arc112.sh`. |
| `The current Google Cloud project already has an App Engine application` | App sudah dibuat lebih dulu, mungkin di region lain. Script melewatinya; kalau regionnya salah, App Engine tidak bisa dipindah — lab harus diulang. |
| Deploy gagal soal kuota instance | `automatic_scaling` belum masuk `app.yaml`. Cek isinya, script mencetaknya sebelum deploy. |
| Halaman masih `Hello World!` setelah fase update | Versi baru belum menerima trafik. Tunggu belasan detik lalu refresh; `gcloud app versions list` menunjukkan versi mana yang aktif. |
