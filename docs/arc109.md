# ARC109 - Deploy and Secure Serverless APIs with API Gateway: Challenge Lab

Ketiga task otomatis penuh. Yang lama cuma pembuatan gateway (~10 menit).

## Jalankan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc109.sh
REGION=us-east1 nohup bash arc109.sh > arc109.log 2>&1 &
tail -f ~/arc109.log
```

Sesi Cloud Shell di lab keluarga ini pernah putus di tengah (lihat
[gsp872](gsp872.md)), jadi jalankan di background. Script idempoten.

## Task

| Task | Otomatis | Catatan |
|------|----------|---------|
| 1. Create a Cloud Run function | Ya | `gcfunction`, nodejs22, unauthenticated |
| 2. Create an API Gateway | Ya | api/config/gateway semuanya `gcfunction-api`, display name `gcfunction API` |
| 3. Pub/Sub topic + publish via API backend | Ya | `demo-topic` + `demo-topic-sub`, function di-redeploy lalu gateway dipanggil |

## Catatan

- **Deploy pakai `gcloud run deploy --function`, bukan `gcloud functions deploy
  --gen2`**, plus `--execution-environment=gen2`. Alasannya sama seperti
  [gsp081](gsp081.md): grader lab keluarga ini mencari Cloud Run service hasil
  alur "Write a function".
- **Klik Check my progress Task 1 lebih awal.** Function yang sama di-redeploy
  di Task 3 dengan kode Pub/Sub yang membalas `Message sent to Topic
  demo-topic!`, bukan lagi `Hello World!`. Script sengaja mencetak banner
  pengingat setelah deploy pertama, lalu lanjut bikin gateway (~10 menit) —
  jendela waktu yang cukup untuk mengklik.
- **Task 2 gagal kalau diklik terlalu cepat**: `Please create a gateway
  gcfunction API with API config as 'gcfunction-api' API`. Tunggu gateway
  `ACTIVE` dulu:
  ```bash
  gcloud api-gateway gateways list --format="table(name.basename(), displayName, state, defaultHostname)"
  ```
- Default subscription tidak ikut terbuat lewat `gcloud pubsub topics create`
  (itu hanya perilaku Console), jadi `demo-topic-sub` dibuat eksplisit.
