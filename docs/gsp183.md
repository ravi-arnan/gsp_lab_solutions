# GSP183 - App Dev: Setting up a Development Environment - Python

Runbook untuk [`gsp183.sh`](../gsp183.sh).

Lab ini memandu pembuatan lingkungan pengembangan Python di Google Cloud menggunakan Compute Engine VM instance (`dev-instance`), instalasi dependensi build Python, pengunduhan kode aplikasi dari Google Cloud Storage bucket (`gs://${PROJECT_ID}-assets/devenv`), serta pengujian web server HTTP dan enumerasi instance menggunakan Google APIs Client Library untuk Python.

## Alur Kerja

1. **Task 1: Create a Compute Engine virtual machine instance**
   - Membuat VM instance `dev-instance` (Debian 12 Bookworm, machine type `e2-medium`).
   - Menetapkan tag `http-server` dan memastikan aturan firewall port 80 (`default-allow-http`) aktif.
   - Mengaktifkan full access scopes ke Cloud APIs (`cloud-platform`).
   - Penilaian: *Create a Compute Engine Virtual Machine Instance*.

2. **Task 1 (Lanjutan): Install software on the VM instance**
   - Memperbarui apt cache (`apt-get update`).
   - Menginstal Git, Python setuptools, Python dev headers, dan build tools (`build-essential`).
   - Mengunduh dan menginstal pip versi terkini via `get-pip.py --break-system-packages`.
   - Penilaian: *Install software and configure the VM instance*.

3. **Task 2: Configure the VM to run application software**
   - Mengunduh lab assets dari Cloud Storage bucket project (`gs://${PROJECT_ID}-assets/devenv`).
   - Menjalankan `server.py` pada port 80 HTTP di latar belakang agar siap menerima evaluasi traffic HTTP dari grader.
   - Penilaian: *Run application software to get a success response*.
   - Menginstal pustaka Python yang didefinisikan di `requirements.txt` (`google-api-python-client`, dll).
   - Menjalankan `python3 list-gce-instances.py <PROJECT_ID> --zone=<ZONE>` untuk memverifikasi enumerasi VM instance via Python client library.

## Detail Teknis

- **Isolasi stdin SSH dan SCP:** Pemanggilan `gcloud compute scp` dan `gcloud compute ssh` dipasangi `< /dev/null` agar aman dijalankan dalam mode pipa non-interaktif (`curl ... | bash`).
- **Penanganan Package Lock:** Script remote menunggu file lock `dpkg` / `apt` dilepaskan secara otomatis oleh sistem sebelum menjalankan instalasi paket untuk menghindari bentrok dengan proses background sistem Debian yang baru booting.
- **Resilient Asset Retrieval & Fallback:** Script mencoba mengambil source code dari bucket assets resmi lab (`gs://${PROJECT_ID}-assets/devenv`). Jika bucket tidak tersedia atau terjadi delay propagasi, script menyertakan file fallback yang identik untuk `server.py`, `requirements.txt`, dan `list-gce-instances.py`.
- **Background Web Server:** `server.py` dijalankan di latar belakang (`nohup sudo python3 server.py &`) sehingga port 80 tetap listening ketika grader lab mengecek koneksi HTTP eksternal.
