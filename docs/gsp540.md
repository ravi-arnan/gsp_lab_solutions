# GSP540 - Engineer AI Agents with Agent Development Kit (ADK): Challenge Lab

Runbook untuk [`gsp540.sh`](../gsp540.sh). Status: **terverifikasi 100/100** (2026-08-01), sekali jalan tanpa koreksi.

## Kenapa lab ini cocok di-script

Semua pekerjaan lab adalah tiga edit kecil di source code yang sudah disediakan plus `.env`. Yang tidak bisa di-script cuma percakapannya: checkpoint Task 2, 3, dan 5 baru hijau setelah agent benar-benar dipanggil (grader membaca Cloud Logging, agent-agentnya memasang `log_query_to_model` / `log_model_response`), dan Task 2 dan 5 secara spesifik menuntut lewat Dev UI.

## Jalankan

```bash
gcloud auth application-default login   # interaktif, jalankan sendiri lebih dulu
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp540.sh
bash gsp540.sh setup   # Task 1 + patch Task 2, 4, 5
bash gsp540.sh geo     # Task 4 -> {"capital": "Paris"}
bash gsp540.sh cli     # Task 3 -> adk run my_google_search_agent
bash gsp540.sh web     # Task 2 + 5 -> dua percakapan manual di Dev UI
```

Idempoten: download dilewati kalau `~/adk_project` sudah ada, tiap patch punya penanda "sudah dipatch" sendiri.

## Hal yang mudah terlewat

- **`.env` juga perlu di root project.** `geo_validator/agent.py` memanggil `load_dotenv()` tanpa argumen, dan dijalankan sebagai `python3 geo_validator/agent.py` dari `~/adk_project`, jadi yang dibaca adalah `.env` di cwd — bukan yang ada di folder agent. Script menulis keempatnya.
- **`GOOGLE_CLOUD_LOCATION=global`,** bukan `us-central1`. Lab menegaskan ini dan model `gemini-3.5-flash` memang dilayani dari endpoint global.
- **Jangan pakai API key.** Lab meminta jalur Agent Platform lewat ADC.
- **Task 4 butuh `disallow_transfer_to_parent` dan `disallow_transfer_to_peers`.** Agent dengan `output_schema` tidak boleh punya jalur transfer; tanpa dua flag itu ADK menolak.
- **Checkpoint tidak membaca file.** Mengedit kode saja tidak menghijaukan Task 2, 3, dan 5 — percakapannya harus benar-benar dijalankan, dan Task 2 dan 5 lewat Dev UI (`adk web`), bukan CLI.
