# ARC111 - Implement Cloud Storage and Data Protection Solutions: Challenge Lab

Runbook untuk [`arc111.sh`](../arc111.sh). Status: terverifikasi 100/100 di form-3
(2026-08-02, europe-west1) dan form-1 (2026-08-21, us-east4).

## Dua hal yang diacak per instance

1. **Nama bucket.** Ada suffix random (`74fx`, `w9kj`, ...), jadi tidak bisa
   diturunkan dari Project ID. Salin ketiganya dari panel **Lab setup and access**.
   Polanya tidak konsisten — di instance 2026-08-21, Bucket1 justru tidak punya
   tanda hubung sebelum suffix (`...-83e44225493574fx-bucket`) sementara Bucket2
   dan Bucket3 punya. Salin apa adanya, jangan dinormalkan.
2. **Isi task.** Teks lab memuat catatan `Form ID: form-N` tepat di atas Task 1.
   Nomor itu menentukan task mana yang muncul. Isi lewat `FORM=<n>`.

| Form | Task 1 | Task 2 | Task 3 |
|------|--------|--------|--------|
| 1 | buat Bucket1 dengan class **COLDLINE** | retention policy **30 detik** di Bucket2 | upload satu object ke Bucket3 |
| 3 | buat Bucket1 dengan class **NEARLINE** | ubah isi `sample.txt` di Bucket2 | ubah default class Bucket3 ke **ARCHIVE** |

Form lain belum pernah kena. Script akan berhenti dengan pesan jelas kalau
`FORM` tidak dikenal, bukan menjalankan task yang salah.

## Jalankan

Butuh parameter, jadi download dulu — jangan `curl | bash`.

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/arc111.sh
FORM=1 REGION=us-east4 \
  B1=<Bucket1_name> B2=<Bucket2_name> B3=<Bucket3_name> \
  bash arc111.sh
```

Kurang dari satu menit. Variabel bucket yang dikosongkan akan dilewati, jadi aman
kalau instance-mu cuma menampilkan sebagian task.

Kalau script baru saja diperbarui, ambil lewat commit SHA, bukan `main` —
`raw.githubusercontent.com` menyajikan versi lama sekitar lima menit untuk file
yang sudah ada.

## Klik manual

Tiap task punya tombol **Verify Task** sendiri. Klik satu per satu setelah script
selesai.

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `HTTPError 404 ... bucket does not exist` | Nama bucket salah salin. Cocokkan huruf per huruf dengan panel lab, termasuk ada/tidaknya tanda hubung sebelum suffix. |
| Task 1 `409 already exists` | Bucket sudah dibuat percobaan sebelumnya. Script mendeteksinya dan hanya meng-update storage class, aman. |
| `Form N belum dikenal` | Varian baru. Baca task di teks lab, tambahkan cabangnya di script (lihat `case "$FORM"` di Task 1 dan `if ... "$FORM" == "1"` di Task 2/3). |
| Retention policy gagal di-set | Bucket sudah punya retention lock. Tidak pernah terjadi sejauh ini; cek `gcloud storage buckets describe gs://$B2`. |
