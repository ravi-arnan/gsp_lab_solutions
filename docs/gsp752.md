# GSP752 — Manage Terraform State

Lab intermediate Terraform di Google Cloud: migrasi backend dari local ke Cloud Storage (GCS), refresh state dengan label bucket, dan import konfigurasi Docker container.

## Cara jalan

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp752.sh
bash gsp752.sh
```

Atau one-liner langsung:

```bash
curl -sL https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp752.sh | bash
```

## Yang perlu diperhatikan

**Deteksi dummy wrapper Terraform di Cloud Shell:**
Pengecekan instalasi memeriksa output `terraform --version | grep 'Terraform v'`. Jika belum terpasang atau masih berupa dummy wrapper bawaan Google Cloud Shell, script otomatis menginstal Terraform dari repositori resmi HashiCorp.

**Backend Migration & Labeling:**
- Script membuat bucket `gs://$PROJECT_ID` dengan local backend terlebih dahulu, lalu memigrasikan state ke `backend "gcs"` menggunakan `terraform init -migrate-state`.
- Label `key=value` ditambahkan ke bucket dan disinkronkan ke Terraform state via `terraform refresh`.
- Bucket sengaja tidak di-destroy agar checkpoint "Work with backends" di grader Cloud Skills Boost tetap hijau.

**Task 2 (Docker Container Import):**
Task 2 dieksekusi secara otomatis tanpa jeda interaktif `read -r` untuk mematuhi aturan otomatisasi non-interaktif.
