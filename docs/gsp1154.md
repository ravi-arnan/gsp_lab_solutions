## Kenapa 0/5

Diuji di lab instance sungguhan 2026-07-17. Skor 0 di kelima checkpoint.

Yang penting: **kegagalannya bukan karena script error.** Task 1, 2, dan 3 jalan tuntas, API merespons, isi jawabannya sesuai yang diminta lab. Tetap nol. Jadi ini bukan soal salah parameter di satu tempat, melainkan pendekatannya yang keliru.

## Pelajaran yang bisa dipakai lab lain

**Kalau pesan checkpoint menyebut nama artefak UI, otomasi lewat API tidak akan menghasilkan poin** — sebanyak apa pun API call yang sukses.

Cara murah mengeceknya sebelum menulis script: klik Check my progress sekali di lab kosong, baca pesan gagalnya. Kalau bunyinya "Please create the 'X' prompt" atau menyebut nama resource UI, hentikan. Kalau bunyinya menyebut resource yang punya padanan `gcloud` (dataset, lake, bucket), lanjut.

## Jalur yang masih terbuka (tidak disarankan)

Secara teori prompt tersimpan bisa dibuat lewat Vertex AI Datasets API dengan schema prompt, supaya namanya cocok dengan yang dicari checkpoint. Tidak dikejar karena: schema-nya belum tentu cocok, Task 1 (Cloud Run) tetap mustahil, Task 4 dan 5 hampir pasti tetap butuh UI, dan taruhannya beberapa putaran coba-gagal demi lab yang manualnya lebih cepat.

## Catatan teknis

Terverifikasi jalan di lab instance, berguna kalau nanti ada yang meneruskan:

- **Model lab: `gemini-3.5-flash` dan `gemini-2.5-pro`.** Pasangannya memang terbalik, Flash-nya generasi lebih baru. Keduanya valid di endpoint `global`.
- **Gemini 3 pakai `thinkingConfig.thinkingLevel`** (enum, mis. `MINIMAL`), bukan `thinkingBudget` (angka) seperti generasi 2.x. Lab menyebutnya "Thinking level: Minimal". Terverifikasi diterima.
- **`gemini-2.5-pro` gampang kena `429 Resource has been exhausted`** di project lab. Task 3e dibuat non-fatal supaya tidak memblokir Task 4 dan 5.
- **Akun student tidak punya izin `serviceusage`.** Jangan panggil `gcloud services enable` — gagal `PERMISSION_DENIED` dan `set -e` membunuh script. Qwiklabs sudah meng-enable API sejak provisioning.
- **Region:** Gemini pakai endpoint `global` sesuai instruksi lab. Dialog Save prompt pakai `us-central1`.
- **`timetable.png`** ada di bucket bawaan lab yang namanya beda tiap instance. Default script pakai copy publik `gs://cloud-samples-data/generative-ai/image/timetable.png`.

## Beda dengan teks tugas

Materi lab sudah diperbarui tapi teks tugasnya ketinggalan:

- **Task 5 pakai Nano Banana 2**, bukan Imagen 4 seperti yang tertulis. Ketahuan dari pesan checkpoint. Default `IMAGEN_MODEL` di script masih `imagen-4.0-generate-001` dan kemungkinan besar salah sasaran.
- Teks tugas menulis model sebagai placeholder `model_name`; nilai sebenarnya `gemini-3.5-flash` / `gemini-2.5-pro`.
