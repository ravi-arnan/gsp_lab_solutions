# GSP750 - Infrastructure as Code with Terraform

Runbook untuk [`gsp750.sh`](../gsp750.sh). Status: belum diuji.

## Sebelum jalan

1. Start lab, login pakai kredensial student.
2. Buka Cloud Shell (ikon terminal di kanan atas console).
3. Clone dulu (jangan di-pipe ke bash, karena lama dan butuh beberapa fase):

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp750.sh
bash gsp750.sh
```

Durasi sekitar 15 menit (install Terraform ~2 menit, build resource ~3 menit, destroy/create ~3-4 menit, taint + recreate ~2 menit).

## Yang harus muncul

Tidak ada nilai spesifik yang dicek. Script akan menulis `ip_address.txt` di akhir berisi alamat IP instance.

## Klik manual

Script tidak bisa mengklik. Setelah selesai, klik **Check my progress** untuk:

- Create resources in Terraform (Task 1)
- Change the infrastructure (Task 2)
- Make destructive changes (Task 2)
- Create resource dependencies (Task 3)
- Create a bucket dependent instance (Task 3)
- Provision infrastructure (Task 4)

## Troubleshooting

| Gejala | Sebab dan solusi |
|--------|------------------|
| `terraform init` gagal | Cek koneksi internet Cloud Shell. HashiCorp repo mungkin perlu proxy. |
| Bucket already exists | Storage bucket name harus global unique. Script otomatis pakai project ID yang unik per lab instance, jadi seharusnya aman. |
| `terraform apply` error `service usage` | Akun student tidak punya izin `serviceusage.services.enable`. Qwiklabs sudah meng-enable API yang diperlukan. |
| Region/Zona beda | Set `REGION` dan `ZONE` environment variable: `REGION=us-central1 ZONE=us-central1-a bash gsp750.sh` |
