# GSP343 - Optimize Costs for Google Kubernetes Engine: Challenge Lab

Runbook untuk [`gsp343.sh`](../gsp343.sh). Status: **siap uji**.

Challenge lab untuk menguji keahlian optimasi biaya pada Google Kubernetes Engine (GKE) melalui pemilihan custom machine type, migrasi node pool (cordon/drain), Pod Disruption Budget (PDB), rolling update image tanpa downtime, Horizontal Pod Autoscaling (HPA), dan Cluster Autoscaler.

## Alur Kerja

1. **Task 1: Create a cluster and deploy your app**
   - Membuat cluster GKE zonal (2 node, `e2-standard-2`, channel `rapid`) di zone yang ditentukan (misal `europe-west4-c`).
   - Membuat namespace `dev` dan `prod`.
   - Meng-clone repo `microservices-demo` dan men-deploy aplikasi OnlineBoutique ke namespace `dev`.
   - Penilaian: *Create the cluster [cluster-name] and deploy an app* (25 pts).

2. **Task 2: Migrate to an optimized node pool**
   - Membuat node pool baru dengan tipe mesin custom yang lebih hemat biaya (`e2-custom-2-3584`, 2 node).
   - Melakukan cordon dan drain pada `default-pool`.
   - Menghapus node pool lama `default-pool`.
   - Penilaian: *Migrate to an optimized node pool* (25 pts).

3. **Task 3: Apply a frontend update**
   - Membuat Pod Disruption Budget `onlineboutique-frontend-pdb` dengan `min-available: 1` pada deployment `frontend` di namespace `dev`.
   - Memperbarui image container frontend menjadi `gcr.io/qwiklabs-resources/onlineboutique-frontend:v2.1` dengan `imagePullPolicy: Always`.
   - Penilaian: *Apply a Frontend Update* (25 pts).

4. **Task 4: Autoscale from estimated traffic**
   - Menerapkan Horizontal Pod Autoscaler (HPA) pada deployment `frontend` (target CPU 50%, min 1, max 12 pod).
   - Mengaktifkan Cluster Autoscaler pada node pool baru (min 1, max 6 node).
   - Menerapkan HPA pada deployment `recommendationservice` (target CPU 50%, min 1, max 5 pod).
   - Penilaian: *Autoscale from estimated traffic* (25 pts).

## Cara Menjalankan

Jalankan langsung di Cloud Shell:

```bash
curl -sLO https://raw.githubusercontent.com/ravi-arnan/gsp_lab_solutions/main/gsp343.sh
bash gsp343.sh
```

*Catatan*: Nama cluster dan node pool memiliki nomor acak unik per lab instance. Script menyediakan prompt default yang cocok dengan instruksi lab Anda (misal `onlineboutique-cluster-445` dan `optimized-pool-6743`). Tekan ENTER jika sudah cocok.

Setelah script menampilkan banner `SELESAI!`, klik keempat tombol **Check my progress** di panel lab:

2. *Migrate to an optimized node pool* (25 pts)
3. *Apply a Frontend Update* (25 pts)
4. *Autoscale from estimated traffic* (25 pts)
