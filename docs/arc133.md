## Task 1 — Query BigQuery → log ke Google Sheets (Apps Script)

1. Buka [script.google.com](https://script.google.com) → **New project**.
2. Rename project jadi bebas (klik judul "Untitled project" kiri atas).
3. Di editor, buka `Code.gs` (file default), **rename ke `bq-sheets.gs`** lalu tempel kode dari lab. Dua hal wajib dicek di dalam kode:
   - `PROJECT_ID` = **project ID dari panel lab** (mis. `qwiklabs-gcp-04-...`). Sudah terisi benar di paste lab, jangan diganti.
   - Query-nya memang memakai **syntax lama `[bigquery-public-data:samples.shakespeare]`** dengan kurung siku. Jangan "perbaiki" ke backtick, biarkan apa adanya — itu yang diharapkan.
4. **Enable BigQuery advanced service:** ikon **+ (Services)** di editor → pilih **BigQuery** → **Add**. Ini syarat Task 1; tanpa ini `BigQuery.Jobs.query` melempar error.
5. **Run** → pilih `runQuery` → izinkan otorisasi (pilih akun student, **Advance → Go to... (unsafe)** kalau muncul warning).
6. Kalau muncul error *"Service BigQuery API has not been enabled for your Apps"*: Services → hapus BigQuery → **+** tambahkan lagi → Run ulang.
7. Sukses = muncul log `Results spreadsheet created: <url>` — spreadsheet baru bernama persis judul query: **Most common words in all of Shakespeare's works**, berisi header `WORD` / `COUNT` + 10 baris hasil.

## Task 2 — Connected Sheets + formula

1. Buka [sheets.new](https://sheets.new) (halaman Google Sheets → **Blank spreadsheet**).
2. **Data → Data connectors → Connect to BigQuery**.
3. Pilih **project ID lab** (bukan "Public datasets" dulu) → **Public datasets** → **chicago_taxi_trips** → **taxi_trips** → **Connect**.
   - Muncul popup "Connect and analyze big data in Sheets" → **Get Connected**.
   - Ini mengunduh data besar; butuh beberapa menit.
4. Ketik tiga formula ini (masing-masing di sel terpisah, kolom bebas):

   | Pertanyaan | Formula |
   |------------|---------|
   | Berapa banyak perusahaan taksi? | `=COUNTUNIQUE(taxi_trips!company)` |
   | % perjalanan yang memberi tip? | `=COUNTIF(taxi_trips!tips,">0")` |
   | Total perjalanan dengan fare > 0? | `=COUNTIF(taxi_trips!fare,">0")` |

   **Click to insert**: saat mengetik `taxi_trips!`, Google Sheets menyarankan kolom — klik saran `company`/`tips`/`fare` untuk memasukkan referensi kolom yang benar.

   Untuk nilai persen: ubah format sel COUNTIF jadi **percent** (Format → Number → Percent), atau bagi dengan COUNT: `=COUNTIF(taxi_trips!tips,">0")/COUNT(taxi_trips!tips)`.

## Task 3 — Charts di Connected Sheets

Masih di spreadsheet yang sama (tab hasil connection). Klik kanan pada **Another chart on this sheet → Chart**, atau gunakan **Insert → Chart**, lalu edit tiap chart sesuai ini:

| Chart | X-axis | Series / Label | Value | Filter |
|-------|--------|----------------|-------|--------|
| **Pie: bentuk pembayaran** | - | Label: `payment_type` | Value: `fare`, set **Sum → Count** | - |
| **Line: revenue payment mobile sepanjang waktu** | `trip_start_timestamp`, centang **Group by** → **Year-Month** | Series: `fare` | (default Sum) | **Add filter** → `payment_type` → **Text contains** → `mobile` |
| **Line: payment mobile sejak revenue puncak 2015** | `trip_start_timestamp`, Group by → **Year-Month** | Series: `fare` | (default Sum) | filter `payment_type` → **Text contains** → `mobile` (bukan setiap tahun seorang diri, tapi seluruh rangkaian) |

Rincian langkah tanggal: di chart line, drag kolom **trip_start_timestamp** ke **X-axis**, centang **Group by**, pilih **Year-Month**. Drag **fare** ke **Series**. Untuk filter: **Filter → Add → payment_type**, klik status "Showing all items", pilih **Filter by condition → Text contains**, input `mobile`, **OK**.
